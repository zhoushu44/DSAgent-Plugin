消息发送模拟
Enter 发送 · Shift+Enter 换行
调用说明

在渲染进程（React 代码）中，可通过以下方式在任意位置模拟向指定会话发送消息： 

// 方式 1：使用 IPC Bridge（Electron 渲染进程）
await window.phoenixAPI?.sendMessageToConversation?.({
  conversationId: '<目标会话 ID>',
  text: '你好，这是一条模拟消息',
  attachmentUrls: ['https://example.com/file.pdf'], // 可选
})

也支持简写形式（参数2 为消息内容）：

await window.phoenixAPI?.sendMessage?.('<conversationId>', '消息内容')

在子窗口 / 浏览器预览窗口内，通过 IPC 发送消息并附带截图附件：

// 方式 2：browser-preview 子窗口发送（附带截图）
window.contentBridge?.sendToConversation?.({
  conversationId: '<目标会话 ID>',
  text: '页面截图已发送',
  attachmentUrls: ['<截图 URL>'],
})
Payload 字段说明
字段 类型 说明
conversationId string 目标会话 ID，必填
text string 消息文本内容
attachmentUrls可选 string[] 附件 URL 数组（图片、文件等）
注意事项

• 若目标会话正在对话中（AI 响应未结束），发送会被拒绝。
• text 与 attachmentUrls 至少须有其一。
• 此模拟子窗口仅在开发者模式下可打开；sendMessageToConversation 接口本身在所有版本中均可调用。
