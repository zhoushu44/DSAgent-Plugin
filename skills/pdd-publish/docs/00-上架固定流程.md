## 一、入口（实现只有一套）

| 入口 | 用途 | 会不会提交 |

| `skills/pdd-publish/steps/index.mjs` | **唯一实现**（contract 指向它，工具调用走这里） | `--confirm true` 才提交；`--stop-before-submit` 填完停下 |

## 二、商品数据格式（不要改）

```json
{
  "title": "≤60 字",
  "catId": 15021,
  "images": ["本地路径 5 张"],
  "detailImages": ["本地路径 10 张"],
  "specs": [
    { "name": "颜色分类", "values": ["银河蓝", "迷雾紫"] },
    { "name": "参考分类", "values": ["110", "120"] }
  ],
  "skus": [{ "specs": { "颜色分类": "银河蓝", "参考分类": "110" }, "price": 34, "multiPrice": 33, "stock": 99, "itemNo": "S01-01" }],
  "attributes": { "材质成分": "涤纶（聚酯纤维）" },
  "price": 35,
  "shipTime": "48小时"
}
```

- 规格名必须是**类目内置维度名**（颜色分类 / 参考分类），不要自造「图案 / 尺码」。
- 没有 `thumb` 字段：第 i 个颜色 → `images[i]`（颜色不够时回落到 `images[0]`）。
- `price` = 单买价，`multiPrice` = 拼单价。

## 三、步骤与关键动作

1. 打开发布页 → 主图 → 标题 → 第 2 步
2. **类目**：按 `catId` 找模板核对，不一致就手动选；**找不到模板直接报错停下**（不会带着残留类目往下填）
3. 属性（14 项）→ 详情图
4. **11 规格**：按模板预置维度填；页面一次只画 ~18 行，不够就先补画（`helpers/sku-window.mjs`）
5. **12 价格/库存/编码**：走页面官方「Excel批量编辑规格」
   `导出当前规格 → 本地按规格值匹配填值 → 导入 → 点「确认编辑」 → 再导出回读校验`
6. **12b 预览图**：价格填完后单独一步，逐行上传该颜色对应的主图
7. 13 参考价 → 14 → 15 发货时间 → 停在提交前

## 四、三条硬规矩（踩过的坑）

1. **价格表绝对不能滚动或聚焦后再填**。它是虚拟列表，一滚就重渲染收缩回 18 行。
   补画之后同样不能再滚。所以价格一律走 Excel，不逐格填。
2. **Excel 导入后必须点「确认编辑」**。少了这一步，页面不报错、什么都不写。
3. **找不到类目模板就先拉模板再跑**，不要手改类目：
   ```
   node skills/pdd-publish/scripts/pdd-category.mjs template --catId <catId> --save
   ```
   然后复制 `skills/pdd-publish/templates/<模板ID>__<名字>/template.json`
   到 `artifacts/pdd-templates/<名字>-<catId>/template.json`
