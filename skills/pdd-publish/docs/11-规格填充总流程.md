# 三、读模板

从 `tpl.specs` 取两组信息。

## 3.1 `dimensions[]` —— 平台预置维度

```json
{
  "name": "尺码",
  "type": "size-table",
  "refPid": 233,
  "controlType": 3,
  "presetValues": [
    { "value": "M", "group": "中国码" },
    { "value": "120", "group": "身高" },
    { "value": "40", "group": "欧码" }
  ],
  "presetCount": 91
}
```

| 字段 | 用途 |
|---|---|
| `name` | 维度名，和页面标题比对 |
| `type` | 决定用哪个填充器（text / checkbox / size-table）|
| `refPid` | 平台属性号。>0 表示平台内置维度 |
| `presetValues[].group` | **关键**：尺码表切标签页靠它，不要靠猜 |

## 3.2 `maxDims` —— 维度上限

```
maxDims > 0  → 真实上限
maxDims = 0  → 模板没记录，交给页面限制
```

> **实测坑**：床上四件套 `maxDims=0`，但页面写「添加规格类型(0/2)」能加 2 维。
> 所以 `maxDims=0` 必须跳过校验，否则永远报「规格最多 0 维」。

# 五、A 类：预设勾选

## 5.1 流程图

```
① 定位维度块
   ├─ 外层 .property-name-title 文字 == 维度名
   ├─ 内层 [class*="wrapperTitle"] 文字 == 维度名
   └─ 内容特征（全选以下规格值 / 尺码表）
        ▼
② 收集所有组 .package-item-container
        ▼
③ 第 i 个值 → 第 i 组
        ▼
④ 组内有输入框？
   ├─ 有 → 先写值
   └─ 无 → 跳过
        ▼
⑤ 勾组的 checkbox
        ▼
⑥ 派发事件 input / change / Enter / blur
```

## 5.2 关键代码点

```js
// 维度定位（find-dim.mjs 三层兜底）
findDim(page, dimName)
  → { ok, idx, why }  // why: title / inner-title / content

// 组配对
const groups = [...box.querySelectorAll('.package-item-container')]
const target = groups[i]          // 第 i 个值用第 i 组
const cb = target.querySelector('input[type="checkbox"]')
if (!cb.checked) cb.click()
```

## 5.3 注意事项

| 注意点 | 说明 |
|---|---|
| **先写值，再勾选** | 顺序不能反，反了值会丢 |
| 组内第 1 个 text input 是规格名 | 第 2 个是备注，不要写 |
| 勾选框是 `input[type="checkbox"]` | 不是 `div.CBX_square`（那是视觉方块）|

## 7.1 流程图

```

        而在 [class*="wrapperTitle"] 里

   （label 或 div 文字 == 目标值）
        ▼

## 7.2 为什么要停用

**不停用 → 必须填身高/体重/衣长/肩宽/胸围/袖长/裤长/臀围/腰围 9 个参数。**

童装停用前的报错：

```
3 个规格值尺码信息未填写正确，请修改
```

**停用后 → 这些参数都不用填，直接提交。**

## 7.3 各服装类目的分组（模板原文）

|---|---|---|
| 女装T恤 | 尺码 | 通用 / 中国码 / 欧码 / 英码 / 德码 / 美码 / 均码 |
| 连衣裙 | 尺码 | 同上 |
| 休闲裤 | 尺码 | 同上 |
| 运动鞋 | 鞋码 | 欧码 / 法码 / 英码 |
| 童装 | 参考分类 | 身高 / 国际标准 |

```

## 8.3 三个致命坑（全部实测踩过）

### 坑 1：点 `div` 不触发下拉

```
❌ 点外层 div：text="添加规格类型("  → ok:true 但下拉不出现
✅ 点 button：  text="添加规格类型(1/2)" → 下拉正常弹出
```

**代码**：必须 `document.querySelectorAll('button')` 优先，非 button 只做兜底。

### 坑 2：不点 `规格类型N` 输入框，下拉不弹

```
❌ 等下拉自己出现 → 等 10 秒也没有
✅ 点 input[placeholder="规格类型1"] → 下拉立刻弹出（30 个选项）
```

**代码**：

```js
inp.scrollIntoView({ block: 'center' })
inp.focus()
inp.click()
inp.dispatchEvent(new MouseEvent('mousedown', { bubbles: true }))
inp.dispatchEvent(new MouseEvent('mouseup', { bubbles: true }))
inp.dispatchEvent(new MouseEvent('click', { bubbles: true }))
```

### 坑 3：写完值不点空白，值丢失

```
现象：写入 1.5m床 ✅  写入 1.8m床 ✅
      → 但页面只剩 1.5m床，1.8m床不见了
      → SKU 表只有 2 行（应该 4 行）

原因：最后一个值没有触发「提交」动作

解决：写完点空白 label
      document.querySelector('.Form_itemLabelWrapper_5-194-0').click()
```

**点完的效果**（实测）：

```
点前：valInputs = ["1.5m床", "1.8m床", ""]
点后：valInputs = ["1.5m床", "1.8m床"]
SKU 表：从 2 行 → 4 行 ✅
```

# 十一、价格库存填写（step12）

## 11.1 流程图

```
① 读表头文字 → 找列号
   库存 / 拼单价 / 单买价 / 规格编码 / 商品编码
        ▼
② 行内定位：用「第 N 个 text input」
   表头顺序 → input 顺序：
   库存 → 拼单价 → 单买价 → 规格编码 → 商品编码
   （规格列只有文字无 input；预览图是 file input，已跳过）
        ▼
③ 写入顺序：库存 → 单买价 → 拼单价 → 编码
   ★ 必须先写单买价
        ▼
④ 每写一个值立刻回读确认
        ▼
⑤ 每行写完等 400ms
        ▼
⑥ 全部写完 → 回读校验（不一致只警告）
```

## 11.2 为什么必须先写单买价

**平台联动校验：拼单价 必须 < 单买价**

```
❌ 先写拼单价 545
   → 此时单买价还是空
   → React 判定非法
   → 直接清空拼单价

✅ 先写单买价 546
   → 再写拼单价 545
   → 两个都保留
```

**实测证据**：

```
顺序 A（拼单价先）：
  写 11.1 → 回读 ["111","","22.1","TEST"]   ← 拼单价空了

顺序 B（单买价先）：
  写 22.1 → 写 11.1 → 回读 ["111","11.1","22.1","TEST"]  ← 全在
```

## 11.3 为什么每写一个值要回读

```
同一次 page.evaluate 里连续写 4 个值：
  第1个 ✅  第2个 ❌  第3个 ✅  第4个 ✅
  （React 重渲染把第2个冲掉了）

每写一个 → evaluate 返回 → 再进页面 → 重新查 DOM → 写下个：
  4 个全部 ✅
```

## 11.4 为什么回读不一致只警告

不同类目 SKU 表的 `rowspan / colspan / 表头结构` 差异极大：

| 类目 | 表头 | 颜色列 |
|---|---|---|
| T恤 | 8 列 | rowspan=3 |
| 休闲裤 | 8 列 | rowspan=2 |
| 四件套 | 8 列 | rowspan=2 |
| 纸杯 | 6 列 | 无规格列 |

回读算法难以 100% 覆盖。**写入本身是成功的（页面可见），真实校验交给 step16 提交前的必填检查 + 平台校验。**

# 十四、常见报错对照

| 报错 | 原因 | 解决 |
|---|---|---|
| `规格最多 0 维，当前 1 维` | 模板 maxDims=0 但被当上限 | maxDims=0 时跳过校验 |
| `规格维度「XXX」不在模板内（可用：）` | 模板无预置维度，被误判 | 模板 dimensions 为空时允许任意维度名 |
| `选了「尺寸常用」但页面上找不到该维度块` | 维度名取的是 li 全文（含「常用」） | 取 li 内第一个文本节点 |
| `下拉里找不到「XXX」（页面可选：官方客服）` | 选择器抓到页面底部客服 | 用 `ul[role="listbox"] li[role="option"]` |
| `找不到「添加定制规格」` | 点的是外层 div，没真加维度 | 点 button |
| `规格值尺码信息未填写正确` | 尺码表没停用 | 点「停用尺码表」→ 确认 |
| `第1行规格的拼单价必须大于0` | 拼单价被联动校验清空 | 先写单买价 |
| `请上传第1行规格的预览图` | 缺 SKU 缩略图 | 每个 sku 加 thumb |
