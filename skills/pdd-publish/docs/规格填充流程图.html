七、价格库存填写（step12）

进入价格库存
① 读表头文字 → 找列号
库存 / 拼单价 / 单买价 / 规格编码
② 行内定位：用「第 N 个 text input」
表头顺序 → input 顺序：
库存 → 拼单价 → 单买价 → 规格编码 → 商品编码
（规格列只有文字无 input；预览图是 file input，已跳过）
③ 写入顺序：库存 → 单买价 → 拼单价 → 编码
★ 必须先写单买价！
平台联动校验「拼单价 < 单买价」
先写拼单价时单买价还是空 → React 判非法 → 直接清空
④ 每写一个值 立刻回读确认
同一次 evaluate 里连写 4 个 → 第 2 个被 React 重渲染冲掉
每个值单独 evaluate + 回读 → 4 个全部保留
⑤ 每行写完等 400ms 再写下一行
回读不一致？
只警告
不阻断，继续
写入失败
才算错误
交给 step16 提交 + 平台校验
回读为什么只警告：不同类目 SKU 表的 rowspan / colspan / 表头结构差异极大 （T恤颜色列 rowspan=3、休闲裤 rowspan=2、纸杯无规格列），回读难以 100% 覆盖。 写入本身是成功的（页面可见），真实校验交给提交前的必填检查 + 平台校验。
