# 拼多多·商品发布（pdd-publish）

> 一句话定位：把本地图片与商品信息发布为拼多多商品（商家后台 mms.pinduoduo.com），自动跑完两步式发布链路并填通用字段，用于「铺货到拼多多」。

## 能力

- 把本地主图 + 标题发布为拼多多商品，自动填**类目（平台推荐）/ 主图 / 标题 / 参考价 / 库存 / 货号**。
- 自动上传**商品详情页图片**（最多 50 张）。
- 自动配置 **SKU 多规格**：规格值、预览图、拼单价（单买价自动 = 拼单价 + 1）。
- 尽力自动选**部分商品属性**（按类目动态出现的下拉项，品牌除外）。
- **只支持单件发布**，不做批量 / 定时发布 / 批量上下架。

**不做的事**：不采集比价、不动订单售后、不管库存、不发客服消息、不做数据分析、不发淘宝/天猫、不发闲鱼、不生成文案（标题与价格需用户提供）。

## 触发方式（自然语言示例）

- 「帮我把这个发到拼多多」「拼多多上架」 → 发布商品
- 「拼多多发布商品」「上传商品到拼多多」 → 发布商品
- 「把这批货铺到拼多多」 → 单件发布（逐件调用）
- 直接给图片路径 + 标题（可带价格 / 库存 / 货号） → 发布商品

## ⚠️ 发布是真实操作（L2），两步式

发布是**不可撤销**的真实操作，必须走两步：**先由工具给出「发布预览」给你确认，你明确同意后才真正提交浏览器上架**。预览阶段的返回不是报错（`needConfirm=true` 属正常流程）。

**不会自动填的字段**（需你在随后弹出的浏览器窗口中人工补全）：**发货与售后设置、运费模板、商品资质、品牌、类目属性**。提交被平台拦下时也可能需要你补全这些项后手动点「提交并上架」。

## 输入

| 参数 | 必需 | 说明 |
|------|------|------|
| `title` | 是 | 商品标题，**不超过 60 个字符** |
| `images` | 是 | 本地图片**绝对路径**，1~10 张、单张 ≤ 3MB；多张用英文逗号分隔或传 JSON 数组字符串 |
| `detailImages` | 否 | 商品详情页图片本地路径，最多 50 张、单张 ≤ 3MB，写法同 `images` |
| `skus` | 否 | SKU 多规格 JSON，如 `[{"name":"白色","image":"C:/img/w.jpg","price":"9.9","stock":"1000"}]`；`name` 规格值名（必填）、`image` 规格预览图（提交必填：宽高比 1:1、宽高均 >480px、单张 <3MB、仅 JPG/PNG）、`price` 拼单价、`stock` 库存 |
| `category` | 否 | 类目关键词（如「纸杯」）——**仅作提示，不会自动选类目**，类目由平台智能推荐 |
| `price` | 否 | 商品参考价（元），正数、1 亿元以内 |
| `stock` | 否 | 库存（件），非负整数；**不传则默认填 1000** |
| `itemNo` | 否 | 商家编码 / 货号，**默认不写** |
| `confirm` | 否 | 省略或 `false` → **只返回预览、不产生任何写操作**；`true` → 才真正打开浏览器提交 |
| `account` | 否 | 指定账号 `shopKey`；仅在多账号待选时回传用户选定值 |

**默认值约定**（用户没提就别追问）：库存省略按 **1000**；单买价自动 = **拼单价 + 1**；货号不写。

## 平台硬限制

- 主图 1~10 张、单张 ≤ 3MB；详情图最多 50 张。
- 标题必填、≤ 60 字符（约 30 个汉字）。
- SKU 规格预览图为提交必填，且需满足「1:1、>480px、<3MB、JPG/PNG」。
- 拼单价必须 > 0；单买价必须 ≥ 拼单价 + 1；库存必填。
- 规格类型固定为「颜色」，规格值名 ≤ 40 字，最多 20 个规格值、2 个规格类型。
- 同一时间只能有一个拼多多商家后台浏览器任务；会出现滑块拼图需人工完成，遇到「右侧填写建议面板」拦因时需按提示处理。

## 账号绑定

- 绑定**拼多多商家后台**账号（登录 mms.pinduoduo.com，可拼多多 App 扫码或账号密码）。
- **★ 强调**：商家后台与买家端「拼多多」是**两套完全独立登录态**。采集技能（`pdd-crawl`）用的买家端账号**不能**用于发布商品，必须在「账号连接」里单独绑定商家后台账号。

## 输出

返回 JSON，`text` 字段就是给人看的中文文案（原样转述即可）：

- **成功**：`ok=true`，含商品 ID、`finalUrl`、已自动填写的字段清单，以及「未自动填写」的字段提醒——平台仍会审核，最终以商家后台「商品管理 → 出售中」为准。
- **预览**：`ok=false + needConfirm=true`，文案含渠道 / 账号 / 标题 / 类目 / 参考价 / 库存 / 主图 / 详情图 / SKU，等你确认。
- **失败**：`ok=false`，带 `failureKind`，按下方速查处理。

## 错误处理速查

| 常见失败 | 处理动作 |
|---------|---------|
| 未绑定商家后台账号（`not_bound`） | 引导到「账号连接」添加**商家后台**账号（买家账号不行） |
| 多账号未选（`need_account_choice`） | 候选清单给用户选，回传 `shopKey`，绝不自己挑 |
| 后台登录态失效（`token_expired`） | 重新登录商家后台 |
| 命中滑块拼图（`risk_control`） | 工具等 120s，人工在窗口内拖动滑块后自动继续 |
| 图片不存在 / 超 3MB / 超 10 张 | 修正路径或压缩后重试 |
| 标题空 / 超 60 字符 / 价格库存越界 | 修正参数后重试 |
| 提示发货售后 / 运费模板 / 资质未填 | **不由工具自动填**，在窗口内补全后手动提交 |
| 提示 SKU 预览图未填 | 多为图片不达标，换图或人工上传 |
| 提交后 180s 无成功标志 | 看窗口内红色校验项补全后手动提交 |

## 相关技能

- **采集 / 比价拼多多商品** → `pdd-crawl`（买家端账号，与发布账号不同）
- **淘宝 / 天猫发布** → `taobao-publish`
- **订单 / 售后** → `pdd-order`；**库存** → `pdd-stock`；**客服** → `pdd-im`；**数据分析** → `pdd-analytics`
- **闲鱼发布** → `xianyu-publish`
