# 行业竞争护城河分析

将公司置于其真实的行业结构中，检验其是否具备可防御的经济特性。

## 不可违反的规则

- 使用公开的政策文件、统计数据、招投标信息与公司披露来验证行业相关主张。
- 区分公司自身声明与第三方验证信息。
- 明确标注竞争对手比较中哪些是事实、哪些是推断。
- 不在本技能中重复进行详细的公司财务评分。
- 所有中间及最终输出默认使用简体中文，除非用户明确要求其他语言。
- 所有核心事实、数据和结论必须附带可点击的来源链接。

## 适用场景

- 评估行业吸引力与竞争强度。
- 将公司与上市可比公司及替代商业模式进行对比。
- 检验政策、资本、资质、数据、渠道或转换成本是否构成护城河。

## 工作流程

1. **定义价值链**：明确价值链各环节，定位公司在其中的精确位置。
2. **获取行业数据**：从官方来源拉取产业政策与需求数据。
3. **筛选可比公司**：基于来源支撑选取可比公司集合，比较产能、客户、利润率与商业模式。
4. **护城河与五力分析**：运用护城河评估矩阵与波特五力框架进行结构化分析。
5. **价值捕获与脆弱点**：标注公司在哪些环节捕获价值，在哪些环节仍然脆弱。

## 必需输出格式

- **事实**：行业规模、政策顺风/逆风、可比公司定位、价值链角色
- **解读**：护城河强度、结构性优势、可能的压力点
- **待验证问题**：缺失的可比公司指标、不确定的新增供给、不清晰的监管政策
- **价值链图谱**：每个环节标注强（Strong）、中（Medium）、弱（Weak）的价值捕获能力

## 边界约束

- 不详细推演公司的订单管线。
- 不在本技能中构建风险仪表盘。
- 不产出目标价或交易计划。

## 附录一：护城河评估矩阵

对每个维度进行评估，并以来源支撑每一项判断。

| 维度 | 核心问题 |
| --- | --- |
| **成本优势** | 规模效应、制造能力、区位优势或融资成本是否降低了成本？ |
| **转换成本** | 客户是否因系统集成、认证要求或迁移成本而被锁定？ |
| **产能或资源获取** | 土地、能源、配额、牌照或供给是否难以复制？ |
| **品牌或资质** | 正式资质或品牌声誉是否影响中标率？ |
| **生态位** | 公司是否处于多方依赖的关键节点？ |

**评估标准**：对每个维度标注 **强（Strong）**、**中（Mixed）** 或 **弱（Weak）**，并解释原因。

### 来源使用强制规则

- 所有核心事实、数字、合同、融资及治理事项优先使用 **第一层级** 来源。
- 使用 **第二层级** 验证市场规模、政策、采购与区域产业背景。
- **第三层级** 仅作补充背景，除非其引用了官方来源。
- 所有链接必须可直接点击访问。
- 若来源需要登录或无法公开访问，标注为"不可公开获取"，不得将其作为主要证据。

### 按主题推荐的来源查找顺序

- **公司历史与业务组合**：巨潮资讯 -> 年报 -> 招股说明书 -> 官方网站
- **订单与项目**：交易所公告 -> 运营商采购门户 -> 地方政府/园区网站
- **债务与融资**：年度/中期报告 -> 债券/可转债备案 -> 董事会决议
- **产业政策**：工信部 -> 发改委或地方政府 -> 行业协会
- **宏观与区域需求**：国家统计局 -> 省/市统计局 -> 政策文件

## 附录三：行业适配清单

针对不同行业调整分析框架，但不降低证据标准。

### 通用核心问题

- 真正的收入引擎是什么？
- 哪些资产负债表科目隐藏了关键风险？
- 哪些外部来源可以验证管理层的叙事？
- 哪个指标最能体现变现质量？

### IDC与重资产基础设施

- 检查运营商采购门户、能源政策、区域资源约束、上架率或负载爬坡。
- 聚焦资本开支、债务期限、项目投产与合同执行。
- 若公司为IDC、AI算力或重资产转型标的，需额外关注：资本密集度、自建与轻资产模式的差异、机柜利用率与上电节奏。

### 制造业

- 聚焦产能利用率、客户集中度、出口敞口与库存真实性。
- 若公司以出口为主或OEM/ODM占比高，需额外关注供应链集中度与汇率风险。

### 消费品

- 聚焦同店增长趋势、渠道健康度、应收风险与品牌定价权。
- 当渠道库存与品牌力是核心议题时，需额外关注终端动销与经销商库存数据。

### 医药与健康

- 聚焦管线披露、定价政策、医保报销与监管里程碑。
- 当政策或审批风险是核心议题时，需额外关注集采影响与审评审批进度。

### 周期品与材料

- 聚焦价差、库存周期、资本开支纪律与区域新增供给。
- 当盈利受价差或价格驱动时，需额外关注原材料价格波动与产能投放节奏。

### 输出规则

应用行业适配清单时，保持统一的引用格式，并标注哪些部分属于行业特定分析。

## 附录四：IDC行业价值链与可比公司筛选指南

当公司声称在IDC、AI算力基础设施或数据中心生命周期服务领域竞争时，使用本指南。

### IDC专项官方来源

| 来源 | 验证内容 | 网址 |
| --- | --- | --- |
| 工信部（MIIT） | 绿色数据中心、数字基础设施、工业互联网政策 | https://www.miit.gov.cn/ |
| 国家发改委（NDRC） | 算力基础设施与宏观政策框架 | https://www.ndrc.gov.cn/ |
| 国家统计局 | 宏观与区域需求背景 | https://www.stats.gov.cn/ |
| 运营商采购门户 | 外部需求与套餐结构 | https://b2b.10086.cn/ |
| 交易所信息披露 | 可比公司业务模式、资本开支、利用率披露 | https://www.cninfo.com.cn/new/index |

### 价值链分桶

- **上游**：设备、电力、制冷、模组、工程能力
- **中游**：设计、集成、EPC、调试交付
- **资产持有方/运营方**：自建或自营数据中心产能
- **需求侧**：运营商、云厂商、互联网平台、地方政府支持的算力需求

### 可比公司筛选逻辑

不要仅凭"IDC"或"AI"标签强制划定可比公司集合。

按以下维度进行比较：

- **收入模式**：一次性交付 vs 持续性运营
- **资产密集度**：自有资产 vs 轻资产集成模式
- **客户类型**：运营商、云厂商、政府、企业
- **爬坡指标**：上架率、机柜负载、上电率、利用率或服务收入占比
- **融资负担**：债务驱动型扩张 vs 较轻资产模式

### IDC专项护城河检验

- 优势究竟来自制造成本、集成速度、审批资质、客户关系还是稀缺电力资源？
- 所声称的护城河能否经受运营商压价或云厂商自建的冲击？
- 公司赚取的是集成利润、资产收益还是两者兼有？

### 竞争主张验证规则

对每一项竞争主张，必须明确其证据来源是：公司披露、政策文件、招投标信息还是第三方验证。
