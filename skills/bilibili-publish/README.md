# B站·内容发布（bilibili-publish）

> 一句话定位：把本机视频文件投稿到 B站，自动上传视频、填写标题/简介、创建标签、选分区与创作声明并提交，属于**真实、不可撤销的发布操作**。

## 能力

- 把本地视频文件上传到 B站 并发布为稿件
- 自动填写标题、简介，创建标签
- 选择分区与创作声明
- 支持完整预览确认流程（见下）
- 同一时间仅支持一个发布窗口，窗口进行中需等待其结束

## 触发方式（自然语言示例）

- 「把这个视频发到 B站」
- 「投稿 B站，「标题是 xxx，标签是 xxx」」
- 「把这个 mp4 上传到 B站账号」
- 「帮我发个 B站 稿件」

## 输入

| 参数 | 必需 | 说明 |
|------|------|------|
| videoPath | 是 | 本地视频文件的**绝对路径**（如 `D:\videos\demo.mp4`），须真实存在 |
| title | 是 | 稿件标题，**≤ 80 字** |
| description | 否 | 简介，**≤ 2000 字** |
| tags | 否 | 标签，逗号分隔；上限约 **10 个**、单个 **≤ 20 字** |
| partition | 否 | 分区名（如「科技数码」「知识」「生活兴趣」）。**不传则沿用页面自动预选** |
| statement | 否 | 创作声明，可选：`内容无需标注` / `含AI生成内容` / `含虚构演绎内容` / `内容含营销信息` / `个人观点，仅供参考` / `内容为转载` / `内容为自制：未经作者允许，禁止转载`；不传默认「内容无需标注」 |

**发布是 L2 真实操作，必须两步走：**
1. 第一次调用**不带 confirm**，工具只返回「发布预览」文本（含账号、视频路径、标题、标签、分区、创作声明、简介），不启动浏览器、不产生任何写操作；
2. 把预览原样展示给用户并询问「确认要发布吗？」，得到**明确同意**后，第二次调用**带 `confirm=true`** 才真正提交发布。严禁在不确认的情况下直接提交。

## 限制与边界

- **不做数据采集** → 用 `bilibili-crawl`
- **不做视频下载** → 用 `bilibili-download`
- **不做评论互动、弹幕、数据分析**（对应技能未实现）
- **不生成文案**：标题/简介/标签由用户提供，或先用文案技能生成再回来发布
- **只支持视频投稿**：专栏图文、动态、音频投稿不支持
- **不支持定时发布、封面自定义、合集/活动话题选择、联合投稿**
- 视频必须是本机绝对路径且真实存在；技能不做下载，需先备好文件
- 平台硬限制：标题 ≤ 80 字、简介 ≤ 2000 字、标签 ≤ 10 个且单个 ≤ 20 字，超限会被拦下；分区与创作声明为必填项
- 发布会弹出**可见浏览器窗口**（真实操作，用户全程可见）；若出现滑块/安全验证需人工完成

## 账号绑定

- 绑定 **bilibili** 平台的投稿账号，登录态由工具从其凭证库注入浏览器 Cookie，技能不接触 Cookie
- **必须要有登录态**：未绑定 / 登录态失效都会被引导去「账号连接」页面重新登录
- 若平台有多账号未选，会把候选列表交给你选择，选定后填入 `account`，不会自行挑选

## 输出

- 预览阶段：返回一段发布预览文本供确认
- 提交成功：告知已提交，并提示**平台可能仍在审核**，最终状态以 B站 创作中心「稿件管理」为准
- 失败：返回 `failureKind` 与引导动作，按错误速查处理

## 错误处理速查

| 常见失败 | 处理动作 |
|---------|---------|
| 未绑定 B站 账号（`not_bound`） | 到「账号连接」页面扫码登录 B站 |
| 多账号未选（`need_account_choice`） | 把候选账号给用户选，选定填入 `account` 重试 |
| 投稿页被重定向到登录页（`token_expired`） | 去「账号连接」重新登录 B站 |
| 文件不存在 / 标题超 80 字 / 简介超 2000 字 | 修正参数后重试 |
| 上传后编辑器未就绪 | 可能是格式不支持或被风控；确认格式（建议 mp4），必要时重试 |
| 分区名未匹配 | 改用合法分区名，或省略 `partition` 沿用自动预选 |
| 创作声明列表未展开 | 页面结构可能变更，重试一次 |
| 找不到标题框/投稿按钮 | 页面结构可能变更，上报该问题 |
| 点击投稿后未检测到成功标志 | 查看弹出浏览器窗口内的提示；若有滑块需人工完成 |

## 相关技能

- 上下游：`bilibili-crawl`（查数据）、`bilibili-download`（备好本地视频）
- 同类：`douyin-publish`（抖音发布）、`xiaohongshu-publish` / `zhihu-publish` / `taobao-publish` 等（各平台发布）
