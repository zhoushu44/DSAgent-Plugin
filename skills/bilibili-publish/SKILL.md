# B站内容发布

> **重要:** 发布是**不可撤销的真实操作（L2）**。必须两步走：先拿「发布预览」给用户看，用户**明确同意**后才真正提交。
> 绝不要在一次调用里直接传 `confirm=true`。

## 何时使用

- 用户说"把这个视频发到 B站"、"投稿 B站"、"上传视频到 B站" → 发布视频
- 用户给出本地视频文件路径 + 标题（可选简介/标签），要求发到 B站 → 发布视频
- 用户说"帮我发 B站"、"发个 B站 稿件" → 发布视频

## 边界

- **不做数据采集** —— 视频详情 / UP 主投稿 / 搜索 / 排行榜 / 评论请用 `bilibili-crawl`
- **不做视频下载** —— 把 B站 视频存到本地请用 `bilibili-download`
- **不做评论互动、弹幕、数据分析** —— 对应技能尚未实现
- **不生成文案** —— 标题、简介、标签由用户提供（或先用通用文案技能生成，再回到本技能发布）
- **只支持视频投稿** —— 专栏图文、动态、音频投稿当前不支持
- **不支持定时发布、封面自定义、合集/活动话题选择、联合投稿**
- 视频文件必须是**本机绝对路径**且真实存在；技能不做下载，用户需先备好文件
- 标题**限 80 字**、简介**限 2000 字**，超限会在调用前被拦下
- 标签上限约 **10 个**、单个 **≤ 20 字**
- 分区为**必填项**：页面会随机自动预选一个有效分区，若用户对分区有要求需显式传 `partition`
- 创作声明为**必填项**：不传时工具自动选「内容无需标注」
- 发布过程会**弹出可见浏览器窗口**（真实操作，用户可见）；若出现滑块/安全验证需人工完成
- 同一时间只能有一个 B站 发布窗口；已有窗口进行中时需等待其结束

## 执行流程

本技能**没有脚本入口**，执行方式是**直接调用 host 工具** `dsagent_bilibili_publish`。

### 1. 收集参数

从用户话里提取，缺项就主动问：

| 参数 | 必需 | 说明 |
|------|------|------|
| `videoPath` | 是 | 本地视频文件的**绝对路径**（如 `D:\videos\demo.mp4`） |
| `title` | 是 | 稿件标题，**≤ 80 字** |
| `description` | 否 | 简介，**≤ 2000 字** |
| `tags` | 否 | 标签，多个用逗号分隔，上限 10 个、单个 ≤ 20 字 |
| `partition` | 否 | 分区名（如「科技数码」「知识」「生活兴趣」）。**不传则沿用页面自动预选的分区** |
| `statement` | 否 | 创作声明。不传则自动选「内容无需标注」 |

创作声明可选项：`内容无需标注` / `含AI生成内容` / `含虚构演绎内容` / `内容含营销信息` / `个人观点，仅供参考` / `内容为转载` / `内容为自制：未经作者允许，禁止转载`。

### 2. 先取「发布预览」（不带 confirm）

调用 `dsagent_bilibili_publish`，**不要传 `confirm`**：

```
dsagent_bilibili_publish(videoPath="D:\videos\demo.mp4", title="今天分享一个技巧", tags="运营,干货", partition="知识")
```

工具此时**不会启动浏览器、不产生任何写操作**，只返回一段「发布预览」文本（含账号、视频路径、标题、标签、分区、创作声明、简介）。

### 3. 把预览完整展示给用户并征求明确同意

把预览内容原样呈现给用户，并明确问一句类似"确认要发布吗？"。
**这一步不可跳过、不可自行假设用户同意**（L2 风险门禁）。

### 4. 用户同意后带 `confirm=true` 重新调用

```
dsagent_bilibili_publish(videoPath="D:\videos\demo.mp4", title="今天分享一个技巧", tags="运营,干货", partition="知识", confirm=true)
```

工具会弹出可见浏览器窗口，依次完成：注入登录态 → 打开创作中心投稿页 → 上传视频 → 等编辑器就绪 → 填标题 → 创建标签 → 填简介 → 选创作声明 → （可选）选分区 → 点「立即投稿」→ 判定结果。

### 5. 报告结果

- 成功：告知已提交，并说明**平台可能仍在审核**，最终状态以 B站 创作中心「稿件管理」为准
- 失败：按返回的 `failureKind` 走下方「错误处理」

## 错误处理

| 场景 | failureKind | 引导动作 |
|------|-------------|---------|
| 未绑定 B站 账号 | `not_bound` | 引导用户到「账号连接」页面扫码登录 B站 账号 |
| 平台有多个可用账号且当前会话未绑定 | `need_account_choice` | **把候选列表给用户选**，把选定的 `shopKey` 填进 `account` 参数重调；★ 绝不要自己挑一个 |
| 投稿页被重定向到登录页 | `token_expired` | 引导用户到「账号连接」页面**重新登录** B站 |
| 视频文件不存在 / 标题超 80 字 / 简介超 2000 字 | `api_error` | 按提示修正参数后重试 |
| 上传后编辑器未就绪（等不到标题框） | `api_error` | 可能是视频格式不支持或上传被风控；让用户确认格式（建议 mp4），必要时重试 |
| 分区名未匹配到 | `api_error` | 按提示改用合法分区名（如「科技数码」「知识」「生活兴趣」），或省略 `partition` 沿用自动预选 |
| 创作声明选项列表未展开 | `api_error` | 页面结构可能变更或加载未完成，重试一次 |
| 找不到标题框 / 投稿按钮 | `api_error` | 页面结构可能变更，请上报该问题 |
| 点击投稿后未检测到成功标志 | `api_error` | 让用户查看弹出的浏览器窗口内的具体提示；若有滑块需人工完成 |

## 环境变量

本技能为纯指令型，不执行脚本，无环境变量依赖。
账号凭证由 host 工具从凭证库直接读取并注入浏览器 Cookie，**技能侧不接触 Cookie**。
