# Style Guide

## Routing Header

- **Load when**: no specialized scene matches, the user asks for creative generation, or a prompt needs richer atmosphere/composition/lighting/material vocabulary.
- **Do not load when**: a specialized reference already provides sufficient prompt structure.
- **Merge notes**: use only small vocabulary snippets from this file; do not let style enrichment override product fidelity or factual constraints.
- **Hard stop**: do not add unsupported product materials, features, claims, or brand elements for style reasons.

Prompt enrichment vocabulary for general image generation (Priority 4 fallback) and any scene that benefits from more specific visual language. Use these references to replace vague terms with concrete descriptors.

## Atmosphere Keywords

serene, contemplative, ethereal, intimate, bold, sophisticated, melancholic, uplifting, mysterious, tranquil, whimsical, elegant, cozy, minimalist, dramatic, nostalgic, energetic
