# B站·视频下载（bilibili-download）

> 一句话定位：把 B站 的视频、番剧、合集或收藏夹下载到本地，自动拉流并用 ffmpeg 合流，可自定义清晰度、音质、输出格式与选集范围。

## 能力

- **下载单个视频**：按 BV 号或普通 bilibili.com 视频链接下载
- **批量下载**：番剧、合集、多 P 视频一键下全集（`batch=true`）
- **指定清晰度 / 音质**：从 360P 到 8K 多档可选，音质从 64kbps 到 Hi-Res
- **仅音频 / 仅视频**：可只保留单轨（二者互斥），实现「B站转 MP3」等需求
- **输出格式**：`infer`（默认自动推断）/ mp4 / mkv / mov
- **附加选项**：弹幕、字幕、nfo 元数据、封面随视频一起保存
- 适合个人学习与备份用途

## 触发方式（自然语言示例）

- 「把这条 B站 视频下载下来，存到本地」
- 「下载这个 BV 号的 1080P 版本」
- 「把这个 B站 番剧 / 合集全部下载」
- 「把这条 B站 视频转成音频，只要声音」

## 输入

| 参数 | 必需 | 说明 |
|------|------|------|
| url | 是 | B站 视频/番剧/合集链接，支持 `b23.tv` 短链 |
| dir | 否 | 输出目录，默认 `~/.dsh/downloads/bilibili` |
| quality | 否 | 清晰度：数字码或名称（见下表），默认跟随登录态可用最高档 |
| audioQuality | 否 | 音质：数字码或名称 |
| outputFormat | 否 | `infer`（默认）/ `mp4` / `mkv` / `mov` |
| batch | 否 | 番剧/合集/多 P 批量时传 `true` |
| episodes | 否 | 选集范围，如 `1~-1`（全部）、`1,3,5`、`2~6` |
| videoOnly / audioOnly | 否 | 只保留单轨，二者互斥 |
| noDanmaku / noSubtitle | 否 | 不要弹幕 / 不要字幕 |
| withMetadata / saveCover | 否 | 附带 nfo 元数据 / 保存封面 |

**清晰度档位：** 8K=127、4K=120、1080P60=116、1080P=80、720P60=74、720P=64、480P=32、360P=16

**音质档位：** Hi-Res=30251、320kbps=30280、128kbps=30232、64kbps=30216

## 限制与边界

- **不做数据采集**（详情/搜索/排行/评论）→ 用 `bilibili-crawl`
- **不做内容发布**（投稿）→ 用 `bilibili-publish`
- **弹幕只下载不做加工**：默认带下载，但不做「弹幕转字幕」等后处理
- **权限边界**：只能下载当前账号有权访问的内容，大会员专享 / 付费内容需对应用户权限
- **高清与登录态**：1080P 及以上通常需登录态；未绑定账号只能拿到低清
- **本地依赖**：需要本机已安装 `yutto`（CLI）与 `ffmpeg`（用于 DASH 音视频合流）；大文件不走代理网关，由本机工具直接调 yutto
- **时长/体积**：下载耗时取决于大小与清晰度，工具总超时 **30 分钟**，超时可能产出不完整文件
- **频控**：建议控制并发与频率，避免触发 B站 风控
- 仅限个人学习与备份，不得二次分发或商用

## 账号绑定

- 绑定 **bilibili** 平台账号，登录态由下载工具从其凭证库注入
- **需要登录态**：主要用于拿到高清（1080P+）清晰度；不登录也可下载，但只能得到低清
- 账号凭证内联传给 `yutto --auth`，日志与返回值均已脱敏，技能不接触 Cookie

## 输出

- 成功后返回**本次实际产出的新文件绝对路径列表**（按下载前后目录快照差集计算）
- 涉及批量/选集时多个文件一并返回
- 失败时返回 `failureKind` 与提示；超时中断会带回已产出的不完整文件路径

## 错误处理速查

| 常见失败 | 处理动作 |
|---------|---------|
| 未绑定 B站 账号（`not_bound`） | 到「账号连接」页面扫码登录 B站（否则只能低清） |
| 多账号未选（`need_account_choice`） | 把候选账号列表给用户选，选定后填入 `account` 重试，不要自己挑 |
| 登录态失效 / 401 / 403（`token_expired`） | 到「账号连接」页面重新登录 B站 |
| 风控 / `-352` / 请求频繁（`risk_control`） | 稍后重试、降低频率，必要时先在浏览器正常浏览 B站 |
| URL 不含 bilibili.com / b23.tv | 让用户确认链接；短链 `b23.tv` 是支持的 |
| 找不到 yutto（`api_error`） | 安装：`uv tool install yutto`（需 Python 3.11+ 与 FFmpeg） |
| 清晰度 / 音质不识 | 按返回值中的可用取值列表重新指定 |
| videoOnly 与 audioOnly 同时为 true | 二者只能选其一 |
| 下载超时（30 分钟） | 告知已产出的不完整文件，建议改低清晰度或缩小选集后重试 |

## 相关技能

- 上下游：`bilibili-publish`（投稿内容）、`bilibili-crawl`（获取视频/合集清单供选择下载）
- 同类：本技能是 B站 特有的下载能力，暂无跨平台对应下载技能
