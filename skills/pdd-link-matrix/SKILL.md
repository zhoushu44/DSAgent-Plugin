# 拼多多多链接矩阵

一个款 → N 条差异化链接。每条链接产出：**3 张主图**（3:4 长图 / 1:1 方图 / 白底图）+ **8 屏详情页** + 详情长图。

## 何时使用

- 用户说「一个款铺 N 条链接」「主图分裂」「批量主图 + 详情页」→ 本技能
- 用户给一批关键词，要求每个关键词配一套主图与详情页 → 本技能

## 边界

- **不发布**。本技能只产图，发布请用 `pdd-publish-2`
- **不改商品事实**。面料、成分、尺码、安全等级等数据全部逐条取自 `assets/product.json`（来自供应商商品页原字段），脚本不会改写、不会推断
- **不写极限词**。文案模板库已排除「最」「第一」「100%」等《广告法》禁用词
- 供应商侧的 B2B 数据（销量、好评率、评价数、回购率）**一律不写入 C 端页面**
- 换款需要重新抓取该款的 SKU / 属性 / 素材并更新 `assets/`

## 执行流程

```bash
python3 {baseDir}/scripts/run.py --keywords "儿童睡衣,儿童家居服" --count 2 --index 1
```

参数：

| 参数 | 说明 |
|---|---|
| `--keywords` | 关键词列表，逗号/换行分隔。留空则用内置词池（24 个，来自生意参谋且与实物一致） |
| `--count` | 要生成的链接总数 |
| `--index` | 生成第几条（batch 模式由工作流传入轮次）；`0` = 一次生成全部 |
| `--out` | 输出目录，默认 `./pdd-matrix-output` |
| `--dry-run` | 不调用 AI，用参考图占位跑通矩阵与合成（用于测试链路） |
| `--model` | 生图模型，默认 `gpt-image-2.5` |

脚本自动完成：按 index 分配「颜色 × 场景 × 机位 × 模特 × 文案」→ 压缩参考图（≤40KB）→ 调生图 API 出 2 张底图（主图 + 场景）→ 代码合成 3 张主图与 8 屏详情页 → 拼接长图。

## 生图 API 配置

优先级：命令行 `--api-base/--api-key` → 环境变量 `IMG_API_BASE` / `IMG_API_KEY` → `~/.dsagent/pdd-matrix.json`（`{"api_base":"...","api_key":"..."}`）。

未配置时脚本返回 `failure_kind: skill_error` 并说明如何配置。

## 规格（拼多多）

主图 1:1 ≥750×750、服装建议 750×1000、单张 ≤3MB；详情图宽 750px、单图高 ≤1500px、单张 ≤3MB、≤20 张；白底图纯白无模特无文字、主体占比 ≥70%。

> 拼多多的像素规格不在技能资料库内，以上按公开规范交叉核对。**上架前请在商家后台发布页再确认一次。**

## 执行约束（重要）

工作流引擎对单次技能执行有 **5 分钟硬超时**，且 **60 秒无输出会被看门狗终止**。因此：

- 必须走 **batch 模式、一轮生成 1 条链接**（一轮约 100 秒：2 张生图 + 合成）
- 不要把 `--count 50` 和 `--index 0` 一起用 —— 那是一次跑 50 条，必定被超时杀掉
- 脚本持续向 stderr 打进度与心跳，避免被误判为空转

## 风险提示（必须向用户说明）

同一款铺多条链接，平台按**重复铺货**管理，拼多多与淘宝规则均有明确条款，判定成立会下架或降权。本技能把差异化做到**视觉主体层面**（不同颜色/场景/机位/模特/文案），抗判定能力强于「同图改字」，但**不构成合规豁免**。建议同时提醒用户：每条链接的标题需按对应关键词单独撰写，且优先集中投放高供需比的关键词而非全部平推。
