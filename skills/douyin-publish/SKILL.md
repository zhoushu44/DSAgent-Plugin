# 抖音内容发布

> **重要:** 发布是**不可撤销的真实操作（L2）**。必须两步走：先拿「发布预览」给用户看，用户**明确同意**后才真正提交。
> 绝不要在一次调用里直接传 `confirm=true`。

## 何时使用

- 用户说"把这段视频发到抖音"、"发布抖音作品"、"投稿到抖音" → 发布视频
- 用户给出本地视频文件路径 + 标题（可选描述），要求发到抖音 → 发布视频
- 用户说"帮我发抖音"、"上传视频到抖音账号" → 发布视频

## 边界

- **不做数据采集** —— 采集作品列表 / 视频详情 / 搜索 / 热搜请用 `douyin-crawl`
- **不做评论互动、私信、数据分析** —— 对应技能尚未实现
- **不生成文案** —— 标题与描述由用户提供（或先用通用文案技能生成，再回到本技能发布）
- **只支持视频投稿** —— 图文（多图）投稿、定时发布、封面自定义、合集/位置选择当前不支持
- 视频文件必须是**本机绝对路径**且真实存在；技能不做下载，用户需先备好文件
- 标题**限 30 字**、描述**限 1000 字**，超限会在调用前被拦下
- 发布过程会**弹出可见浏览器窗口**（真实操作，用户可见）；若出现滑块/安全验证需人工完成
- 同一时间只能有一个抖音发布窗口；已有窗口进行中时需等待其结束

## 执行流程

本技能**没有脚本入口**，执行方式是**直接调用 host 工具** `dsagent_douyin_publish`。

### 1. 收集参数

从用户话里提取三项，缺项就主动问：

| 参数 | 必需 | 说明 |
|------|------|------|
| `videoPath` | 是 | 本地视频文件的**绝对路径**（如 `D:\videos\demo.mp4`） |
| `title` | 是 | 作品标题，**≤ 30 字** |
| `description` | 否 | 作品描述/文案，可含 `#话题`，**≤ 1000 字** |

### 2. 先取「发布预览」（不带 confirm）

调用 `dsagent_douyin_publish`，**只传 `videoPath` / `title` / `description`，不要传 `confirm`**：

```
dsagent_douyin_publish(videoPath="D:\videos\demo.mp4", title="今天分享一个技巧", description="干货满满 #运营")
```

工具此时**不会启动浏览器、不产生任何写操作**，只返回一段「发布预览」文本（含账号、视频路径、标题、描述）。

### 3. 把预览完整展示给用户并征求明确同意

把预览内容原样呈现给用户，并明确问一句类似"确认要发布吗？"。
**这一步不可跳过、不可自行假设用户同意**（L2 风险门禁）。

### 4. 用户同意后带 `confirm=true` 重新调用

```
dsagent_douyin_publish(videoPath="D:\videos\demo.mp4", title="今天分享一个技巧", description="干货满满 #运营", confirm=true)
```

工具会弹出可见浏览器窗口，依次完成：注入登录态 → 打开投稿页 → 上传视频 → 等编辑页 → 关引导弹窗 → 填标题 → 填描述 → 点「发布」→ 判定结果。

### 5. 报告结果

- 成功：告知已提交，并说明**平台可能仍在审核**，最终状态以抖音创作服务平台「作品管理」为准
- 失败：按返回的 `failureKind` 走下方「错误处理」

## 错误处理

| 场景 | failureKind | 引导动作 |
|------|-------------|---------|
| 未绑定抖音账号 | `not_bound` | 引导用户到「账号连接」页面扫码登录抖音账号 |
| 平台有多个可用账号且当前会话未绑定 | `need_account_choice` | **把候选列表给用户选**，把选定的 `shopKey` 填进 `account` 参数重调；★ 绝不要自己挑一个 |
| 投稿页被重定向到登录页 | `token_expired` | 引导用户到「账号连接」页面**重新登录**抖音 |
| 视频文件不存在 / 标题超 30 字 / 描述超 1000 字 | `api_error` | 按提示修正参数后重试 |
| 上传后未跳转编辑页 | `api_error` | 可能是视频格式不支持或上传被风控；让用户确认格式（建议 mp4），必要时重试 |
| 找不到标题框 / 描述区 / 发布按钮 | `api_error` | 页面结构可能变更，请上报该问题 |
| 点击发布后未检测到成功标志 | `api_error` | 让用户查看弹出的浏览器窗口内的具体提示；若有滑块需人工完成 |

## 环境变量

本技能为纯指令型，不执行脚本，无环境变量依赖。
账号凭证由 host 工具从凭证库直接读取，**技能侧不接触 Cookie**。
