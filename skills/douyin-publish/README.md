# 抖音·内容发布（douyin-publish）

> 一句话定位：把本机视频文件投稿到抖音，自动上传视频、填写标题与描述并提交发布，属于**真实、不可撤销的发布操作**。

## 能力

- 把本地视频文件上传到抖音并发布为作品
- 自动填写标题与作品描述/文案（可带 `#话题`）
- 支持完整预览确认流程（见下）
- 同一时间仅支持一个发布窗口，窗口进行中需等待其结束

## 触发方式（自然语言示例）

- 「把这段视频发到抖音」
- 「发布抖音作品，标题是 xxx，描述是 xxxx」
- 「帮我发抖音，上传这个视频文件」
- 「投稿到抖音账号」

## 输入

| 参数 | 必需 | 说明 |
|------|------|------|
| videoPath | 是 | 本地视频文件的**绝对路径**（如 `D:\videos\demo.mp4`），须真实存在 |
| title | 是 | 作品标题，**≤ 30 字** |
| description | 否 | 作品描述/文案，可含 `#话题`，**≤ 1000 字** |

**发布是 L2 真实操作，必须两步走：**
1. 第一次调用**不带 confirm**，工具只返回「发布预览」文本（含账号、视频路径、标题、描述），不启动浏览器、不产生任何写操作；
2. 把预览原样展示给用户并询问「确认要发布吗？」（或其他等效确认），得到**明确同意**后，第二次调用**带 `confirm=true`** 才真正提交发布。严禁在不确认的情况下直接提交。

## 限制与边界

- **不做数据采集**（作品/详情/搜索/热搜）→ 用 `douyin-crawl`
- **不做评论互动、私信、数据分析**（对应技能未实现）
- **不生成文案**：标题与描述由用户提供，或先用文案技能生成再回来发布
- **只支持视频投稿**：图文（多图）投稿、定时发布、封面自定义、合集/位置选择当前不支持
- 视频必须是本机绝对路径且真实存在；技能不做下载，需先备好文件
- 平台硬限制：标题 ≤ 30 字、描述 ≤ 1000 字，超限会被拦下
- 发布过程会**弹出可见浏览器窗口**（真实操作，用户全程可见）；若出现滑块/安全验证需人工完成

## 账号绑定

- 绑定 **douyin** 平台的发布账号，登录态由工具从其凭证库注入，技能不接触 Cookie
- **必须要有登录态**：未绑定 / 登录态失效都会被引导去「账号连接」页面重新登录
- 若平台有多账号未选，会把候选列表交给你选择，选定后填入 `account`，不会自行挑选

## 输出

- 预览阶段：返回一段发布预览文本供确认
- 提交成功：告知已提交，并提示**平台可能仍在审核**，最终状态以抖音创作服务平台「作品管理」为准
- 失败：返回 `failureKind` 与引导动作，按错误速查处理

## 错误处理速查

| 常见失败 | 处理动作 |
|---------|---------|
| 未绑定抖音账号（`not_bound`） | 到「账号连接」页面扫码登录抖音 |
| 多账号未选（`need_account_choice`） | 把候选账号给用户选，选定填入 `account` 重试 |
| 投稿页被重定向到登录页（`token_expired`） | 去「账号连接」重新登录抖音 |
| 文件不存在 / 标题超 30 字 / 描述超 1000 字 | 修正参数后重试 |
| 上传后未跳转编辑页 | 可能是格式不支持或被风控；确认格式（建议 mp4），必要时重试 |
| 找不到标题框 / 描述区 / 发布按钮 | 页面结构可能变更，上报该问题 |
| 点击发布后未检测到成功标志 | 查看弹出浏览器窗口内的提示；若有滑块需人工完成 |
