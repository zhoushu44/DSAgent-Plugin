# 抖音·数据采集（douyin-crawl）

> 一句话定位：采集抖音的作品、账号、搜索、热搜、话题与相关推荐数据，供你做数据分析参考，所有操作只读、不改动任何内容。

## 能力

- **作品列表**：当前登录账号发布的作品列表
- **视频详情**：按视频 ID（aweme_id）取单条视频的完整信息（文案、时长、点赞/评论/分享/收藏/播放等）
- **关键词搜索**：按关键词搜视频；按关键词搜用户 / 搜话题
- **热搜榜**：抖音热搜 / 热点榜
- **喜欢列表**：当前账号点赞（喜欢）过的视频
- **账号资料**：当前登录账号昵称、粉丝数等
- **话题数据**：某话题的详情（累计播放、参与人数）以及该话题下的作品/爆款
- **相关推荐**：某条视频的同题材爆款推荐
- 结果以归一化字段返回，便于直接阅读或进一步分析

## 触发方式（自然语言示例）

- 「采集我的抖音作品 / 看看我抖音发了什么」
- 「帮我分析这个抖音视频的数据」
- 「搜一下抖音上的 xxx」
- 「抖音热搜有什么 / 这个 #话题 的数据怎么样」

## 输入

| 参数 | 必需 | 说明 |
|------|------|------|
| mode | 是 | 采集模式：`user` / `detail` / `search` / `user-search` / `hot` / `favorite` / `profile` / `topic` / `topic-search` / `related`；不传时按参数自动判定 |
| aweme-id | 视模式而定 | 视频 ID，用于 `detail` / `related` |
| keyword | 视模式而定 | 关键词，用于 `search` / `user-search` / `topic`（话题名）/ `topic-search` |
| ch-id | 否 | 话题 ID，用于 `topic` 模式（已知时可省一次解析请求） |
| count | 否 | 每页数量，单次采集 ≤ 50 条 |
| offset / cursor / max-cursor | 否 | 翻页游标；新开查询从 0 开始 |

> 约定：不传 `--mode` 时按 aweme-id、keyword、请求文本中「热榜/热搜/热门」「我的/自己/本人」等关键词自动判断模式。

## 限制与边界

- **不采集评论**：抖音评论接口需 `a_bogus` 签名，当前链路不可用
- **不采集合集作品、关注/粉丝列表**：前者需签名，后两者抖音已下线该接口
- **不做批量爬取**：单次上限约 50 条，超出需翻页多次调用
- **不做内容发布、点赞、关注**，纯只读采集
- **平台硬限制**：搜索类接口风控较严，可能返回 `verify_check`，需你先去抖音完成安全验证后重试
- Cookie 失效需重新登录；请求间隔建议 ≥ 6 秒避免触发风控
- 采集结果仅供数据分析参考，不得用于商业用途

## 账号绑定

- 绑定 **douyin** 平台账号（当前登录会话对应的发布/浏览账号）
- 登录态由本地代理网关自动注入 Cookie，技能不接触 Cookie
- **必须要有登录态**：作品列表、喜欢列表、账号资料等依赖登录（凭证库的 `account_id` 是派生哈希值，不能当真实 `sec_uid` 用，脚本会自行解析真实身份）

## 输出

- 通过标准输出返回一份 JSON，核心字段如下：
  - `ok`：是否成功
  - `mode`：本次执行的采集模式
  - `account`：当前账号昵称与 uid / sec_uid
  - `total` / `has_more` / `max_cursor`：总量、是否还有更多、翻页游标
  - `data`：数据列表
- 作品/详情/搜索/喜欢/话题作品/相关推荐的数据项字段：`aweme_id`、`desc`、`create_time`、`duration_ms`、`author_nick`、`author_uid`、`author_sec_uid`、`digg_count`、`comment_count`、`share_count`、`collect_count`、`play_count`、`video_url`（无水印）、`cover_url`、`share_url`
- `detail` 额外含 `music_title`、`text_extra`；热搜榜、用户搜索、话题各有对应字段
- `user` / `favorite` / `topic` 支持翻页（沿用返回的游标）；`related` 一次性返回、不支持翻页

## 错误处理速查

| 常见失败 | 处理动作 |
|---------|---------|
| 网关地址未设置（`not_bound`） | 到「账号连接」页面扫码绑定抖音账号 |
| 拿不到账号真实身份（sec_uid 为空） | 抖音登录态可能失效，需重新登录 |
| 搜索返回 `verify_check`（风控） | 去抖音完成安全验证后重试，勿当 0 条结果 |
| 接口返回非 0 `status_code` | 按提示处理，如 `status_code=5` 表示参数不合法 |
| 响应解析失败（`parse_error`） | 展示原始返回供排查 |
| 结果为空（非风控） | 正常返回空列表，非异常 |
