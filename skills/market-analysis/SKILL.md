## 直接使用

用户最常见的说法可以这样理解：

- `帮我看看手机的趋势`
  等于直接分析“手机”，用综合排序，不限制发货地。
- `分析耳机市场`
  等于分析“耳机”的搜索结果，并自动生成结果表和网页报告。
- `查下女装在浙江发货的情况`
  等于分析“女装”，同时把发货地限制在“浙江”。

## 可选条件怎么说

如果用户想加条件，尽量用自然语言去理解，不要先甩参数名给用户。

  支持的说法包括：`综合排序`、`销量排序`、`信用排序`、`价格从低到高`、`价格从高到低`
  例如：
  `按综合排序看看手机壳`
  `按销量排序看看耳机市场`
  `按信用排序看看女装`

- 想看发货地：
  可以说 `帮我看浙江发货的女装`
- 想设置最低价格：
  可以说 `帮我看 100 元以上的手机壳`
- 想设置最高价格：

- 想限制价格区间：

**当市场分析成功完成后**，Agent 应主动追问，引导用户进入关键词分析环节：

用户同意后，调用「关键词分析助手」Skill：
```bash
cd "{keyword_assistant_dir}" && python -m keyword_assistant "{关键词}"
```

**追问规则：**
- 从市场分析结果的 `keyword` 字段提取搜索词作为种子词
- 如果市场分析的 `analysis.high_frequency_terms` 中有高频标题词，可推荐作为额外种子词
- 追问仅一次，用户拒绝后不再重复
- 关键词分析完成后，该 Skill 会继续引导用户查看 13 个月流量趋势（完整链路：市场分析 → 关键词助手 → 流量解析）
