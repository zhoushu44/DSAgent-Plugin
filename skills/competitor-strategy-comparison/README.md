# 竞品策略对比分析（competitor-strategy-comparison）

> 一句话定位：结合生意参谋 / 达摩盘登录态，以本店商品的叶子类目为入口精确对比一个竞品的经营数据，输出包含经营结论、完整数据表和调整建议的 HTML 报告，交付时隐藏全部技术细节。

## 能力

- **精确竞品对比**（`analyze`）：以“本店商品 ID + 竞品商品 ID + 时间周期”为核心，先定位本品叶子类目，再校验竞品属于同一叶子类目后拉取对比数据。
- **三类业务数据**：核心经营指标（浏览量、付费 / 免费点击量、成交订单数、支付转化率、单价、成交金额、加购率）、人群经营对比、推广策略（渠道、方案、计划、TOP 关键词）。
- **原子子命令**：`overall`（核心经营指标）、`flow`（推广渠道 / 计划 / 关键词）、`audience`（人群经营）、`report`（生成 HTML）、`history`（查历史产物）。
- **HTML 报告**：九章节固定结构（对比对象与周期、经营结论、核心经营数据、流量与成交诊断、人群经营、推广渠道、投放计划明细、双方 TOP 关键词、调整建议），蓝白配色，本品蓝 / 竞品橙。
- **清单辅助**：`list-products` 仅在本店商品 ID 未知且用户要求时辅助选本品。

## 触发方式（自然语言示例）

- “用本店商品 123 对比竞品 456，查看最近 30 天”
- “帮我做一份竞品策略对比分析报告”
- “对比一下这个竞品的推广策略和人群”

## 输入

| 参数 | 必需 | 说明 |
|------|------|------|
| 本店商品 ID（`--item-id`） | 是 | 用于读取本品信息并确定叶子类目 |
| 竞品商品 ID（`--competitor-id`） | 是 | 用户精确指定的竞品，须与本品同叶子类目，否则无法对比 |
| 时间周期（`--start-date` / `--end-date`） | 是 | `YYYY-MM-DD`；相对周期（最近 N 天）默认截至昨天，不包含今天 |

## 限制与边界

- **竞品必须与本品同叶子类目**，否则达摩盘无法完成对比查询；未命中时提示核对类目，不换用相似商品。
- 不打开、导航或展示 DMP 页面；不返回竞品候选列表。
- 不调用成功品配置接口，不调用 DMP AI workflow，不接受 cookie / token / CSRF 作命令行参数。
- “无数据”不解释为“竞品没有投放”，不作跨周期外推。
- 正常交付**隐藏所有程序字段 / 接口信息 / 文件路径**，只用业务口径展示。

## 账号绑定

- 使用当前智能体已绑定的 **sycm（生意参谋 / 达摩盘）** 店铺会话；cookie / token / CSRF 由 Connect Gateway 携带，不读写、不持久化凭证。

## 输出

- **stdout**：UTF-8 JSON，取数命令含 `artifact_path`（内部完整数据）与 `report_path`（业务版 Markdown）。
- **业务 Markdown**：`analyze` 将核心指标、人群、推广渠道、计划和关键词表格化写入 `{workspace}/artifacts/`。
- **HTML 报告**：`report --input <artifact_path>` 生成；成功时 JSON 含 `html_path`，stderr 尾行 `[OUTPUT_FILES] HTML: ...`，在浏览器打开作为正式交付物。
- **报告流程**：`analyze`（JSON + 业务 Markdown）→ 写 AI 洞察（`artifacts/竞品策略洞察.md`）→ `report` 生成 HTML；最终只交付 3–5 条核心摘要 + HTML 报告，不附内部 JSON / Markdown / 程序字段。
- **关键指标业务名称**：IPV→浏览量、营销推广点击量→付费点击量、自然点击量→免费点击量、成交笔数→成交订单数、笔单价→单价、额外新增“成交金额”（按成交订单数 × 单价计算）。

## 错误处理速查

| 常见失败 | 处理动作 |
|----------|----------|
| 竞品未命中 | 提示竞品可能与本品不同叶子类目或不在可对比商品池，核对类目后重给 ID |
| 缺 AI 洞察文件 / 章节 | 按 `insights_pending` 提示路径补写后重新 `report` |
| 模块数据缺失 | 保留其他成功模块，用业务语言说明缺失原因，不编造结论 |
| 目标字段缺失 | 按“本周期无法计算 / 未返回可确认的投放方案（或关键词）”说明，不取中点估算 |
