# 淘宝 / 天猫 商品发布

> **重要:** 发布是**不可撤销的真实操作（L2）**。必须两步走：先拿「发布预览」给用户看，用户**明确同意**后才真正提交。
> 绝不要在一次调用里直接传 `confirm=true`。

## 何时使用

- 用户说"帮我把这个发到淘宝"、"淘宝上架"、"上架宝贝"、"上传宝贝" → 发布商品到淘宝
- 用户说"发到天猫"、"天猫上架"、"天猫发布商品" → 发布商品到天猫（`channel="tmall"`）
- 用户给出本地图片路径 + 标题（可选价格/库存/货号），要求发布到淘宝或天猫 → 发布商品

## 边界

- **不做商品采集与比价** → 用 `taobao-crawl` 系技能
- **不做生意参谋数据分析** → 用 sycm 系技能
- **不做闲鱼发布** → 用 `xianyu-publish`（闲鱼需独立的 goofish 会话）
- **不生成文案** → 标题与价格由用户提供（或先用通用文案技能生成，再回到本技能发布）
- **不做批量发布、定时发布、批量上下架** —— 当前只支持**单件**商品发布
- ★ **只自动填通用字段**：主图、标题、一口价、库存、货号。
  **类目属性、商品详情、发货与售后设置不会自动填写**，需要在弹出的浏览器窗口内由用户人工补全。
- ★ **发布第一步是「选择类目」**：页面可能停在选择类目页，这是正常流程，需要用户在窗口内选好类目后才会进入正式表单
- 图片必须是**本机绝对路径**且真实存在，**1~5 张**，单张 **≤ 3MB**（超出请先压缩）
- 标题**必填**且**不超过 60 个字符**（淘宝/天猫的硬性限制）
- 一口价（可选）为正数、1 亿元以内；库存（可选）为非负整数
- 发布过程会**弹出可见浏览器窗口**（真实操作，用户可见）；若出现滑块/安全验证需人工完成
- 同一时间只能有一个淘宝浏览器任务；已有任务进行中时需等待其结束
- ★ **淘宝与天猫共用同一套淘宝登录态**：账号连接页只需连接**淘宝**账号，无需也无法单独登录天猫

## 执行流程

本技能**没有脚本入口**，执行方式是**直接调用 host 工具** `dsagent_taobao_publish`。

> 为什么不是 Python 脚本：发布的核心动作是**图片 multipart 上传（二进制）**与页面运行时生成的 `sign` 签名，
> 本地代理网关不支持 multipart，纯 HTTP 请求无法复刻；且开放平台 TOP 的 `alibaba.item.publish.*`
> 只对**天猫/企业店的自研应用**开放，集市店无法申请。
> 因此由 host 工具用 puppeteer 驱动网页版发布页（淘宝 `item.upload.taobao.com`、天猫 `sell.publish.tmall.com`）完成填写与提交。

### 1. 收集参数

从用户话里提取，缺项就主动问：

| 参数 | 必需 | 说明 |
|------|------|------|
| `images` | 是 | 本地图片文件**绝对路径**，1~5 张，单张 ≤ 3MB。多张用英文逗号分隔，或传 JSON 数组字符串 |
| `title` | 是 | 商品标题，**不超过 60 个字符** |
| `channel` | 否 | 发布渠道：`taobao`（淘宝，默认）/ `tmall`（天猫） |
| `price` | 否 | 一口价（元，字符串数字），正数、1 亿元以内 |
| `stock` | 否 | 库存（件，字符串数字），非负整数 |
| `itemNo` | 否 | 商家编码/货号（天猫发布页有独立输入框） |

### 2. 先取「发布预览」（不带 confirm）

调用 `dsagent_taobao_publish`，**只传业务参数，不要传 `confirm`**：

```
dsagent_taobao_publish(images="D:\imgs\1.jpg,D:\imgs\2.jpg", title="纯棉短袖T恤 男 夏季新款", price="79", stock="100")
```

工具此时**不会启动浏览器、不产生任何写操作**，只返回一段「发布预览」文本（含渠道、账号、标题、一口价、库存、货号、主图）。

### 3. 把预览完整展示给用户并征求明确同意

把预览内容原样呈现给用户，并明确问一句类似"确认要发布吗？"。
同时**必须提醒用户**：类目属性、商品详情、发货与售后设置不会被自动填写，稍后需要在弹出的浏览器窗口内人工补全。

**这一步不可跳过、不可自行假设用户同意**（L2 风险门禁）。

### 4. 用户同意后带 `confirm=true` 重新调用

```
dsagent_taobao_publish(images="D:\imgs\1.jpg,D:\imgs\2.jpg", title="纯棉短袖T恤 男 夏季新款", price="79", stock="100", confirm=true)
```

工具会弹出可见浏览器窗口，依次完成：注入登录态 → 打开发布页 → 等表单就绪（中间可能需用户**选类目**）→ 上传主图 → 填标题/一口价/库存/货号 → 点「提交宝贝信息」→ 判定结果。

### 5. 报告结果

- 成功：告知已提交发布、商品 ID（若页面返回），并说明**平台仍会审核**，最终状态以千牛/卖家中心「出售中的宝贝」为准；
  同时明确列出**未自动填写的字段**，提醒用户核对
- 失败：按返回的 `failureKind` 走下方「错误处理」

## 错误处理

| 场景 | failureKind | 引导动作 |
|------|-------------|---------|
| 未绑定淘宝账号 | `not_bound` | 引导用户到「账号连接」页面添加**淘宝**账号（登录淘宝后天猫即可用，无需单独登录天猫） |
| 平台有多个可用账号且当前会话未绑定 | `need_account_choice` | **把候选列表给用户选**，把选定的 `shopKey` 填进 `account` 参数重调；★ 绝不要自己挑一个 |
| 发布页未登录 / 登录态失效 | `token_expired` | 引导用户到「账号连接」页面**重新登录淘宝**账号 |
| 命中 baxia 滑块 / 安全验证 | `risk_control` | 调用 `dsagent_risk_verify`（platform=taobao，可带返回的 verifyUrl）拉起验证页，用户完成滑块后在窗口内重新提交 |
| 图片不存在 / 超过 3MB / 超过 5 张 | `api_error` | 按提示修正图片路径或压缩后重试 |
| 标题为空 / 超过 60 字符 / 价格或库存越界 | `api_error` | 按提示修正参数后重试 |
| 页面长时间停在「选择类目」 | `api_error` | ★ 让用户在窗口内**选好类目**；选完类目才会进入正式表单 |
| 提交后提示类目属性 / 详情未填 | `api_error` | ★ **类目属性与商品详情不由本工具自动填写**，让用户在窗口内补全后手动点「提交宝贝信息」 |
| 主图上传控件未找到 / 上传失败 | `api_error` | 让用户在浏览器窗口内人工上传主图（图片格式建议 jpg/png） |
| 提交后未检测到成功标志 | `api_error` | 让用户查看弹出的浏览器窗口内的具体提示；补全必填项后手动提交；若有滑块需人工完成 |
| 已有淘宝浏览器任务在进行中 | `api_error` | 提示先等待或关闭已弹出的浏览器窗口 |
| 未找到 Chrome / Edge | `api_error` | 提示用户安装 Chrome 或 Edge |

## 环境变量

本技能为纯指令型，不执行脚本，无环境变量依赖。
账号凭证由 host 工具从凭证库读取并**在浏览器内注入 Cookie**，日志与返回值均已脱敏，**技能侧不接触 Cookie**。
