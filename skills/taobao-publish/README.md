# 淘宝 / 天猫·商品发布（taobao-publish）

> 一句话定位：把本地图片与商品信息发布为淘宝或天猫商品，自动填主图、标题、一口价、库存、货号并提交，用于「上架宝贝 / 铺货到淘宝」。

## 能力

- 发布为**淘宝**商品（默认）或**天猫**商品（`channel="tmall"`）。
- 自动上传**主图**并填通用字段：**标题 / 一口价 / 库存 / 货号**。
- 只支持**单件**发布，不做批量 / 定时发布 / 批量上下架。

**不做的事**：不采集比价、不做生意参谋数据分析、不发闲鱼、不生成文案（标题与价格需用户提供）。另外**只会自动填通用字段**，类目属性、商品详情、发货与售后设置**不会自动填**。

## 触发方式（自然语言示例）

- 「帮我把这个发到淘宝」「淘宝上架」「上架宝贝」「上传宝贝」 → 发布淘宝商品
- 「发到天猫」「天猫上架」「天猫发布商品」 → 发布天猫商品
- 直接给图片路径 + 标题（可带价格 / 库存 / 货号） → 发布商品

## ⚠️ 发布是真实操作（L2），两步式

发布是**不可撤销**的真实操作，必须走两步：**先由工具给出「发布预览」给你确认，明确同意后才真正提交浏览器上架**。预览阶段的返回不是报错。

- **不会自动填的字段**（需你在随后弹出的浏览器窗口中人工补全）：**类目属性、商品详情、发货与售后设置**。
- **发布第一步是「选类目」**：页面可能停在选择类目页，这属正常流程，需你在窗口内选好类目后才会进入正式表单。

## 输入

| 参数 | 必需 | 说明 |
|------|------|------|
| `images` | 是 | 本地图片**绝对路径**，1~5 张、单张 ≤ 3MB；多张用英文逗号分隔或传 JSON 数组字符串 |
| `title` | 是 | 商品标题，**不超过 60 个字符**（淘宝/天猫硬性限制） |
| `channel` | 否 | 发布渠道：`taobao`（淘宝，默认）/ `tmall`（天猫） |
| `price` | 否 | 一口价（元），正数、1 亿元以内 |
| `stock` | 否 | 库存（件），非负整数 |
| `itemNo` | 否 | 商家编码 / 货号（天猫发布页有独立输入框） |

## 平台硬限制

- 主图 1~5 张、单张 ≤ 3MB（主图建议 jpg/png）。
- 标题必填、≤ 60 个字符。
- 一口价正数、1 亿元以内；库存非负整数。
- 发布会弹出可见浏览器窗口；可能出现 baixa 滑块 / 安全验证，需人工完成（必要时通过验证流程拉起验证页）。
- 同一时间只能有一个淘宝浏览器任务。

## 账号绑定

- 绑定**淘宝**账号（登录淘宝后天猫即可用，**无需也无需单独登录天猫**）。
- 淘宝与天猫共用同一套淘宝登录态。

## 输出

- 成功：告知已提交发布、商品 ID（若页面返回），并说明平台仍会审核，最终以千牛 / 卖家中心「出售中的宝贝」为准；同时列出**未自动填写的字段**提醒核对。
- 预览：返回发布预览文本（含渠道 / 账号 / 标题 / 一口价 / 库存 / 货号 / 主图），等你确认。
- 失败：带 `failureKind`，按下方速查处理。

## 错误处理速查

| 常见失败 | 处理动作 |
|---------|---------|
| 未绑定淘宝账号（`not_bound`） | 引导到「账号连接」添加淘宝账号（登录后天猫即可用） |
| 多账号未选（`need_account_choice`） | 候选清单给用户选，回传 `shopKey`，绝不自己挑 |
| 发布页未登录 / 登录失效（`token_expired`） | 重新登录淘宝账号 |
| 命中滑块 / 安全验证（`risk_control`） | 通过验证流程拉起验证页，完成滑块后在窗口内重新提交 |
| 图片不存在 / 超 3MB / 超 5 张 | 修正路径或压缩后重试 |
| 标题空 / 超 60 字符 / 价格库存越界 | 修正参数后重试 |
| 页面长时间停在「选择类目」 | 在窗口内选好类目，选完才进入正式表单 |
| 提示类目属性 / 详情未填 | **不由工具自动填**，在窗口内补全后手动点「提交宝贝信息」 |
| 主图上传控件未找到 / 上传失败 | 在窗口内人工上传主图（建议 jpg/png） |
| 提交后无成功标志 | 看窗口内红色校验项补全后手动提交 |
