# 小红书·数据采集（xiaohongshu-crawl）

> 一句话定位：在「小红书」平台按关键词搜索笔记、采集笔记数据，用于内容调研。

## 能力
- 关键词搜索笔记：按用户关键词调用小红书搜索接口，返回笔记 ID、标题、描述、作者、点赞数等。
- 支持翻页采集（`page` / `limit` 参数）。
- 采集内容仅供数据分析，不得用于商业用途。
- ⚠️ **当前受限**：现状实现仅开放**关键词搜索**能力；SKILL.md 中规划的「笔记详情」「评论采集」尚未提供对应脚本，属未实现能力。
- **不可做**：不发布内容、不互动、不采集商城/商品数据。

## 触发方式（自然语言示例）
- 「搜索小红书 手机壳」
- 「小红书搜 穿搭」
- 「采集小红书关键词 护肤」

## 输入
| 参数 | 必需 | 说明 |
|------|:----:|------|
| 搜索关键词 | 是 | 用户话里的关键词（无条件时从请求文本自动提取） |
| `page` | 否 | 页码，默认 1 |
| `limit` | 否 | 单页条数，默认 20 |

> 采集请求间隔 ≥ 3 秒。小红书风控等级最高（L3），频繁请求会迅速触发风控、导致 Cookie 失效，建议使用小号登录。

## 限制与边界
- **当前仅关键词搜索可用**，笔记详情与评论采集尚未实现（见「能力」）。
- 小红书接口强制要求 `x-s` / `x-t` / `x-s-common` 签名头，缺签名会返回「账号没有权限访问」；签名由技能内置模块自算，签名失败会以登录失效处理。
- 搜索接口只接受 POST + JSON body，用 GET 会直接 404（历史上「执行成功但 0 条」的坑）。
- 高频请求极易风控，注意节流与小号。
- 抖音/知乎等其它平台采集走对应平台技能。

## 账号绑定
- 绑定**小红书（xhs）**平台账号，Cookie 中的 `web_session` 是登录成功的关键凭证。
- 登录态有效期较短（约 1~3 天），过期后需重新登录。

## 输出
- 采集结果通过 stdout 输出 `__DSAGENT_RESULT__` 行，JSON 结构：
  ```
  { ok: true, keyword: "手机壳", total: 20,
    data: [ { note_id, title, desc, user, liked_count, type } ] }
  ```
- 搜索无结果显示 `{ ok: true, data: [], total: 0 }`（非错误）。

## 错误处理速查
| 常见失败 | 处理动作 |
|---------|---------|
| 未绑定小红书账号（`not_bound`） | 引导到「账号连接」扫码登录 |
| 签名失败 / 需 `a1` Cookie（`token_expired`） | 登录态异常，提示重新登录 |
| 业务错误 `code=-101` 或含「登录」 | 判定登录失效，重新登录 |
| 风控（`code=461/471` 或含「风控/验证」） | 提示去平台完成安全验证后重试，勿当 0 条 |
| 响应结构异常 / 空体 / HTML 挑战页（`parse_error`） | 可能是被风控或接口变更，展示原始返回 |
| 搜索无结果（非风控） | 按空结果返回 |

## 相关技能
- 发布笔记：`xiaohongshu-publish`
- 经营数据分析：`xiaohongshu-analytics`（当前未实现）
- 内容排版/文案生成：`smart-compose`
