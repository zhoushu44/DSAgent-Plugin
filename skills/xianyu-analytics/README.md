# 闲鱼·数据分析（xianyu-analytics）

> 一句话定位：统计自己闲鱼账号已发布商品的曝光、想要、收藏数据，输出账号概况、爆款排行与疑似滞销清单，辅助经营复盘与选品优化。

## 能力
- 账号概况：粉丝 / 关注 / 被赞等账号基础数据。
- 商品排行：按浏览数输出爆款 TOP、疑似滞销清单（零浏览零想要）。
- 全量明细：商品 ID / 标题 / 价格 / 浏览 / 想要 / 收藏 / 城市 / 链接。
- 模式可选：`overview`（默认，概况 + 排行）/ `items`（全量商品明细）。
- 只读操作，**不产生任何平台副作用**。
- **不可做**：采集/比价他人商品、发布/编辑/下架商品、订单/售后、客服消息均不在此技能。

## 触发方式（自然语言示例）
- 「分析一下我的闲鱼商品数据」
- 「哪些宝贝卖得好 / 哪些商品没人看」
- 「看看闲鱼曝光量 / 统计闲鱼商品表现」

## 输入
| 参数 | 必需 | 说明 |
|------|:----:|------|
| `mode` | 否 | `overview`（账号概况+爆款/滞销排行，默认）/ `items`（全量商品明细） |
| `limit` | 否 | 返回条数上限，默认 50，最大 100 |
| `account` | 否 | 指定账号 `shopKey`；多账号待选时回传用户选择 |

## 限制与边界
- 只统计**已发布在售/已下架的自有商品**，不含买家侧数据。
- 数据来源为闲鱼个人页展示口径（曝光/想要/收藏），**不是**平台后台完整漏斗，无成交金额与转化率——推测经营判断时需注意口径差异。
- 分析过程会**弹出可见浏览器窗口**；出现滑块/安全验证需人工完成。
- 同一时间只能有一个闲鱼分析窗口。
- ★ 账号必须为**闲鱼 APP 扫码登录**的真实 goofish 会话，淘宝 SSO 派生的账号在 goofish 域下无效。

## 账号绑定
- 绑定**闲鱼（xianyu）**平台账号，须为闲鱼 APP 扫码获取的真实 goofish 会话。

## 输出
- 返回结果含：
  - `profile`：账号概况（粉丝 / 关注 / 获赞）。
  - `overview` 模式：文本含「账号概况 + 爆款 TOP（按浏览数）+ 疑似滞销（零浏览零想要）」。
  - `items` 模式：结构化 `items` 数组（商品 ID / 标题 / 价格 / 浏览 / 想要 / 收藏 / 城市 / 链接）。
  - `sourceUrls`：本次实际命中的接口，排查「没有数据」时一并展示。
- 基于数据给出可执行建议（如滞销商品改标题、降价、重新擦亮等）。

## 错误处理速查
| 常见失败 | 处理动作 |
|---------|---------|
| 未绑定账号（`not_bound`） | 引导到「账号连接」添加闲鱼账号 |
| 多账号待选（`need_account_choice`） | 把候选列表给用户选，不要自行选择 |
| 接口 Session 过期（`token_expired`） | 删除并重新添加，用闲鱼 APP 扫码 `goofish.com/login`，不要走淘宝 SSO |
| 接口 403/429（`risk_control`） | 拉起验证页完成滑块后重试 |
| 拦截到接口但无商品字段（`parse_error`） | 人工完成验证后重试；若仍无数据可能是接口调整，反馈 `sourceUrls` |
| 账号下无在售商品 | 说明暂无已发布商品，无需分析 |
| 有分析窗口进行中 / 无浏览器 | 等待或关闭窗口 / 安装 Chrome 或 Edge |
