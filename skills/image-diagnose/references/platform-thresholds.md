# 各平台硬指标阈值

> **来源纪律**：所有数值必须标来源。来源只有三类：
> 1. **官方** — 平台规则中心/开放平台文档明确写出的数值
> 2. **实测** — 本机在真实发布链路里验证通过的数值
> 3. **无来源** — 推测值，**不许用于否决**，只能作为"建议核实"
>
> 拼多多数值规格在 image-prompt-guide 的 `platform-specs-china.md` 里
> 标注为 **not covered**。本文件的拼多多数值全部来自**实测**，不冒充官方。

## ⚠️ 零、采样图陷阱（诊断前必读）

**最容易犯的错：拿搜索页缩略图当原图诊断。**

### 真实踩坑记录（2026-10-28）

诊断 `童装\同行主图\主图\` 40 张图，脚本报 **0/40 通过**，长边全部
`580 < 750`。看起来结论是「同行全都不达标」——**错的**。

查 `_manifest.json` 才发现，图片 URL 全部是这个形态：

```
https://g-search3.alicdn.com/img/bao/uploaded/i4/i4/.../O1CN01...jpg_580x580q90.jpg_.webp
                                                                              ^^^^^^^^^^^^^
```

`_580x580q90` 是**淘宝搜索页的缩略图渲染参数**，q90 = JPEG 质量 90，
转 WebP 输出。这是平台为了列表页加载速度生成的采样图，
**原图被压到 580×580**，与商家实际上传的尺寸无关。

### 识别方法

URL 或文件名里带这些标记的，一律是采样图：

| 标记 | 平台 |
|---|---|
| `_580x580q90.jpg_.webp` | 淘宝/天猫搜索页缩略图 |
| `_400x400` / `_360x360` | 淘宝搜索列表缩略图 |
| `_240x240` / `_120x120` / `_64x64` | 各级缩略图 |

`check_metrics.py` 已内置 `THUMBNAIL_SIZES` 识别表，
命中长边即标记 `is_thumbnail: true`，**不计入质量失败**。

### 纪律

1. **采样图不判尺寸、不判锐度**——原图被平台压过，所有指标都是平台的
   压缩结果，不是商家的图的质量
2. 采样图**可以**看构图、看场景、看文案形式（这些没被压掉）
3. 要判质量，必须抓原图——从商品详情页的 `img.alicdn.com` 原图地址取
4. **结论里必须写清判的是采样图还是原图**，不许混为一谈

### 已确认（实测，2026-10 发布链路）

| 项目 | 数值 | 来源 |
|---|---|---|

| 主图体积 | ≤3MB | 实测 |
| 白底图 | 1:1，纯白 #FFFFFF | 实测 |
| 单图体积区间 | 64–92 KB 为健康值 | 实测 |

### 平台规则（来自 image-prompt-guide → platform-specs-china.md §16）

| 项目 | 要求 |
|---|---|
| 图内语言 | 简体中文（zh-CN） |
| 真实性 | 商品描述、介绍、图片必须真实有效，不得虚假伪造误导 |
| 图像质量 | 图片必须清晰无形变，**商品外观不得变形** |
| 禁项 | 变形外观；有明确指向性的误导性对比图 |
| 多规格 | SKU 图必须对应真实颜色/型号/款式，数量容量包装配件须与该 SKU 一致 |
| 数值规格 | **not covered — 交付前自行核实官方** |

### 诊断时的拼多多专属检查

1. **形变是硬否决**——任何拉伸/压缩/挤压变形，直接 P0
2. **SKU 图文不符**是硬否决——高价值产品图配低价值配件 SKU
3. 禁极限词（"最""第一""100%"）—— 这是拼多多主图驳回第一大原因
   （占 35%，来源：本机交付记录）

## 诊断通用规则

1. **没有来源的数值不进否决项**
2. **实测值在报告里标「实测」**，让用户知道这不是官方背书
3. 平台规则优先于诊断偏好——比如抖音禁文字时，
   不能因为"文字有助三问"就建议加文字
4. **先判是不是采样图，再判质量**——见第零节
5. **按图片类型选阈值档**——场景图（`scene`）不查白底占比，
   拿白底图的标准卡场景图是误判

## 类型档位速查

| 档位 | 用于 | 长边阈值 | 体积阈值 | 白底占比 |
|---|---|---|---|---|
| `main` | 白底/纯背景主图 | ≥750 | ≤3MB | ≥85% |
| `scene` | 场景图、模特图、生活方式图 | ≥750 | ≤3MB | 不查 |
| `sku` | SKU 颜色图 | ≥600 | ≤2MB | 不查 |
| `pdp` | 详情页单屏 | ≥750 | ≤3MB | 不查 |
