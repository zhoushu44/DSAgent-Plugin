# B站·数据采集（bilibili-crawl）

> 一句话定位：采集哔哩哔哩（B站）的视频、UP 主、账号、搜索、排行榜、热门、相关推荐与评论数据，供你做数据分析参考，所有操作只读、不改动任何数据。

## 能力

- **视频详情**：按 BV 号或 av 号取单条视频的完整信息（标题、简介、播放/点赞/投币/收藏/分享数等）
- **UP 主投稿**：采集某个 UP 主或你自己的投稿列表
- **账号资料**：当前登录账号的昵称、mid、粉丝等资料
- **关键词搜索**：按关键词搜视频；按关键词搜 UP 主（用户搜索）
- **排行榜 / 热门**：全站排行榜、热门视频
- **相关推荐**：某条视频的同类推荐
- **评论**：采集视频下方的评论列表
- 结果以归一化字段返回，便于直接阅读或进一步分析

## 触发方式（自然语言示例）

- 「分析一下这个 B站 视频 BV1xx…的数据」
- 「采集 UP 主 xxx 最近发的投稿」
- 「B站 搜一下 xxx 相关的视频」
- 「看看 B站 现在热搜榜 / 排行榜 / 什么火」

## 输入

| 参数 | 必需 | 说明 |
|------|------|------|
| mode | 是 | 采集模式：`video` / `user` / `up` / `profile` / `search` / `user-search` / `ranking` / `hot` / `related` / `comment`；不传时按参数自动判定 |
| bvid / aid | 视模式而定 | 视频 BV 号或 av 号，用于 `video` / `related` / `comment` |
| mid | 视模式而定 | UP 主 mid，用于 `up` 模式 |
| keyword | 视模式而定 | 搜索关键词，用于 `search` / `user-search` |
| count / page | 否 | 每页数量与页码；默认从第 1 页开始，单次采集 ≤ 50 条 |
| max-cursor | 否 | 抖音类习惯用法；B 站用 page 翻页 |

> 约定：不传 `--mode` 时按是否存在 bvid/aid、mid、keyword 及请求文本中的「排行/热门/评论/我的」等关键词自动判断模式。

## 限制与边界

- **不做视频/音频文件下载** → 用 `bilibili-download`
- **不做弹幕采集**：弹幕接口返回 deflate 压缩的二进制 XML，当前链路不支持
- **不做批量爬取**：单次上限约 50 条，超过需翻页多次调用
- **不做内容发布、点赞、投币、收藏**，纯只读采集
- **平台硬限制**：搜索与空间类接口风控较严，可能返回 `-412` / `-352`，需你先去 B站 完成安全验证后重试
- Cookie 失效时需重新登录；请求间隔建议 ≥ 6 秒避免触发风控
- 采集结果仅供数据分析参考，不得用于商业用途

## 账号绑定

- 绑定 **bilibili** 平台账号（当前登录会话对应的投稿账号）
- 登录态由本地代理网关自动注入 Cookie，技能本身不接触 Cookie
- **必须要有登录态**：账号资料、本人投稿、「我的」相关查询都依赖登录；未绑定或无登录态时无法采集

## 输出

- 通过标准输出返回一份 JSON，核心字段如下：
  - `ok`：是否成功
  - `mode` / `keyword`：本次执行的模式与关键词
  - `account`：当前账号昵称与 mid
  - `total` / `has_more` / `page`：总量、是否还有更多、当前页码
  - `data`：数据列表，各项含完整字段（详见下）
- 视频类数据项字段：`bvid`、`aid`、`title`、`desc`、`create_time`、`duration_sec`、`author_name`、`author_mid`、`play_count`、`danmaku_count`、`comment_count`、`like_count`、`coin_count`、`favorite_count`、`share_count`、`cover_url`、`video_url`
- 搜索/排行/评论各有对应字段（如 `rank`/`score`、`rpid`/`is_up` 等）
- `user` / `up` / `search` / `comment` / `hot` 支持翻页（把当前页号 +1 继续传）；`ranking` / `related` 一次性返回、不支持翻页

## 错误处理速查

| 常见失败 | 处理动作 |
|---------|---------|
| 网关地址未设置（`not_bound`） | 到「账号连接」页面扫码绑定 B站 账号 |
| 账号资料返回未登录（`-101`） | 引导重新登录 B站 |
| 接口返回 `-412`（被风控） | 去 B站 完成安全验证后重试，勿当 0 条结果 |
| 接口返回 `-352`（风控校验失败） | 稍后重试或降低请求频率 |
| 其他非 0 错误码（`api_error`） | 按返回提示处理，如 `-404` 表示视频不存在 |
| 响应解析失败（`parse_error`） | 展示原始返回供排查 |
| 结果为空（非风控） | 正常返回空列表，非异常 |
