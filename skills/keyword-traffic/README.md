# 万相台关键词解析（keyword-traffic）

> 一句话定位：基于万相台（无界版）后台做关键词流量趋势分析——类目匹配、最多 13 个月的关键词日趋势（展现 / 点击 / CTR / CVR / 竞争 / 均价）、市场总结与 HTML 报告，用于判断关键词的季节性与投放时机。

## 能力

- **类目匹配**（`categories <词>`）：根据关键词匹配行业类目，供后续 `--cate_id` 使用。
- **流量趋势**（`trend <词>`）：拉取关键词最多 13 个月的日趋势数据（展现、点击、点击率 CTR、转化率 CVR、竞争、市场均价），输出 JSON + CSV + HTML 报告，并自动入库。
- **市场总结**（`summary <词>`）：输出关键词的市场总结（词性、流量、竞争、人群、时间维度）。
- **历史查询**（`history`）：查看本 workspace 已抓取过的关键词列表，可按关键词筛选。
- **数据回存**：趋势明细写入 Connect `skill_cache`（表 `cache_keyword_traffic_*`，按 `shop_key` 隔离），`history` 从此读取。

## 触发方式（自然语言示例）

- “帮我查一下「充电宝」的流量趋势”
- “这个关键词最近 13 个月的展现和竞争怎么样？”
- “分析一下「猫粮」的市场均价和转化率”
- “看看这个行业类目下有哪个关键词值得测”

## 输入

| 参数 | 必需 | 说明 | 默认值 |
|------|------|------|--------|
| 命令 `categories` / `trend` / `summary` / `history` | 是 | 期望执行的功能 | — |
| 关键词 | 是（除 `history`） | 待分析的搜索词 | — |
| `--cate_id` | 否 | 行业类目 ID | 自动取首个有效类目 |
| `--months` | 否 | 趋势月数，范围为 1–13 | `13` |
| `--keyword` | 否 | `history` 命令的筛选词 | 空 |

## 限制与边界

- 只覆盖**万相台付费搜索场景**；展现 / 点击指数为相对指数，不是绝对流量。
- 不做拓词 / 排行榜（归 `keyword-assistant`），不做建计划（归推广管理助手）。
- 趋势月数上限为 13 个月，按 `--months` 控制。

## 账号绑定

- 需绑定 **sycm（生意参谋 / 万相台 / 达摩盘）** 账号。在“平台连接”登录后绑定到当前智能体；技能进程不持有 cookie，由 Connect 代理平台请求。
- 会话无效时退出码为 2，需重新登录绑定。

## 输出

- **stdout**：UTF-8 JSON 摘要，`trend` 命令含 `csv_path` 与 `report_path`。
- **CSV / HTML**：写到 `{workspace}/artifacts/`（CSV 为 UTF-8 BOM 编码）。
- **HTML 报告**：`trend` 成功后直接生成可视化 HTML，从 stdout JSON 取 `report_path` 在浏览器打开；趋势明细已入库，不额外写 artifacts JSON。
- **报告流程**：`trend` 一步即产出 CSV + HTML 报告；可选由 Agent 对 CSV 进一步做深度分析。

## 错误处理速查

| 常见失败 | 处理动作 |
|----------|----------|
| 退出码 2，未绑定 sycm / 会话无效 | 在平台连接登录并绑定 sycm 账号 |
| 退出码 3，限流 | 约 5 分钟后重试 |
| 退出码 4，API 业务错误 | 检查类目 ID 与关键词后重试 |
| 类目匹配不到 | 换更通用的词或用 `categories` 先确认类目 |

## 相关技能

- **协作链**：`market-analysis`（市场分析）→ `keyword-assistant`（关键词助手）→ 本技能（长期趋势）→ 智能数据分析（深度挖掘）。
- **上游拓词**：`keyword-assistant`（榜单与关联词）。
- **同类**：`keyword-assistant`、`market-trend`（生意参谋市场排行）。
