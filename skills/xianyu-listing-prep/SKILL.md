# 闲鱼上架物料准备

按关键词生成**合规主图 + 合规文案**，并跑**违禁词闸门**，产出一份可直接拿去发布的物料包。

## 为什么需要这个技能

闲鱼 API/虚拟商品批量下架的真实原因（实测 2026-10-15）：

| 原因 | 说明 |
|---|---|
| 类目错放 | 数字服务挂到实物类目（如「其他闲置」） |
| 冒充官方 | 第三方中转自称「官方 2 折」 |
| 贬损同业 | 写「不做套路」「不掺量」「不共享号池」 |
| 同模板批量铺 | 多条链接用同一套文案与主图结构 |

本技能把**文案与主图**这两条固化成机器闸门，避免再犯。

## 何时使用

- 用户说「准备闲鱼上架物料」「生成闲鱼主图」「写闲鱼文案」→ 本技能
- 批量铺货前，先跑本技能做合规闸门

## 边界

- **不发布** —— 只产物料，发布用 `xianyu-publish`
- **不做数据采集** —— 关键词需求判断用 `xianyu-crawl`
- 不编造商品事实（价格、模型清单、折扣必须由用户提供或确认）
- 类目选择不在本技能范围（网页版选不到正确类目，需 APP 发布）

## 执行流程

```bash
python3 {baseDir}/scripts/prep.py --keyword "DeepSeek API" --out ./xianyu-out
```

参数：

| 参数 | 必填 | 说明 |
|---|---|---|
| `--keyword` | 是 | 关键词，如 `DeepSeek API` |
| `--discount` | 否 | 折扣口径，默认「官网价 2 折起」 |
| `--models` | 否 | 支持模型列表，逗号分隔 |
| `--price` | 否 | 参考价（写入物料包） |
| `--out` | 否 | 输出目录，默认 `./xianyu-out` |
| `--check-only` | 否 | 只跑合规闸门，不生成图 |

脚本产出：

```
xianyu-out/<slug>/
├── 01-官网价2折起.jpg     主图（首图）
├── 02-服务说明.jpg
├── 03-支持模型.jpg
└── listing.json            标题/描述/价格/图片路径/合规报告
```

## 合规闸门（内置）

**硬拦截**（命中即报错退出）：

| 类别 | 模式 |
|---|---|
| 冒充官方 | `官方\d*折`、`官方直营`、`官方授权`、`官方渠道` |
| 贬损同业 | `不掺量`、`不共享`、`不做套路`、`别家的坑`、`套路` |
| 极限词 | `最`+低价/好、`第一`、`100%`、`唯一`、`绝对` |
| 虚假稀缺 | `仅剩`、`最后一天`、`秒没` |

**软提醒**（提示但不拦截）：

- 缺少合规披露「非官方直营」
- 缺少「虚拟商品不支持退换」说明
- 缺少「需要基础使用经验」提示

## 输出

`listing.json` 结构：

```json
{
  "keyword": "DeepSeek API",
  "title": "...",
  "description": "...",
  "price": "1",
  "images": [".../01-官网价2折起.jpg", "..."],
  "compliance": { "passed": true, "blocked": [], "warnings": [] }
}
```

## 错误处理

| 场景 | 说明 |
|---|---|
| 合规闸门拦截 | 按报出的词修正文案后重跑；不要绕过 |
| 缺字体 | 需要 `C:\Windows\Fonts\msyh.ttc`（Windows 自带） |
| 输出目录不可写 | 换 `--out` 路径 |
