# 1688 找品取数

一句话流程：**关键词 → 1688 搜索 → 打分选款 → 抓详情页 → 出素材包**。

素材包可直接喂给 `pdd-link-matrix`（`--pack`）生成主图与详情页。

## 何时使用

- 用户说「帮我从 1688 找品」「自动选款」「找货源然后出图」→ 本技能
- 作为「找品 → 出图」工作流的第一个步骤

## 边界

- **只读**：不下单、不付款、不改库存
- **不臆造**：详情页接口不回传的字段（如结构化尺码表）一律留空，不推断不补全
- 产地筛选靠厂家名/城市匹配，同名异地会被城市字段交叉校验掉

## 执行

```bash
python3 {baseDir}/scripts/run.py --keywords "儿童睡衣,儿童家居服" --index 1 --origin "宜山,苍南,温州" --out ./pdd-matrix-output
```

| 参数 | 说明 |
|---|---|
| `--keywords` | 关键词列表，逗号/换行分隔 |
| `--index` | 取第几个关键词（工作流按轮次传入） |
| `--origin` | 产地关键词，默认 `宜山,苍南,温州,浙江` |
| `--max-price` | 批发价上限（可选，0=不限） |
| `--out` | 输出根目录，素材包落在 `<out>/packs/<offerId>/` |
| `--skip-scrape` | 只找品不抓详情（调试） |

## 打分规则

| 维度 | 权重 |
|---|---|
| 产地 | 厂家名含「宜山/苍南」+30，其他命中产地词 +15（基础分 20） |
| 应季 | 命中加绒/珊瑚绒/摇粒绒/德绒/夹棉/秋冬等词，每词 +6 |
| 新款 | 标题含 2026/新款/新品 +10 |
| 销量 | 平台回传的「N 件」信号，封顶 +40 |
| 回头率 | 百分比 × 0.25 |
| 店龄 | 每年 +1，封顶 +12 |
| 实力 | 深度验厂 / 超级工厂 各 +4 |

## 依赖与环境

- **生图网关**：本技能只取数不生成，无需配置
- **1688 网关**：自动读取 `~/.dsagent/gateway/*.json` 发现 DSH 本地网关；未绑定 alibaba 账号时返回 `not_bound`
- **浏览器**：抓详情页会启动一个**可见的 Chrome 窗口**（使用 `~/.dsh/browser-profiles/` 下已登录 1688 的配置），约 30 秒
- 需要 `node` 与插件自带的 `puppeteer-core`
