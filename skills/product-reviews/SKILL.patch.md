# product-reviews 现场修正

> 本文件是对主文档的补充修正。按 `SKILL.md` 约定，与主文档冲突时**以本文件为准**。
> 用法：主文档照常读，本文件在技能执行时自动合并到正文之后，无需额外操作。

## 1. 详情接口必须走 tmall 域（修 #53）

主文档 `## 手动命令行` 里的示例用的是 `detail.tmall.com`，这是**正确且必须**的。

`pcdetail.data.get`（商品 SKU 详情）在 `taobao.com` 域下会被平台拒绝，
这是「域名 + API」组合级风控，不是登录态问题 —— 重新登录不解决任何问题。

若脚本报 `FAIL_SYS_ILLEGAL_ACCESS` / 空返回 / `no_permission`：

| 症状 | 正确动作 |
|---|---|
| 详情接口空返回或 403 | 确认请求域名是 `*.tmall.com`，并把 `Referer` / `Origin` **一并改成 tmall 域** |
| 评价列表（`rate.detaillist.get`）正常、只有详情失败 | 同上 —— 两个接口的风控域不同，不能因为列表通了就认为域没问题 |
| 引导用户「重新登录」 | ❌ 错误。登录态是有效的，重登不解决 |

> 只改 URL 域但 `Referer` 仍为 taobao 域，仍会被拒。三者必须同域。

## 2. 风控处置优先级

本技能是阿里系 MTOP 接口，命中 `risk_control` 时：

1. **不要**重复调用本技能 —— 连续请求会放大风控分。
2. 调 `dsagent_risk_verify(platform=taobao)` 拉起验证页。
3. 用户完成滑块后，凭证自动写回账号、冷却自动解除。
4. **然后**再重试本技能。

若验证页返回的是「访问被拒绝」deny 页（`action=denycdc_forbidden`，**无滑块**），
说明账号处于平台侧高风险态，此时：

- 用该账号在真实浏览器里登录并正常浏览几分钟
- 等待风控分自然衰减（数小时到一天）
- 或更换网络出口 / 换一个账号

这类 deny 页不是插件缺陷，也不是登录过期，**不要**引导用户反复重新登录。

## 3. 翻页上限与总量

`total_count` 是平台返回的总量，但**可翻页数受平台限制**，通常远小于
`total_count / page_size`。脚本会在达到平台上限时正常停止，
这**不是**失败 —— 不要把「拿到的条数少于 total_count」报告成错误。
