# 巡店管家（store-patrol-manager）

> 一句话定位：基于生意参谋做店铺综合巡店 / 经营诊断——分析店铺、类目、商品、推广和退款五层数据，在行业数据可用且类目可比时用行业大盘校准市场表现，回答店铺是否正常、问题在哪里、下一步优先做什么。

## 能力

- **分层取数**：店铺整体与每日趋势、本店商品每日明细、推广渠道与计划明细、退款明细，以及可选行业数据与类目树。
- **证据冻结**（`prepare` / `analyze`）：把各层原始 JSON 冻结为证据包，后续从此汇总。
- **确定性汇总**（`aggregate`）：从证据确定性地汇总事实。
- **校验**（`validate`）：校验周期、覆盖、类目映射和严格日环比。
- **组合分析**（`analyze`）：一次完成冻结、汇总、校验。
- **紧凑摘要**（`summary`）：只输出模型需要的紧凑事实目录（数字、表格和分析的唯一事实来源）。
- **交付**：基于冻结事实按“店铺整体 → 类目贡献 → 商品贡献 → 推广 / 退款因素 → 可选行业校准 → 优先动作”给出业务结论；默认输出 HTML 报告，Excel 仅在用户明确要求时生成。

## 触发方式（自然语言示例）

- “帮我巡一下店，看这周经营有没有异常”
- “这周店铺涨 / 跌的原因是什么？帮我归因分析”
- “做一次本周的周复盘”
- “综合诊断一下这家店铺的推广和退款”

## 输入

| 参数 | 必需 | 说明 |
|------|------|------|
| `--shop-name` | 是 | 当前店铺名称 |
| `--display-start` / `--display-end` | 是 | 正式周期 `S~E`（用户没说周期时先询问；相对周期默认不含今天） |
| 各层原始数据（`--shop-raw` / `--item-raw` / `--promotion-raw` / `--refund-raw` / `--industry-raw`） | 视情况 | 可传文件或含 JSON 的目录，未取得的数据层省略 |
| `--category-map` | 否 | 类目可比性映射（由 AI 结合本店商品与行业返回判断写入） |

## 限制与边界

- 只基于当前绑定的店铺，不复用历史店铺 / 类目 / 结论 / 旧报告。
- 行业校准强依赖会话原生注入的行业 MCP：未注入时标记为未绑定并跳过，**禁止**从配置 / 凭证 / 其他智能体 / 历史文件寻找 MCP。
- 商品层缺失时跳过类目 / 商品归因；某层缺失时用证据补齐其他诊断，不生成悬空等待。
- 不设固定成交笔数门槛；短周期零成交不单独触发停计划。
- 不负责仅单一推广渠道或投放报表（归专门的推广分析技能）、商品市场大盘（归 `market-analysis`）。

## 账号绑定

- 在当前 DeepSeek Agent workspace 中运行，读取其已绑定的 sycm（生意参谋 / 达摩盘）店铺登录态；行业 MCP 由 runtime 注入。技能不保存凭证或服务地址，脱离已安装 workspace 时拒绝运行。

## 输出

- **stdout**：UTF-8 JSON；业务产物只写当前工作区 `{workspace}/artifacts/`（或 `tool_results/`）。
- **中间产物**：`patrol_evidence.json`、`patrol_facts.json`、`patrol_validation.json`。
- **HTML / Excel**：直接生成自包含 HTML 最终报告（默认）；Excel 仅在用户明确要求时生成。不修改已安装技能目录。
- **报告流程**：锁定店铺与周期 → 分层取数（存原始 JSON）→ `analyze` 冻结 · 汇总 · 校验 → `summary` 取紧凑事实 → 按业务顺序分析并生成最终报告。

## 错误处理速查

| 常见失败 | 处理动作 |
|----------|----------|
| 校验报错 | 先修正输入或明确降级，不得绕过；只有警告时可交付并说明缺口及影响 |
| 行业 MCP 未注入 | 标记未绑定并跳过行业校准，不寻找替代 MCP |
| 某层数据缺失 | 继续完成其他有证据的诊断，用业务语言说明缺失部分 |
| 周期未给出 | 先询问周期，不可用默认值 / 当前日期猜测 |
| 类目不可比 | 按可比性判断结果为该类目跳过行业对比 |

## 相关技能

- **同类 / 上游**：`market-analysis`（商品市场大盘，巡店不做大盘）、`competitor-strategy-comparison`（竞品策略，环比巡店侧重本店）。
- **市场 / 竞品维度**：`market-trend`、`competitor-indicator`。
