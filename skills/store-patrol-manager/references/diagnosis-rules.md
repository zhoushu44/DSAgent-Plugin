# 诊断规则

## 店铺与商品

- 店铺整体拆分流量、转化、客单、退款和推广，不把单日变化外推为长期趋势。
- 类目周期指标从商品日数据聚合；支付转化率按支付买家数除以商品访客重算，访客平均价值按支付金额除以商品访客重算。
- 店铺层与商品层同期金额明显不一致时，停止跨层归因并说明口径差异。
- 商品层缺失时，不得从推广计划名称反推全店商品或类目贡献。

## 推广

- 汇总前必须过滤到正式周期 `S~E`，只保留周期内确实有消耗、展现、点击或成交的渠道和计划。
- 先按渠道对比，再下钻计划；不要求逐日展示。
- 优先使用明确的计划类型、出价模式和目标ROI。仅从标题识别“ROI、控投产、动销”等词时，标记为“标题推断”。
- 不设“至少5笔成交”等跨类目门槛。
- 高客单计划短周期零成交只触发复核；结合消耗、点击、收藏加购、询单、成交、ROI、目标和运行时长判断。
- 明确或疑似ROI/动销计划只有在完整月度或至少约30天连续证据下，持续消耗且没有成交或有效中间转化，才可建议停止或重建。
- “暂停、砍掉、大幅降价、加预算”等强动作必须有与动作匹配的连续周期和目标证据。

## 行业校准

- 先判断当前会话是否有行业MCP，再由AI结合本店实际商品、类目层级和主营结构判断可比性。
- 判断结果为：匹配、部分匹配、不匹配、信息不足。
- 部分匹配时只比较确认可比的范围；不匹配或信息不足时跳过行业结论。
- 映射覆盖率是证据，不设固定阈值。
- 行业可比时必须保留“店铺类目 vs 市场大盘关联分析”：双方逐日销售额、首个共同有效日为100的趋势指数、双方环比、同向/背离、有效样本数和关联结论。
- 本店侧只汇总映射类目，不得用全店销售额替代；类目范围不完全一致时不得称为市场份额。
- 报告展示时把本店类目与其对应行业类目放在同一张结构表和同一张逐日表里，不能拆成两个孤立章节。
- 缺日、重复快照和零值占位不参与环比或相关性计算。日环比必须严格使用前一自然日；不得跳过缺失日与更早日期比较。
