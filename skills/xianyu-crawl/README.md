# 闲鱼·数据采集（xianyu-crawl）

> 一句话定位：在闲鱼平台按关键词搜索商品、采集商品详情与卖家信息，用于选品调研与同类比价。

## 能力
- 关键词搜索商品：按用户给的关键词调用闲鱼搜索接口，返回商品列表。
- 采集商品核心信息：标题、现价、原价、卖家昵称/ID、发货地区、首图、想要人数等。
- 翻页采集：支持 `page` / `size` 参数控制分页，单次搜索不超过 50 条。
- 结果以结构化 JSON 返回，方便后续统计（比价、价格分析）。
- **不可做**：不采集卖家联系方式与隐私数据，不做批量爬取，不自动下单或联系卖家。

## 触发方式（自然语言示例）
- 「帮我搜闲鱼上的 iPhone」
- 「采集闲鱼商品数据」
- 「闲鱼上 xxx 大概卖多少」
- 「帮我对比一下闲鱼上这几款的价格」

## 输入
| 参数 | 必需 | 说明 |
|------|:----:|------|
| 搜索关键词 | 是 | 用户话里包含的商品关键词（无条件时自动从请求文本提取） |
| `page` | 否 | 页码，默认 1 |
| `size` | 否 | 单页条数，默认 20，单次总结果不超过 50 |

> 采集请求间隔 ≥ 2 秒，避免触发闲鱼风控。采集结果仅供数据分析与比价参考，不得用于商业用途。

## 限制与边界
- 搜索结果不含商品描述与浏览次数（`description` 恒为空、`view_count` 恒为 0），需要描述需另走详情接口（当前未内置）。
- `want_count` 以「N 人想要」文本标签为准，接口原始 `wantNum` 是占位串，不可用于判断。
- 不采集卖家隐私；不做批量爬取；不代为下单或联系卖家。
- 平台级采集请换用 `market-analysis`（淘宝商品分析）；抖音/小红书等其它平台采集走对应平台技能。

## 账号绑定
- 绑定**闲鱼（xianyu）**平台账号。账号登录态（Cookie）由本地代理网关注入，Cookie 不出网关。
- 若 Cookie 失效（如 `_m_h5_tk` 获取失败）需重新登录。

## 输出
- 采集结果通过 stdout 输出 `__DSAGENT_RESULT__` 行，JSON 结构：
  ```
  { ok: true, keyword: "iPhone 15", total: 20,
    data: [ { item_id, title, price, original_price, seller_nick, seller_id, area, image_url, want_count } ] }
  ```
- 搜索无结果显示 `{ ok: true, data: [], total: 0 }`（非错误）。

## 错误处理速查
| 常见失败 | 处理动作 |
|---------|---------|
| 未绑定闲鱼账号（`not_bound`） | 引导到「账号连接」页面绑定闲鱼账号 |
| `_m_h5_tk` 获取失败（`token_expired`） | 登录态可能失效，提示重新登录 |
| 搜索请求被风控（`risk_control`） | 引导去平台完成安全验证后重试 |
| 搜索接口限流（`rate_limit`） | 提示稍后重试 |
| 响应解析失败（`parse_error`） | 展示原始返回分析 |
| 搜索无结果 | 按空结果返回，非错误 |

## 相关技能
- 发布上架：`xianyu-publish`
- 分析自有店铺经营：`xianyu-analytics`
- 淘宝侧商品分析：`market-analysis`
