# 生意参谋关键词排行（keyword-assistant）

> 一句话定位：基于生意参谋后台做关键词挖掘与排行榜分析——关联词拓展（搜索人气、点击率、转化率、供需比、环比）以及热搜 / 飙升 / 新词排行榜，用于拓词、找蓝海词、选品和标题优化。

## 能力

- **关联词拓展**（默认模式 `expand`）：给定种子关键词，返回一批关联词的搜索人气、点击率、免费点击率、支付买家数、支付转化率、供需比、天猫点击占比，以及搜索人气 / 点击率的环比变化。
- **多关键词对比**：一次传入多个种子词，批量抓取并对比数据。
- **搜索排行榜**（`rank`）：展示淘宝热搜榜、飙升榜、新词榜，支持搜索词 / 类目词维度，可排序（搜索人气 / 支付买家数 / 点击率）。
- **洞察生成**：由 Agent 依据抓取的 JSON 撰写文字版选品 / 优化建议（蓝海词 TOP5、高转化词、策略建议等）。
- **HTML 可视化报告**：把洞察与数据渲染成浏览器可打开的 HTML 报告，并附 CSV。
- **数据回存**：每次取数结果写入 Connect 的 `skill_cache`（表 `cache_keyword_assistant_*` + `cache_keyword_assistant_runs`，按 `shop_key` 隔离）。

## 触发方式（自然语言示例）

- “猫粮的搜索人气是多少？”
- “猫粮和猫砂哪个搜索人气更高？”
- “帮我分析男装市场，找找蓝海词”
- “帮我出一份男装关键词分析报告”
- “现在淘宝热搜都在搜什么？”

## 输入

| 参数 | 必需 | 说明 | 默认值 |
|------|------|------|--------|
| 种子关键词 | 是 | 关联词拓展的查询词，一次可传多个 | — |
| `--mode` | 否 | `expand`=关联词拓展，`rank`=搜索排行榜 | `expand` |
| `--rank_type` | 否 | rank 模式榜单类型：`hot` / `rise` / `new` | `hot` |
| `--kw_type` | 否 | rank 模式词类型：`search`=搜索词 / `category`=类目词 | `search` |
| `--order_by` | 否 | 排序字段：搜索人气 / 支付买家数 / 点击率 | 搜索人气 |
| `--cate_id` | 否 | 淘宝类目 ID，解决部分权限问题时可指定 | 空 |
| `--max_pages` | 否 | 最大抓取页数（expand 每页 10 条，rank 每页 50 条） | `10` |
| `--date_range` | 否 | 日期范围 `YYYY-MM-DD|YYYY-MM-DD`，或 `recent7` / `recent30` | 近 7 天 |
| `--output_format` | 否 | 输出格式：`json` / `text` / `table` | `json` |

## 限制与边界

- 覆盖生意参谋的关键词市场数据，**不做** 13 个月流量趋势（由 `keyword-traffic` 万相台负责）与商品市场大盘（由 `market-analysis` 负责）。
- 数据为生意参谋的区间化 / 模糊化口径（如“15万~30万”），不提供精确值。
- 单次最多抓到指定页数内的数据，不保证覆盖全部关联词。

## 账号绑定

- 需绑定 **sycm（生意参谋）** 账号。在“平台连接”中登录后绑定到当前智能体；技能进程不直接持有 cookie，由 Connect 代理平台请求。
- 会话失效时退出码为 2，需在平台连接重新登录。

## 输出

- **stdout**：UTF-8 JSON，含 `status`、`top_keywords` / `keywords` 列表及 `csv_path`。
- **CSV**：写到当前智能体 workspace 的 `{workspace}/artifacts/`。
- **HTML 报告**：通过 `inject-report` 子命令生成，stdout JSON 返回 `report_path`，需在浏览器打开该路径查看报告；交付内容为“HTML 报告 + CSV + 文字摘要”。
- **报告流程**：数据获取 → 洞察（Agent 写 `artifacts/{关键词}洞察.md`）→ `inject-report` 生成 HTML。
- `{workspace}` 默认形如 `~/.QIWork/users/{user_id}/workspaces/{agent_id}/`。

## 错误处理速查

| 常见失败 | 处理动作 |
|----------|----------|
| 退出码 2，会话无效 | 在平台连接重新登录 sycm 并绑定智能体 |
| 退出码 4，API 权限错误 | 追加 `--cate_id` 重试 |
| 洞察标题含 emoji 或一级标题 | 改为纯文字、只用 `##` 二级标题，否则报告校验终止 |
| 洞察模块不足 3 个 | 补齐至至少 3 个 `##` 模块（推荐 7-8 个）再生成报告 |

## 相关技能

- **上游**：`market-analysis`（市场分析 / 大盘）→ 本技能（拓展选词）→ `keyword-traffic`（关键词流量解析 / 长期趋势）→ 智能数据分析（深度挖掘）。
- **循环周期可视化**：`keyword-traffic`。
- **同类**：`market-trend`（市场排行趋势，与之互补）。
