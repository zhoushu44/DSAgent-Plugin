# 知乎·内容发布（zhihu-publish）

> 一句话定位：把「标题 + 正文」发布为知乎专栏文章，自动打开写文章编辑器、填写标题与正文并提交发布。

## 能力
- 将标题 + 纯文本正文发布为知乎**专栏文章**。
- 自动注入登录态、打开「写文章」页并完成填标题、填正文、点发布。
- **可做**：发布专栏文章（含附文章链接反馈）。
- **不可做**：数据采集、回答/评论/私信互动；写回答、发布想法、视频、投稿至问题、自定义封面/话题当前不支持；也不自动生成文案。

## 触发方式（自然语言示例）
- 「把这篇发到知乎」
- 「发布知乎文章 / 写一篇知乎专栏」
- 「帮我发知乎 / 投稿到知乎专栏」

## 输入
| 参数 | 必需 | 说明 |
|------|:----:|------|
| `title` | 是 | 文章标题，**≤ 100 字** |
| `content` | 是 | 正文纯文本，用换行分段，**≤ 50000 字** |
| `confirm` | 特殊 | **仅在用户明确同意发布后才传 `true`**，用于真正提交 |

## 限制与边界
- ★ **发布是 L2 真实操作且不可撤销，采用两步式流程**：先不带 `confirm` 调用拿「发布预览」（含账号、标题、正文字数与段数、开头），展示给用户并获**明确同意**后，再带 `confirm=true` 重新调用真正提交。绝不可在一次调用里直接 `confirm=true`。
- 正文为**纯文本**，用换行分段；**不支持富文本 / 图片 / 公式**。
- 标题 ≤ 100 字、正文 ≤ 50000 字，超限会在调用前被拦下。
- 发布会**弹出可见浏览器窗口**（真实操作，用户可见）；出现滑块/安全验证需人工完成。
- 同一时间只能有一个知乎发布窗口。

## 账号绑定
- 绑定**知乎（zhihu）**平台账号，通过扫码登录获取登录态。
- 多账号时会返回候选列表让用户选择，绑定指定账号回传 `account` 参数。

## 输出
- 成功：告知已发布并附文章链接，说明**平台可能仍在审核**，最终状态以知乎「创作中心 → 内容管理」为准。
- 失败：按返回的 `failureKind` 走错误处理速查。

## 错误处理速查
| 常见失败 | 处理动作 |
|---------|---------|
| 未绑定账号（`not_bound`） | 引导到「账号连接」扫码登录 |
| 多账号待选（`need_account_choice`） | 把候选列表给用户选，不要自行选择 |
| 写文章页跳到登录页（`token_expired`） | 引导到「账号连接」重新登录 |
| 标题为空/超 100 字 / 正文为空/超 50000 字 | 修正参数后重试 |
| 找不到标题框/正文区/发布按钮 | 页面结构可能变更，上报问题 |
| 正文插入后编辑器未回填字数 | 编辑器未收到内容，查看弹出窗口后重试 |
| 点发布后未检测到成功标志 | 查看弹出窗口内的提示，有滑块需人工完成 |
| 命中「内容违规」「操作过于频繁」 | 调整内容或稍后重试 |
