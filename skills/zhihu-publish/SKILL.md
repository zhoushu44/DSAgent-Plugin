# 知乎内容发布

> **重要:** 发布是**不可撤销的真实操作（L2）**。必须两步走：先拿「发布预览」给用户看，用户**明确同意**后才真正提交。
> 绝不要在一次调用里直接传 `confirm=true`。

## 何时使用

- 用户说"把这篇发到知乎"、"发布知乎文章"、"写一篇知乎专栏" → 发布文章
- 用户给出标题 + 正文，要求发到知乎 → 发布文章
- 用户说"帮我发知乎"、"投稿到知乎专栏" → 发布文章

## 边界

- **不做数据采集** —— 搜索回答/文章、采集评论、用户主页、热榜请用 `zhihu-crawl`
- **不做回答 / 评论 / 私信互动** —— 对应技能尚未实现
- **不生成文案** —— 标题与正文由用户提供（或先用通用文案技能生成，再回到本技能发布）
- **只支持发布文章（专栏）** —— 写回答、发布想法、视频、投稿至问题、自定义封面/话题当前不支持
- 正文为**纯文本**，用换行分段；**不支持富文本/图片/公式**（编辑器会按纯文本落地）
- 标题**限 100 字**、正文**限 50000 字**，超限会在调用前被拦下
- 发布过程会**弹出可见浏览器窗口**（真实操作，用户可见）；若出现滑块/安全验证需人工完成
- 同一时间只能有一个知乎发布窗口；已有窗口进行中时需等待其结束

## 执行流程

本技能**没有脚本入口**，执行方式是**直接调用 host 工具** `dsagent_zhihu_publish`。

### 1. 收集参数

从用户话里提取两项，缺项就主动问：

| 参数 | 必需 | 说明 |
|------|------|------|
| `title` | 是 | 文章标题，**≤ 100 字** |
| `content` | 是 | 文章正文纯文本，用 `\n` 分段，**≤ 50000 字** |

### 2. 先取「发布预览」（不带 confirm）

调用 `dsagent_zhihu_publish`，**只传 `title` / `content`，不要传 `confirm`**：

```
dsagent_zhihu_publish(title="如何做好内容运营", content="第一段正文。\n第二段正文。")
```

工具此时**不会启动浏览器、不产生任何写操作**，只返回一段「发布预览」文本（含账号、标题、正文字数与段数、正文开头）。

### 3. 把预览完整展示给用户并征求明确同意

把预览内容原样呈现给用户，并明确问一句类似"确认要发布吗？"。
**这一步不可跳过、不可自行假设用户同意**（L2 风险门禁）。

### 4. 用户同意后带 `confirm=true` 重新调用

```
dsagent_zhihu_publish(title="如何做好内容运营", content="第一段正文。\n第二段正文。", confirm=true)
```

工具会弹出可见浏览器窗口，依次完成：注入登录态 → 打开写文章页 → 填标题 → 填正文 → 校验内容已就位 → 点「发布」→ 判定结果。

### 5. 报告结果

- 成功：告知已发布，并附文章链接；说明**平台可能仍在审核**，最终状态以知乎「创作中心 → 内容管理」为准
- 失败：按返回的 `failureKind` 走下方「错误处理」

## 错误处理

| 场景 | failureKind | 引导动作 |
|------|-------------|---------|
| 未绑定知乎账号 | `not_bound` | 引导用户到「账号连接」页面扫码登录知乎账号 |
| 平台有多个可用账号且当前会话未绑定 | `need_account_choice` | **把候选列表给用户选**，把选定的 `shopKey` 填进 `account` 参数重调；★ 绝不要自己挑一个 |
| 写文章页被重定向到登录页 | `token_expired` | 引导用户到「账号连接」页面**重新登录**知乎 |
| 标题为空 / 超 100 字 / 正文为空 / 超 50000 字 | `api_error` | 按提示修正参数后重试 |
| 找不到标题框 / 正文区 / 发布按钮 | `api_error` | 页面结构可能变更，请上报该问题 |
| 正文插入后编辑器未回填字数 | `api_error` | 编辑器未收到内容，让用户查看弹出的浏览器窗口后重试 |
| 点击发布后未检测到成功标志 | `api_error` | 让用户查看弹出的浏览器窗口内的具体提示；若有滑块需人工完成 |
| 命中「内容违规」「操作过于频繁」 | `api_error` | 提示用户调整内容或稍后重试 |

## 环境变量

本技能为纯指令型，不执行脚本，无环境变量依赖。
账号凭证由 host 工具从凭证库直接读取，**技能侧不接触 Cookie**。
