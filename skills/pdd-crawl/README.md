# 拼多多·数据采集（pdd-crawl）

> 一句话定位：从拼多多买家端拉取商品数据（首页推荐流 / 关键词搜索 / 单品详情），返回标题、价格、销量、店铺、链接等结构化字段，用于选品、比价、看行情。

## 能力

- **首页推荐流采集**：抓取拼多多首页推荐的商品列表（推荐优先使用，最稳定）。
- **关键词搜索**：按关键词搜索商品并取回结果（如「搜一下拼多多上的手机壳」）。
- **单品详情**：按商品 ID 拉取单件商品的数据。
- **比价汇总**：多次搜索或拉详情后，把多家价格整理排序给用户。
- 只读操作，**不产生任何平台副作用**（不改价、不上下架、不发布）。

**不做的事**：不发布商品、不动订单与售后、不发客服消息、不做报表类深度数据分析了，这些需要换成别的技能（见文末「相关技能」）。

## 触发方式（自然语言示例）

- 「拼多多上有什么好卖的东西」「给我看看拼多多商品」 → 首页推荐流
- 「搜一下拼多多上的手机壳」「拼多多有哪些卖 XX 的」 → 关键词搜索
- 「这个拼多多商品多少钱」「帮我看看这个商品」 → 单品详情
- 「对比一下拼多多上这几家的价格」 → 多次搜索 / 详情后汇总

## 输入

核心参数如下（只有少数情形必填，多数可省略，工具会自动推断模式）：

| 参数 | 必需 | 说明 |
|------|------|------|
| `mode` | 否 | `feed`（首页推荐流，推荐）/ `search`（关键词搜索）/ `goods`（单品详情）。省略时自动推断：有 `goodsId`→`goods`，有 `keyword`→`search`，都没有→`feed` |
| `keyword` | mode=search 时必填 | 搜索关键词，如 `手机壳` |
| `goodsId` | mode=goods 时必填 | 拼多多商品 ID（纯数字） |
| `limit` | 否 | 返回条数上限，默认 20，最大 100 |
| `account` | 否 | 指定账号 `shopKey`；多账号待选时由用户选定后回传 |

> **取数稳定性提示**：搜索 / 单品接口对账号有较强频控，常返回「系统繁忙」或干脆不发请求；首页推荐流（`mode=feed`）实测最稳定、字段也最全。用户没有明确给出关键词或商品 ID 时，优先用推荐流。

## 限制与边界

- **依赖绑定拼多多买家端账号**：拼多多对未登录访客会强制跳登录页，匿名无法采集，必须先连接账号。
- **单次采集会弹出可见浏览器窗口**。
- 可能遇到**滑块 / 安全验证 / 搜索频控**，需要用户人工参与或改走推荐流。
- 单次采集窗口串行，已有窗口进行中需先等其结束。

## 账号绑定

- 绑定**拼多多买家端**账号（App / H5 那套登录态）。
- **注意**：这个账号与「拼多多商家后台」（mms.pinduoduo.com）是**两套完全独立的登录态**。买家端能采集，但**不能用它去发布商品**；发布请连接商家后台账号。

## 输出

- 把商品列表整理给人看：**商品名 / 价格 / 销量 / 店铺 / 链接**，必要时做价格排序或汇总。
- 工具还会返回 `sourceUrls`（本次实际命中的接口），排查「没数据」时它会一并给出。

## 错误处理速查

| 常见失败 | 处理动作 |
|---------|---------|
| 未绑定账号（`not_bound`） | 引导到「账号连接」扫码登录拼多多买家端账号 |
| 多个账号未选（`need_account_choice`） | 把候选账号列表给用户选，选定后回传，绝不自己挑 |
| 跳登录页 / 登录失效（`token_expired`） | 重新登录拼多多买家端账号 |
| 搜索被限流（`risk_control`，「系统繁忙」） | **不要反复重试搜索**，直接改用首页推荐流取数，或稍后再试 |
| 有数据但无字段 / 全部 403（`parse_error`） | 看浏览器里是否出现滑块验证，人工完成后重试；仍无则可能是平台接口调整 |
| 缺 `keyword` 或 `goodsId` | 按 mode 补齐必填参数 |
| 已有采集窗口在进行中 | 先等它结束或关闭弹窗 |
| 未找到 Chrome / Edge | 安装 Chrome 或 Edge |

## 相关技能

- **发布拼多多商品** → `pdd-publish`（注意用商家后台账号，与采集账号不同）
- **订单 / 售后** → `pdd-order`
- **库存管理** → `pdd-stock`
- **客服消息** → `pdd-im`
- **数据分析 / 报表** → `pdd-analytics`
