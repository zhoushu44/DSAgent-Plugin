# 闲鱼内容发布

> **重要:** 发布是**不可撤销的真实操作（L2）**。必须两步走：先拿「发布预览」给用户看，用户**明确同意**后才真正提交。
> 绝不要在一次调用里直接传 `confirm=true`。

## 何时使用

- 用户说"帮我发个闲鱼"、"把这个挂到闲鱼上卖" → 发布商品
- 用户给出本地图片路径 + 描述 + 价格，要求发到闲鱼 → 发布商品
- 用户说"闲鱼上架"、"发闲置"、"闲鱼卖东西" → 发布商品

## 边界

- **不做商品采集与比价** —— 请用 `xianyu-crawl`
- **不做数据分析** —— 请用 `xianyu-analytics`
- **不做订单与售后** —— 请用 `xianyu-order`
- **不做客服消息** —— 请用 `xianyu-im`
- **不生成文案** —— 描述与价格由用户提供（或先用通用文案技能生成，再回到本技能发布）
- **不做批量发布、定时发布、一键擦亮、批量下架** —— 当前只支持单件商品发布
- 图片必须是**本机绝对路径**且真实存在，**1~9 张**，单张 **≤ 10MB**
- 描述**必填**且**不能包含 emoji**（闲鱼校验规则）
- 价格**必填**，范围 **0 ~ 1 亿元**；原价（可选）需在 1 亿元之内
- ★ 闲鱼网页版发闲置为**单件**，无库存设置项，故本技能**不支持库存**
- ★ **部分类目网页版不支持发布**：页面会要求「扫码去APP发布」，此时只能引导用户到闲鱼 APP 操作
- 发布过程会**弹出可见浏览器窗口**（真实操作，用户可见）；若出现滑块/安全验证需人工完成
- 同一时间只能有一个闲鱼发布窗口；已有窗口进行中时需等待其结束
- ★ **账号必须是闲鱼 APP 扫码登录**：淘宝 SSO 派生的闲鱼账号在 goofish 域下登录态无效

## 执行流程

本技能**没有脚本入口**，执行方式是**直接调用 host 工具** `dsagent_xianyu_publish`。

> 为什么不是 Python 脚本：发布涉及**图片 multipart 上传**与页面运行时生成的 `sign` 签名，
> 本地代理网关不支持 multipart，且纯 HTTP 请求恒被拒（`FAIL_SYS_SESSION_EXPIRED`）。
> 因此由 host 工具用 puppeteer 驱动闲鱼网页版发布页（`https://www.goofish.com/publish`）完成填写与提交。

### 1. 收集参数

从用户话里提取，缺项就主动问：

| 参数 | 必需 | 说明 |
|------|------|------|
| `images` | 是 | 本地图片文件**绝对路径**，1~9 张，单张 ≤ 10MB。多张用英文逗号分隔，或传 JSON 数组字符串 |
| `description` | 是 | 宝贝描述，**不能含 emoji** |
| `price` | 是 | 价格（元，字符串数字），**0 ~ 1 亿元** |
| `title` | 否 | 宝贝标题。闲鱼网页版标题多由描述/类目派生，页面有标题框时会一并填入 |
| `originalPrice` | 否 | 原价/入手价（元），需在 1 亿元之内 |

★ **本工具不提供库存参数**：闲鱼网页版发闲置为**单件**，发布页没有库存输入框，填了也不会生效。

### 2. 先取「发布预览」（不带 confirm）

调用 `dsagent_xianyu_publish`，**只传业务参数，不要传 `confirm`**：

```
dsagent_xianyu_publish(images="D:\imgs\1.jpg,D:\imgs\2.jpg", description="全新未拆封，品牌型号见详情", price="199")
```

工具此时**不会启动浏览器、不产生任何写操作**，只返回一段「发布预览」文本（含账号、图片、描述、价格、库存）。

### 3. 把预览完整展示给用户并征求明确同意

把预览内容原样呈现给用户，并明确问一句类似"确认要发布吗？"。
**这一步不可跳过、不可自行假设用户同意**（L2 风险门禁）。

### 4. 用户同意后带 `confirm=true` 重新调用

```
dsagent_xianyu_publish(images="D:\imgs\1.jpg,D:\imgs\2.jpg", description="全新未拆封，品牌型号见详情", price="199", confirm=true)
```

工具会弹出可见浏览器窗口，依次完成：注入登录态 → 打开发布页 → 上传图片并等待完成 → 填描述 → 填价格 →（可选填原价/库存/标题）→ 点「发布」→ 判定结果。

### 5. 报告结果

- 成功：告知已发布，并说明**平台可能仍在审核**，最终状态以闲鱼 APP「我的-我发布的」为准
- 失败：按返回的 `failureKind` 走下方「错误处理」

## 错误处理

| 场景 | failureKind | 引导动作 |
|------|-------------|---------|
| 未绑定闲鱼账号 | `not_bound` | 引导用户到「账号连接」页面添加闲鱼账号 |
| 平台有多个可用账号且当前会话未绑定 | `need_account_choice` | **把候选列表给用户选**，把选定的 `shopKey` 填进 `account` 参数重调；★ 绝不要自己挑一个 |
| 发布页未识别登录态 / 账号类接口 Session 过期 | `token_expired` | 引导用户**删除该闲鱼账号后重新添加**，★ 必须用**闲鱼 APP 扫描** `https://www.goofish.com/login` 的二维码；**不要走淘宝 SSO**（SSO 派生的账号在 goofish 域下无效） |
| 接口返回 403 / 429 | `risk_control` | 调用 `dsagent_risk_verify`（platform=xianyu）拉起验证页，用户完成滑块后重试 |
| 图片不存在 / 超过 10MB / 超过 9 张 | `api_error` | 按提示修正图片路径或压缩后重试 |
| 描述为空 / 含 emoji / 价格或原价越界 | `api_error` | 按提示修正参数后重试 |
| 图片上传失败 | `api_error` | 提示用户检查图片格式（建议 jpg/png）或换图重试 |
| 页面要求「扫码去APP发布」 | `api_error` | ★ 该分类**不支持网页版发布**，引导用户在闲鱼 APP 内完成该类目商品的发布 |
| 找不到描述框 / 价格框 / 发布按钮 | `api_error` | 页面结构可能变更，请上报该问题 |
| 点击发布后未检测到成功标志 | `api_error` | 让用户查看弹出的浏览器窗口内的具体提示；若有滑块需人工完成 |
| 已有发布窗口在进行中 | `api_error` | 提示先等待或关闭已弹出的浏览器窗口 |
| 未找到 Chrome / Edge | `api_error` | 提示用户安装 Chrome 或 Edge |

## 环境变量

本技能为纯指令型，不执行脚本，无环境变量依赖。
账号凭证由 host 工具从凭证库读取并**在浏览器内注入 Cookie**，日志与返回值均已脱敏，**技能侧不接触 Cookie**。
