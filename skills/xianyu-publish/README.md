# 闲鱼·内容发布（xianyu-publish）

> 一句话定位：把本地的宝贝图片与描述、价格一键发布为闲鱼商品，让你在闲鱼上架闲置。

## 能力
- 上传本地宝贝图片（1~9 张）并填写描述、价格、标题、原价，提交为闲鱼商品。
- 自动注入登录态、打开闲鱼网页版发布页（`goofish.com/publish`）并完成填写与提交。
- **可做**：单件商品发布。
- **不可做**：商品采集/比价、数据分析、订单/售后、客服消息均不在此技能；也不支持批量发布、定时发布、一键擦亮、批量下架、库存设置，且不自动生成文案。

## 触发方式（自然语言示例）
- 「帮我发个闲鱼」
- 「把这个挂到闲鱼上卖」
- 「闲鱼上架 / 发闲置 / 闲鱼卖东西」

## 输入
| 参数 | 必需 | 说明 |
|------|:----:|------|
| `images` | 是 | 本地图片**绝对路径**，1~9 张，单张 ≤ 10MB；多张用英文逗号分隔 |
| `description` | 是 | 宝贝描述，**不能含 emoji**（闲鱼校验规则） |
| `price` | 是 | 价格（元），范围 **0 ~ 1 亿元** |
| `title` | 否 | 宝贝标题，由描述/类目派生，有标题框时一并填入 |
| `originalPrice` | 否 | 原价/入手价（元），需在 1 亿元之内 |
| `confirm` | 特殊 | **仅在用户明确同意发布后才传 `true`**，用于真正提交 |

> 注意：本技能**不提供库存参数**——闲鱼网页版发闲置为单件，发布页没有库存输入框。

## 限制与边界
- ★ **发布是 L2 真实操作且不可撤销，采用两步式流程**：先不带 `confirm` 调用拿「发布预览」，展示给用户并获**明确同意**后，再带 `confirm=true` 重新调用真正提交。绝不可在一次调用里直接 `confirm=true`。
- 描述必填且不能含 emoji；价格/原价有数值边界。
- ★ 部分类目网页版不支持发布，页面会要求「扫码去 APP 发布」，此时只能引导用户在闲鱼 APP 内完成该类目发布。
- 发布会**弹出可见浏览器窗口**（真实操作，用户可见）；出现滑块/安全验证需人工完成。
- 同一时间只能有一个闲鱼发布窗口，已有窗口进行中需等其结束。
- 图片须为本机真实存在的绝对路径。
- ★ 必须使用**闲鱼 APP 扫码登录**：淘宝 SSO 派生的闲鱼账号在 goofish 域下登录态无效。

## 账号绑定
- 绑定**闲鱼（xianyu）**平台账号，且登录态须为**闲鱼 APP 扫码**获取的真实 goofish 会话（不要走淘宝 SSO）。
- 多账号时会返回候选列表让用户选择，绑定指定账号回传 `account` 参数。

## 输出
- 成功：告知已发布，并说明**平台可能仍在审核**，最终状态以闲鱼 APP「我的-我发布的」为准。
- 失败：按返回的 `failureKind` 走错误处理速查。

## 错误处理速查
| 常见失败 | 处理动作 |
|---------|---------|
| 未绑定账号（`not_bound`） | 引导到「账号连接」添加闲鱼账号 |
| 多账号待选（`need_account_choice`） | 把候选列表给用户选，不要自行选择 |
| 登录态失效（`token_expired`） | 删除后重新添加，须用闲鱼 APP 扫码 `goofish.com/login`，不要走淘宝 SSO |
| 接口返回 403/429（`risk_control`） | 走 `dsagent_risk_verify` 拉起验证页，完成滑块后重试 |
| 图片不存在/超 10MB/超 9 张 | 修正路径或压缩后重试 |
| 描述为空/含 emoji/价格越界 | 按提示修正参数 |
| 页面要求「扫码去 APP 发布」 | 该分类不支持网页版，引导到闲鱼 APP 内发布 |
| 已有发布窗口进行中 / 未找到浏览器 | 等待或关闭窗口 / 安装 Chrome 或 Edge |
