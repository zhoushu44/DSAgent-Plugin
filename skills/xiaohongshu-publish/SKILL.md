# 小红书内容发布

> **重要:** 发布是**不可撤销的真实操作（L2）**。必须两步走：先拿「发布预览」给用户看，用户**明确同意**后才真正提交。
> 绝不要在一次调用里直接传 `confirm=true`。

## 何时使用

- 用户说"把这段视频发到小红书"、"发布小红书笔记"、"发红书" → 发布笔记
- 用户给出本地视频或图片路径 + 标题（可选正文），要求发到小红书 → 发布笔记
- 用户说"帮我发小红书"、"上传图文到小红书账号" → 发布笔记

## 边界

- **不做数据采集** —— 笔记搜索 / 详情 / 评论采集请用 `xiaohongshu-crawl`
- **不做数据分析** —— 账号/笔记数据统计与报告请用 `xiaohongshu-analytics`
- **不做评论互动、私信**
- **不生成文案** —— 标题与正文由用户提供（或先用通用文案技能生成，再回到本技能发布）
- **只支持视频笔记与图文笔记** —— 长文、播客、定时发布、自定义封面、合集/地点/话题选择当前不支持
- 素材必须是**本机绝对路径**且真实存在；技能不做下载，用户需先备好文件
- 限制：标题 **≤ 20 字**、正文 **≤ 1000 字**、图文 **≤ 18 张**；视频仅支持 mp4/mov/flv/f4v/mkv/rm/rmvb/m4v/mpg/mpeg/ts，图片仅支持 jpg/jpeg/png/webp。超限或格式不符会在调用前被拦下
- 发布过程会**弹出可见浏览器窗口**（真实操作，用户可见）；若出现滑块/安全验证需人工完成
- 同一时间只能有一个小红书发布窗口；已有窗口进行中时需等待其结束

## 执行流程

本技能**没有脚本入口**，执行方式是**直接调用 host 工具** `dsagent_xiaohongshu_publish`。

### 1. 收集参数

从用户话里提取，缺项就主动问：

| 参数 | 必需 | 说明 |
|------|------|------|
| `videoPath` | 二选一 | 本地视频文件**绝对路径**（如 `D:\videos\demo.mp4`），走视频笔记 |
| `imagePaths` | 二选一 | 本地图片**绝对路径**，多张用英文逗号分隔（或传 JSON 数组字符串），≤ 18 张，走图文笔记 |
| `title` | 是 | 笔记标题，**≤ 20 字** |
| `content` | 否 | 笔记正文，可含 `#话题`，**≤ 1000 字** |

`videoPath` 与 `imagePaths` **只能二选一**，同时传会被拦下。

### 2. 先取「发布预览」（不带 confirm）

调用 `dsagent_xiaohongshu_publish`，**只传素材与文案，不要传 `confirm`**：

```
dsagent_xiaohongshu_publish(imagePaths="D:\img\1.jpg,D:\img\2.jpg", title="秋天穿搭分享", content="今天分享三套日常穿搭 #穿搭 #秋冬")
```

工具此时**不会启动浏览器、不产生任何写操作**，只返回一段「发布预览」文本（含账号、类型、素材、标题、正文）。

### 3. 把预览完整展示给用户并征求明确同意

把预览内容原样呈现给用户，并明确问一句类似"确认要发布吗？"。
**这一步不可跳过、不可自行假设用户同意**（L2 风险门禁）。

### 4. 用户同意后带 `confirm=true` 重新调用

```
dsagent_xiaohongshu_publish(imagePaths="D:\img\1.jpg,D:\img\2.jpg", title="秋天穿搭分享", content="今天分享三套日常穿搭 #穿搭 #秋冬", confirm=true)
```

工具会弹出可见浏览器窗口，依次完成：注入登录态 → 打开发布页（图文/视频）→ 上传素材 → 等编辑区 → 填标题 → 填正文 → 点「发布笔记」→ 判定结果。

### 5. 报告结果

- 成功：告知已提交，并说明**平台可能仍在审核**，最终状态以小红书创作服务平台「笔记管理」为准
- 失败：按返回的 `failureKind` 走下方「错误处理」

## 错误处理

| 场景 | failureKind | 引导动作 |
|------|-------------|---------|
| 未绑定小红书账号 | `not_bound` | 引导用户到「账号连接」页面扫码登录小红书账号 |
| 平台有多个可用账号且当前会话未绑定 | `need_account_choice` | **把候选列表给用户选**，把选定的 `shopKey` 填进 `account` 参数重调；★ 绝不要自己挑一个 |
| 发布页被重定向到登录页 | `token_expired` | 引导用户到「账号连接」页面**重新登录**小红书 |
| 素材文件不存在 / 标题超 20 字 / 正文超 1000 字 / 图片超 18 张 / 格式不支持 | `api_error` | 按提示修正参数后重试 |
| `videoPath` 与 `imagePaths` 同时传或都未传 | `api_error` | 二选一后重试 |
| 上传后未出现编辑区 | `api_error` | 可能是素材格式不支持或上传被风控；让用户确认格式（建议 mp4 / jpg），必要时重试 |
| 找不到标题框 / 正文区 / 发布按钮 | `api_error` | 页面结构可能变更，请上报该问题 |
| 点击发布后未检测到成功标志 | `api_error` | 让用户查看弹出的浏览器窗口内的具体提示；若有滑块需人工完成 |

## 环境变量

本技能为纯指令型，不执行脚本，无环境变量依赖。
账号凭证由 host 工具从凭证库直接读取，**技能侧不接触 Cookie**。
