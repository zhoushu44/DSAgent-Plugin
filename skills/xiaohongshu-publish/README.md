# 小红书·内容发布（xiaohongshu-publish）

> 一句话定位：把本地的图片或视频素材上传发布为小红书笔记，自动填写标题与正文并提交发布。

## 能力
- 发布**图文笔记**：本地多张图片（≤ 18 张）+ 标题 + 正文。
- 发布**视频笔记**：本地视频文件（mp4/mov 等格式）+ 标题 + 正文。
- 自动注入登录态、打开小红书发布页并完成上传、填标题、填正文、点发布。
- **可做**：视频笔记与图文笔记发布。
- **不可做**：数据采集、数据分析、评论互动、私信；不生成文案；也不支持长文、播客、定时发布、自定义封面、合集/地点/话题选择。

## 触发方式（自然语言示例）
- 「把这段视频发到小红书」
- 「发布小红书笔记 / 发红书」
- 「帮我发小红书 / 上传图文到小红书」

## 输入
| 参数 | 必需 | 说明 |
|------|:----:|------|
| `videoPath` | 二选一 | 本地视频**绝对路径**（如 `D:\videos\demo.mp4`），走视频笔记 |
| `imagePaths` | 二选一 | 本地图片**绝对路径**，多张用英文逗号分隔，≤ 18 张，走图文笔记 |
| `title` | 是 | 笔记标题，**≤ 20 字** |
| `content` | 否 | 笔记正文，可含 `#话题`，**≤ 1000 字** |
| `confirm` | 特殊 | **仅在用户明确同意发布后才传 `true`**，用于真正提交 |

> `videoPath` 与 `imagePaths` **只能二选一**，同时传会被拦下。

## 限制与边界
- ★ **发布是 L2 真实操作且不可撤销，采用两步式流程**：先不带 `confirm` 调用拿「发布预览」，展示给用户并获**明确同意**后，再带 `confirm=true` 重新调用真正提交。绝不可在一次调用里直接 `confirm=true`。
- 素材须为本机真实存在的绝对路径；技能不做下载。
- 限制：标题 ≤ 20 字、正文 ≤ 1000 字、图文 ≤ 18 张。
- 格式限制：视频 mp4/mov/flv/f4v/mkv/rm/rmvb/m4v/mpg/mpeg/ts；图片 jpg/jpeg/png/webp；超限或格式不符会在调用前被拦下。
- 发布会**弹出可见浏览器窗口**（真实操作，用户可见）；出现滑块/安全验证需人工完成。
- 同一时间只能有一个小红书发布窗口。

## 账号绑定
- 绑定**小红书（xhs）**平台账号，通过扫码登录获取登录态。
- 多账号时会返回候选列表让用户选择，绑定指定账号回传 `account` 参数。

## 输出
- 成功：告知已提交，并说明**平台可能仍在审核**，最终状态以小红书创作服务平台「笔记管理」为准。
- 失败：按返回的 `failureKind` 走错误处理速查。

## 错误处理速查
| 常见失败 | 处理动作 |
|---------|---------|
| 未绑定账号（`not_bound`） | 引导到「账号连接」扫码登录 |
| 多账号待选（`need_account_choice`） | 把候选列表给用户选，不要自行选择 |
| 发布页跳到登录页（`token_expired`） | 引导到「账号连接」重新登录 |
| 素材不存在 / 超字数 / 超张数 / 格式不支持 | 修正参数后重试 |
| `videoPath` 与 `imagePaths` 同时传或都未传 | 二选一后重试 |
| 上传后未出现编辑区 | 可能素材格式不支持或被风控，建议用 mp4/jpg 重试 |
| 找不到标题框/正文区/发布按钮 | 页面结构可能变更，上报问题 |
| 点发布后未检测到成功标志 | 查看弹出窗口内的提示，有滑块需人工完成 |

## 相关技能
- 素材调研取数：`xiaohongshu-crawl`
- 经营数据分析：`xiaohongshu-analytics`（当前未实现）
- 文案排版生成：`smart-compose`
