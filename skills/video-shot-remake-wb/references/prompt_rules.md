# 提示词速查

## 视频 prompt 顺序

1. Camera
2. Subject
3. Space
4. Audio constraints

## 默认负面 / 约束

- 独立旁白轨时：视频 prompt 不写旁白正文
- 默认加：`no music`
- 默认加：`no subtitles`

## 多节拍

用 `Shot1 / Shot2 / cut to` 描述顺序，不要写不可靠的精确秒表计划。

## 模板复刻锚定

每镜 prompt 必须包含：

1. 新主体/产品的稳定外观锚点（来自元素描述）
2. 参考关键帧的构图与光影
3. 与原片一致的景别与运镜
4. 可替换内容（新台词/产品动作）
