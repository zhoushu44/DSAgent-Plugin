| 全店推广结论 | 推广整体规模、效率、成交贡献与经营质量的判断 + 主要风险 |

## 1. 数据准备（取数清单）

### 全店推广计划分析表（必需 · 周期总览 + 每日趋势）

用途：全店推广计划的流量、花费、成交、回报与每日趋势。

| 数据集 | 字段 |
|---|---|
| sycm.alimama_item_promotion | campaignId 计划 ID、scene1Name 场景、inshopPotentialUvRate 潜客占比、adPv 展现、click 点击、ctr 点击率、charge 花费、ecpc 平均点击花费、ecpm 千次展现花费、alipayInshopAmt 成交金额、roi 投产比、cartRate 加购率、cvr 点击转化率、alipayInshopNum 成交笔数、alipayDirAmt 直接成交金额、alipayDirNum 直接成交笔数、alipayInshopCost 成交成本、inshopPotentialUv 引导潜客数、cartInshopNum 加购数、cartDirNum 直接加购、cartCost 加购成本、wwNum 旺旺咨询数、campaignName 计划名称（可选） |

### 店铺经营分析表（必需 · 周期总览 + 每日趋势）

用途：对照店铺实际流量、成交、转化与退款，判断推广投入和经营结果是否匹配。

| 数据集 | 字段 |
|---|---|
| sycm.core_index | uv 访客数、payAmt 支付金额、netPaymentAmount 净支付金额、payByrCnt 支付买家数、payRate 支付转化率、payItmCnt 支付件数、rfdSucAmt 成功退款金额 |

### 商品推广分析表（必需 · 周期总览）

用途：建立商品与推广计划的可靠关联，识别商品和计划的推广贡献、低效消耗与风险。

| 数据集 | 字段 |
|---|---|
| sycm.alimama_item_promotion | campaignId 计划 ID、scene1Name 场景、inshopPotentialUvRate 潜客占比、adPv 展现、click 点击、ctr 点击率、charge 花费、ecpc 平均点击花费、alipayInshopAmt 成交金额、roi 投产比、cartRate 加购率、cvr 点击转化率、alipayInshopNum 成交笔数、alipayDirAmt 直接成交金额、alipayDirNum 直接成交笔数、alipayInshopCost 成交成本、inshopPotentialUv 引导潜客数、cartInshopNum 加购数、cartDirNum 直接加购、cartCost 加购成本、wwNum 旺旺咨询数、campaignName 计划名称（可选） |

### 取数规则

- 必须同时使用周期汇总和每日趋势：先判断全周期结构，再核对重点计划与店铺每日花费、成交、投产比和经营结果的变化。
- 重点计划按**实际有数据的日期**计算覆盖天数；不得用整个分析周期天数代替单计划有效天数，日期不足时不得写「连续 N 天」。
- 筛选、排序和阈值判断必须使用**未四舍五入的原始值**，并明确比较符号（< / ≤ 等）；四舍五入只用于展示，不得改变入选结果。
- 重点计划同时展示计划名称和计划 ID；名称缺失时明确标记「名称未返回」，不得用 ID 冒充名称。
- 缺失、未知、未采集、归因未成熟都不等于 0。

## 3. AI 分析要求

**分析目标**：全店推广深度诊断。

### 判断顺序

1. 先确认分析周期、经营目标、数据完整性、推广类型和归因口径，判断当前证据能够支持到店铺、商品、场景还是计划级诊断。
2. 先看全店推广投入、推广成交和实际经营结果，判断推广整体规模、效率和经营质量。
3. 再比较不同推广类型和商品的投入与成交贡献，识别主要贡献来源、资源集中、低效消耗和潜在增长机会。
4. 对重点异常对象使用计划通用规则判断问题发生在流量、点击、意向、成交、经营质量还是稳定性。
5. 确认具体推广类型后，再使用关键词、人群、全站推广等专项规则解释该类型特有问题。
6. 最后综合经营影响、紧迫程度和证据确定性确定问题优先级，并决定需要下钻和执行的对象。
7. 必须同时使用周期汇总和每日趋势：先判断全周期结构，再核对重点计划与店铺每日花费、成交、投产比和经营结果的变化。
8. 对重点计划必须按实际有数据的日期计算覆盖天数；不得用整个分析周期天数代替单计划有效天数，也不得在日期不足时写「连续 N 天」。
9. 筛选、排序和阈值判断必须使用未四舍五入的原始值，并明确使用小于、小于等于等比较符号；四舍五入只用于展示，不得改变入选结果。

### 必须回答的问题

- 当前全店推广整体表现是否健康，投入、成交贡献和经营回报之间是否匹配？
- 关键词推广、人群推广、全站推广等不同推广类型分别承担什么经营角色，哪些是主要贡献、增长机会或风险来源？
- 当前推广问题主要发生在流量获取、点击响应、意向承接、成交转化、经营质量还是稳定性？
- 哪些商品和推广计划贡献了主要推广成交，哪些正在形成明显低效消耗或经营风险？
- 推广投入增加是否真正带来了店铺或商品的有效经营增量，是否存在增量不足或经营质量承压？
- 当前最值得优先处理哪些推广问题，哪些需要继续下钻到商品、计划、关键词、人群或其他专项对象？

### 证据要求

- 全店推广结论必须具有同周期、口径可解释的推广投入、推广成交和店铺实际经营结果，不能仅依据推广平台归因数据判断整体经营健康。
- 推广类型、商品和计划的贡献或风险判断必须使用对应粒度证据；结论粒度不得超过数据粒度。
- 投入集中、低效消耗或增长机会必须同时结合实际投入规模、成交贡献、效率和样本稳定性，不能只依据 ROI 排名。
- 推广真实增量判断必须比较推广变化与商品或店铺实际经营结果；缺少来源或增量证据时只能标记「增量贡献存疑」。
- 具体计划诊断必须具有计划级证据，关键词、人群等内部对象结论必须具有对应明细；不得从汇总数据向下猜测。
- 数据缺失、归因未成熟、样本不足或对象无法关联时必须降低结论强度并记录 `missing_evidence`，不得将未知解释为零效果。
- 声称「连续 N 天」「持续恶化」或「表现稳定」时，必须提供该对象实际 N 个有效日期的逐日证据；覆盖不足时写明实际天数并降低结论强度。
- 缺少目标值、历史同期或类目基线时，不得直接写「偏高」或「偏低」；只能描述当前数值、结构影响，并标记待对比基线。
- 缺少毛利、商品成本、履约和其他利润证据时，不得使用「盈利」「亏损」或「利润来源」；只能描述推广归因回报、成交贡献和效率。
- 全站推广、人群推广的扩量建议必须有投放阶段、每日稳定性或边际变化证据；证据不足时只能建议小范围验证，并列入 `missing_evidence`。

### 期望输出

- 全店推广整体经营结论：推广投入、成交贡献、经营质量和主要风险。
- 不同推广类型及重点商品的贡献结构：主要贡献、低效消耗、增长机会和结构依赖。
- 最重要的推广问题及优先级：问题对象、关键证据、经营影响和证据确定性。
- 重点异常计划的健康状态和问题环节，并在证据支持时补充关键词、人群或全站推广专项判断。
- 需要保持、验证、修复、收紧或继续下钻的推广对象；具体强动作不得超过当前证据粒度。
- `missing_evidence` 和后续下钻清单：还需要补什么证据、分析什么对象、验证什么问题。
- 每日趋势与稳定性核查：重点计划实际覆盖日期数、逐日花费与成交变化，以及店铺经营结果是否同步。
- 所有强弱判断注明所用基线；无基线时改为现状描述和待验证项。

## 4. 报告

- 标题：**全店推广深度诊断报告**
- 格式：HTML；大纲固定为 9 节：
  1. 全店推广结论摘要
  2. 推广投入与成交结构
  3. 重点商品与推广类型表现
  4. 每日趋势与稳定性
  5. 核心问题与风险
  6. 重点计划深度诊断
  7. 专项下钻发现
  8. 推广动作与资源调整优先级
  9. 待补证据与后续复盘
- 输出契约：
  - 必须覆盖所有 finding、evidence、knowledge_basis 和 recommendation，结论必须附带证据与行动建议。
  - 运行 ID、步骤 ID、方法 ID、节点 ID、finding / evidence / recommendation 等内部追踪 ID 只保留在 `data-*` 属性中，不进正文。
  - 计划 ID、商品 ID、SKU ID 等业务标识按上游结果正常展示；上游已返回名称时，每次出现业务 ID 都必须同时展示对应名称。
  - 报告需**人工确认后**再定稿。

## 5. 禁止与边界

- 不得仅依据推广平台归因数据判断整体经营健康，也不得只依据 ROI 排名判断低效或增长机会。
- 不得从汇总数据向下猜测计划、关键词或人群级结论；结论粒度不得超过数据粒度。
- 缺少利润证据时不得使用「盈利 / 亏损 / 利润来源」；缺少基线时不得写「偏高 / 偏低」。
- 不得把未知、缺失、归因未成熟解释为零效果。
- 强动作（加预算 / 停推 / 调整出价）必须同时具备对象、周期、投入规模、产出证据和判断标准；证据不足只能建议观察、补数或小范围验证。
- 本技能覆盖全店推广结构层；单计划的预算-ROI 放量测算、类目结构与货品分层走各自专项技能。
