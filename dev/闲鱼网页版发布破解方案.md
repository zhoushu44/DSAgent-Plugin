# 闲鱼网页版发布「数字/服务类商品」的破解方案（实测）

> 结论（2026-10-15 实测）：**闲鱼网页版可以发布 API/数字类商品**。
> 关键不是「网页版不支持」，而是**发布页的「分类」是一个可选下拉框，必须手动选到「其他闲置」**。

---

## 一、问题现象

用 `xianyu-publish` 技能发 API 类商品时，稳定报错：

```
发布失败：该分类暂不支持在网页版发布，页面要求「扫码去APP发布」。
[failureKind] api_error
```

页面文本：`分类 * DeepSeek服务 网页版暂不支持发布此分类，请使用闲鱼APP扫码继续发布 点击展示二维码`

---

## 二、根因

### 1. 分类是**自动识别 + 可手动改**的下拉框，不是只读展示

发布页的「分类」字段 DOM 结构：

```html
<label title="分类">分类<span>*</span></label>
<div class="ant-select ant-select-outlined ...">      <!-- ← 可交互的下拉框 -->
  <div class="ant-select-selector">
    <input type="search" role="combobox" aria-expanded="false"
           aria-owns="rc_select_0_list" ...>
  </div>
</div>
```

平台先用 `mtop.taobao.idle.kgraph.property.recommend` 按**图片+描述自动预测**一个分类
（`categoryPredictResult`），但**用户可以在下拉框里改选**。

### 2. 部分分类被标记为「网页版不可发」

`mtop.idle.item.publish.service.cards.list` 等接口会针对**选中的分类**返回
「网页版暂不支持发布此分类」的提示。AI/软件/服务类分类**全部**命中：

| 自动识别的分类 | channelCatId | 网页版可发 |
|---|---|---|
| DeepSeek服务 | 202148345 | ❌ |
| AI模型训练 | 202038701 | ❌ |
| AI提效工具 | 202152829 | ❌ |
| 软件/程序/网站开发 | 201453616 | ❌ |
| 系统安装升级 | — | ❌ |
| 网络及软硬件维护服务 | — | ❌ |
| **其他闲置** | 201459411 | ✅ **可发** |

### 3. 「其他闲置」在每一批候选里都存在

实测不同描述触发的候选集，**「其他闲置」始终在列**，这是通用的兜底出口。

---

## 三、解决方案

### 手工操作（闲鱼网页版）

1. 上传主图 → 填描述 → 填价格
2. 点「**分类**」下拉框
3. 选「**其他闲置**」
4. 页面上「网页版暂不支持发布此分类」的提示**立即消失**
5. 点「发布」→ 成功跳转到 `https://www.goofish.com/item?id=<新商品ID>`

### 自动化要点（给技能实现）

```js
// 1. 定位分类下拉框（按 label[title=分类] → .ant-form-item → .ant-select）
const box = await page.evaluate(() => {
  const lab = Array.from(document.querySelectorAll('label'))
    .find(l => (l.getAttribute('title') || l.innerText || '').trim().startsWith('分类'))
  const sel = lab?.closest('.ant-form-item')?.querySelector('.ant-select')
  if (!sel) return null
  const r = sel.getBoundingClientRect()
  return { x: Math.round(r.x + r.width / 2), y: Math.round(r.y + r.height / 2) }
})

// 2. 点开下拉
await page.mouse.click(box.x, box.y)
await sleep(3000)

// 3. 选「其他闲置」（antd 需要 mousedown+mouseup+click 才生效）
await page.evaluate(() => {
  const t = Array.from(document.querySelectorAll('.ant-select-item-option'))
    .find(e => (e.textContent || '').trim() === '其他闲置')
  if (!t) return
  t.scrollIntoView({ block: 'center' })
  t.dispatchEvent(new MouseEvent('mousedown', { bubbles: true }))
  t.dispatchEvent(new MouseEvent('mouseup', { bubbles: true }))
  t.click()
})
await sleep(9000)

// 4. 校验：提示消失 + 分类名变为「其他闲置」
const ok = await page.evaluate(() => {
  const t = (document.body?.innerText || '').replace(/\s+/g, ' ')
  return !/网页版暂不支持发布此分类|请使用闲鱼APP扫码/.test(t)
})
```

## 四、关键实现细节（踩坑记录）

| 坑 | 说明 |
|---|---|
| 不能只用 `page.click()` 选选项 | antd Select 需要 `mousedown` + `mouseup` + `click` 三连才触发 onChange |
| 不能用 evaluate 直接改 value | 分类是 React 受控组件，必须走真实鼠标/键盘事件 |
| 下拉选项要先 `scrollIntoView` | 选项多时目标可能不在可视区，直接点会失败 |
| 选完要等 ~9 秒 | 选分类会触发服务端重新校验（cards.list / recommend），需等待提示刷新 |
| 「其他闲置」是通用兜底 | 每批候选都有它，可作为自动化时的固定目标 |
| 描述会二次影响候选集 | 换描述后候选集变化，但「其他闲置」始终存在 |

---

## 五、注意事项与风险

1. **类目选择的合规性**：把 API 商品挂在「其他闲置」下，是平台允许的通用兜底类目，
   但**不等同于平台认可该品类交易**。仍受闲鱼虚拟商品风控约束。
2. **重复铺货**：同关键词多链接必须换主图换文案，否则判重下架。
3. **描述不要提敏感词**：实测竞品在描述里写「请勿私聊敏感词（含英文及带英文的截图），关键词请用汉字谐音代替」，
   说明平台对 API 类商品有敏感词审查。
4. **建议改进 xianyu-publish 技能**：在点发布前自动检测「网页版暂不支持」提示，
   若命中则自动改选「其他闲置」再发布，把本方案固化进技能。
