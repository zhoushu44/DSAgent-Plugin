# DS上架工具（豆包版）—— 安装与使用

淘宝 + 拼多多商品上架、拼多多数据采集。给豆包（或任何 MCP 客户端）调用。
逆向（签名/Cookie/页面驱动）全部在本文件夹引擎内部，豆包只见标准工具，合规可用。

---

## 一、安装（每台电脑一次，约 15 分钟）

### 1. 装 Node.js（≥18）
- 打开 https://nodejs.org → 下载 **LTS** 安装包 → 一路下一步；
- 验证：按 Win 键搜「PowerShell」打开，输入 `node -v` 回车，显示版本号（如 v22.x）即成功。

### 2. 装 Chrome
- 一般电脑已有。没有就到 https://www.google.com/chrome/ 装一个（上架用无界面 Chrome，不动你平时的浏览器）。

### 3. 扫码登录（必做）
- **淘宝**：双击 **login-taobao.ps1**（右键「使用 PowerShell 运行」）→ 弹出浏览器 → 手机淘宝 App 扫码 → 显示「登录态已保存 ✓」→ 关闭；
- **拼多多**（要上架拼多多/查数据才需要）：双击 **login-pdd.ps1** → 拼多多商家 App 扫码。

### 4. 给豆包接上工具
- 打开豆包 PC 版 → 设置 → MCP / 扩展 → 添加自定义 MCP Server：
  - **命令**：`node`
  - **参数**：本文件夹 mcp-server.cjs 的完整路径，例如
    `C:\Users\你的用户名\Desktop\doubao\mcp-server.cjs`
- 保存后豆包里会出现 **5 个工具**：

| 工具 | 作用 | 会真的提交吗 |
|---|---|---|
| upgrade | 升级引擎（git pull 最新版） | 否 |
| publish_preview | 上架预览：填好一切，返回预览+taskId | **否** |
| publish_confirm | 确认提交（要 taskId，10 分钟内有效） | **是** |
| check_listing | 买家页验证：标题/价格/是否已下架+截图 | 否 |
| collect_pdd | 拼多多数据采集：搜索/详情/推荐流 | 否（只读） |

## 二、日常使用（直接对豆包说人话）

**上架商品**（豆包会先出预览问你，确认才提交）：
```
帮我把 D:\商品\马克杯.json 上架到淘宝
```

**拼多多查数据**：
```
搜一下拼多多上「马克杯」卖多少钱
```

**验证商品**：
```
看看 1102232586945 这个商品现在什么状态
```

**升级引擎**（你改完代码 push 后，豆包机器上）：
```
升级一下
```
→ 豆包自动 git pull → **重启豆包**生效。

## 三、商品 JSON 格式（给豆包的商品文件照这个写）

```json
{
  "catId": 50006119,
  "title": "陶瓷马克杯办公水杯定制",
  "price": "19.9", "stock": "200", "itemNo": "SKU001",
  "images": ["D:\\图\\杯子主图.jpg"],
  "specs": [{ "name": "颜色分类", "values": [{ "value": "白色" }, { "value": "黑色" }] }],
  "skus": [
    { "specs": { "颜色分类": "白色" }, "price": "19.9", "stock": "100", "outerId": "SKU001-W" },
    { "specs": { "颜色分类": "黑色" }, "price": "19.9", "stock": "100", "outerId": "SKU001-B" }
  ],
  "fillAllAttrs": true
}
```

- **淘宝**必填：`catId`（叶子类目 ID）、`title`（≤30 个汉字）、`skus`；
- **拼多多**必填：`title`（≤60 字）、`images`（1~10 张本地图片路径）、`skus`；上架时对豆包说「上架到拼多多」并告知账号 shopKey；
- `fillAllAttrs: true` = 自动填满该类目所有可填属性（品牌除外，品牌必须人工填）；
- 服装类目加 `"sizeTable": { "M": ["160","50","90"], "L": ["165","55","94"] }`。

## 四、常见问题

| 问题 | 处理 |
|---|---|
| 报「Cookie 缺登录态」/ 页面跳登录 | 重新双击 login-taobao.ps1（或 login-pdd.ps1）扫码 |
| 预览 10 分钟没确认 | taskId 过期，让豆包重新 preview |
| 「拼多多需要 account」 | 告诉豆包 shopKey（登录后写入凭证库的账号标识） |
| 提交后没结果 | 看 `out\` 文件夹截图，成功页有商品编号 |
| 升级后没变化 | 重启豆包（MCP 服务是启动时加载的） |
| 仓库里已有同款商品 | 引擎不查重，重发会重复上架，自己留意 |
