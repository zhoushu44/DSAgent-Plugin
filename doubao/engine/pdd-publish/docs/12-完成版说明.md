## 规格流程（step11）

```
【1】读模板 → tpl.specs.dimensions.length（预置维度数量）
【2】预置维度 = 0 → 走「添加规格」流程（不看页面探测）
     预置维度 > 0 → 按模板填，多出的补加
【3】逐维度判断
     预设值数量 = 0 → 看控件
                      ct=0 → 输入框
                      vt=1 → 数值
                      其他  → 文本
     预设值数量 > 0 → 看 group
                      group 是尺码标签 → 尺码表
                      （通用/中国码/欧码/英码/德码/美码/均码/
                        身高/国际标准/法码/日本码/韩国码）
                      否则 → 勾选框
【4】执行
     尺码表：查 group 切标签页 → 勾值 → 停用尺码表
     勾选框：先写值 → 再勾选
     输入框：第 i 个值 → 第 i 个框
     添加规格：点 button → 点 input 弹下拉 → 选维度 → 填值 → 点空白
【5】校验行数 = 各维度值数量相乘
```

### 定制规格界面（fill-custom-spec2.mjs）

适用模板无预置维度的类目（四件套）。

```
① 点 <button> 内含「添加规格类型」
   ★ 点外层 div 不触发下拉，必须点 button
   ★ 文字带 (0/2)、(1/2)，用包含匹配
② 等 input[placeholder="规格类型N"] 出现
③ ★ 点这个 input（+ mousedown/mouseup/click）才弹下拉
④ 下拉选维度名
   ul[role="listbox"] li[role="option"]
   纯名字取每项第一个文本节点（去「常用」标签）
   匹配：精确 → 前缀 → 包含 → 第一个
⑤ 填值 input[placeholder="请输入规格名称"]
   不够 → 点「添加定制规格」
⑥ ★ 每写一个值点一次空白（.Form_itemLabelWrapper）
   不点 → 值丢失 → SKU 表不生成
⑦ 按 specs 数组顺序循环（颜色第1、尺寸第2）
```

## 属性流程（step6）

```
【1】读模板属性 tpl.attributes[]
【2】值预校验：不在 options 里的值直接剔除
【3】扫页面属性区
     ★ 等「扫到属性数 >= 模板属性数」（最多 20 秒）
     不能「扫到任意 1 个就停」
     页面分批渲染：先出「运费模板」，属性区在后面
【4】逐个填
     ★ 每属性重扫 labelMap（级联属性：选完上一个下一个才出现）
     ★ label 归一化（去 * / ＊ / 「重要」前缀 / 空格）
     调 selectOptions 选值 → 等回填确认
【5】自动补必填（页面有 * 但模板里没有的动态属性）
【6】返回 ok / results / unmapped / autoRequired / droppedAttrs
```

## 价格库存（step12）

```
【1】读表头找列号
【2】行内定位：用「该行第 N 个 text input」
     库存 → 拼单价 → 单买价 → 规格编码 → 商品编码
     规格列只有文字无 input；预览图是 file input 已跳过
【3】★ 写入顺序：库存 → 单买价 → 拼单价 → 编码
     必须先写单买价：平台联动校验「拼单价 < 单买价」
     先写拼单价 → 被 React 判非法清空
【4】★ 每写一个值单独 evaluate + 回读
     同一次 evaluate 连写会被重渲染冲掉
【5】每行写完等 400ms
【6】回读不一致只记 warning，不阻断
```

## 关键修复记录

| 问题 | 根因 | 修法 |
|---|---|---|
| 四件套 13 属性全 unmapped | 扫到「运费模板」就 break，属性区还没渲染 | 等扫到 >= 模板属性数 |
| 四件套规格只有 2 行 | 每写一个值点空白会冲掉已填值 | 每写一个值点一次空白 |
| 四件套下拉不弹 | 点外层 div 不触发 | 必须点 `<button>` |
| 卫衣/牛仔裤判成勾选框 | `control_type=3` 先于 group 判断 | group 判断提到最前 |
| 拼单价写不进去 | 先写拼单价时单买价为空，联动校验清空 | 先写单买价 |
| 标题被拒 | 中文算 2 字符，30 汉字 = 60 字符 | titleWeight + cutTitle |
| 模板 maxDims=0 报错 | 四件套模板记 0 但页面能加 2 维 | maxDims=0 跳过校验 |
