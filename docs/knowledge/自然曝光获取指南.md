# 自然曝光获取指南

> 不花钱怎么拿到曝光？本文深入挖掘新品如何最大化获取自然曝光——
> 从新品扶持流量、搜索排名优化、推荐流量获取三个方向，讲透"怎么拿到更多免费曝光"。
> 解决测图和测款期的"没曝光"卡点。

---

## 自然曝光的三个来源

新品上架后，不花钱也能拿到的曝光来自三个方向：

```
                    自然曝光
                   /    |    \
          新品扶持流量  搜索匹配流量  推荐流量
          (平台给的)   (标题匹配的) (属性标签的)
```

| 来源 | 本质 | 你能控制什么 | 曝光量级 |
|---|---|---|---|
| 新品扶持流量 | 平台给新品的初始观察流量 | 上架时机/初始数据表现 | 中（几十到几百/天，7-14天） |
| 搜索匹配流量 | 用户搜索词匹配到你的标题 | 标题关键词/类目/权重 | 取决于排名（靠前多靠后少） |
| 推荐流量 | 系统根据属性标签推荐 | 商品属性/标签/主图规范 | 不稳定（可能突然来一波） |

## 来源一：新品扶持流量

### 是什么

> 平台给新品的"初始观察期流量"——让新品有机会被看到，平台观察数据表现决定后续给不给更多。

平台逻辑：
1. 新品上架 → 平台分配初始曝光（几十到几百/天）
2. 观察新品数据表现 → CTR/收藏加购率/转化率/停留时长
3. 表现好 → 继续给流量（扶持期结束后过渡到正常权重）
4. 表现差 → 减少流量（扶持期结束后流量断崖）

### 怎么拿到更多新品扶持

| 动作 | 怎么做 | 为什么有效 |
|---|---|---|
| **抓住扶持期** | 上架后7-14天是黄金期，不要浪费 | 扶持期流量是免费的，过了就没有 |
| **上架即优化好** | 标题/主图/详情页/SKU/属性在上架前全部准备好 | 扶持期数据差=平台判定新品不行=流量断 |
| **上架时机选对** | 旺季前1-2个月上架（旺季流量大扶持效果放大） | 旺季搜索量大，同样扶持比例能拿更多曝光 |
| **初始数据要好** | CTR≥行业均值、收藏加购≥5%、有首单 | 数据好=平台给更多流量=正向循环 |

### 深入：扶持期数据决定了后续流量

> 扶持期不是"白给的"——平台在观察你的数据表现，表现好才继续给。

| 扶持期数据表现 | 扶持期结束后 | 结果 |
|---|---|---|
| CTR高+收藏加购好+有转化 | 继续给流量，过渡到正常权重 | ✅ 流量持续 |
| CTR低或收藏加购差 | 减少流量，扶持期结束后断崖 | ❌ 流量消失 |
| 有曝光但完全无点击 | 平台判定新品不行，快速减少流量 | ❌ 最差情况 |

> **所以扶持期不是"等流量来"，是"用最好的状态迎接流量"——主图CTR好+标题精准+详情页完整+SKU齐全。**

### 深入：上架时机怎么选

| 时机 | 效果 | 适合 |
|---|---|---|
| 旺季前1-2个月 | 最佳——旺季搜索量大，扶持曝光放大 | 季节性产品（防晒霜4月上、羽绒服9月上） |
| 日常时段 | 正常——搜索量稳定，扶持正常 | 全年需求稳定的产品 |
| 旺季中 | 差——竞争最激烈，新品扶持被淹没 | 不推荐（除非有强力推广配合） |
| 淡季 | 差——搜索量低，扶持曝光也低 | 不推荐 |

## 来源二：搜索匹配流量

### 是什么

> 用户搜索关键词 → 平台匹配标题含该词的商品 → 按权重排序展示 → 你的商品出现在搜索结果里。

流程：
```
用户搜索"便携榨汁杯"
    ↓
平台匹配标题含"便携榨汁杯"的商品
    ↓
按权重排序（销量/评价/CTR/转化率/权重分）
    ↓
新品权重低 → 排名靠后 → 曝光少
    ↓
但只要标题含核心词 → 还是会有一些曝光
```

### 怎么拿到更多搜索匹配流量

#### 1. 标题优化（最核心）

> 标题是搜索匹配的第一入口——标题没有核心词，搜索就匹配不到你。

**标题优化步骤**：

| 步骤 | 做什么 | 用什么技能 |
|---|---|---|
| 1. 查核心词 | 查这个品用户搜什么词最多 | keyword-assistant（搜索人气排序） |
| 2. 查长尾词 | 查精准长尾词（竞争小转化高） | keyword-assistant（供需比排序找蓝海词） |
| 3. 查免费点击率高的词 | 查哪些词免费点击率高（不花钱也能来流量） | keyword-assistant（free_click_rate字段） |
| 4. 组合标题 | 核心词+长尾词+属性词组合 | — |
| 5. 验证 | 搜核心词看能不能搜到自己 | market-analysis（搜关键词看结果） |

**标题组合规则**：
- 核心词放前面（权重更高）
- 长尾词放中间（精准匹配长尾搜索）
- 属性词放后面（补充匹配维度）
- 不要堆砌无关词（影响权重）

**用 keyword-assistant 查什么**：

| 查什么 | 命令 | 看什么字段 |
|---|---|---|
| 核心搜索词 | `expand 种子词` | search_popularity（搜索人气，越高越好） |
| 蓝海长尾词 | `expand 种子词` 按供需比排序 | demand_supply_ratio（供需比，越高越蓝海） |
| 免费流量词 | `expand 种子词` | free_click_rate（免费点击率，越高越能拿免费流量） |
| 高转化词 | `expand 种子词` 按 payByrCnt 排序 | pay_conv_rate（转化率，越高越好） |
| 飙升词 | `rank --rank_type rise` | 搜索人气环比上升的词（蹭趋势） |

#### 2. 类目正确

> 类目选错 = 搜索匹配不上 = 没有自然搜索曝光。

| 问题 | 后果 |
|---|---|
| 类目选错 | 用户搜核心词时，平台不把你算进这个类目 → 不展示 |
| 类目选对但层级太深 | 可能错过上级类目的流量 |
| 类目选对 | 搜索匹配正常，有机会获得曝光 |

**怎么确认类目对**：
- 用 market-analysis 搜核心词，看返回的商品是什么类目
- 自己的类目和竞品类目一致 = 对了

#### 3. 权重积累

> 新品权重低排名靠后，但权重会随数据积累提升。

| 权重因素 | 新品怎么积累 |
|---|---|
| 销量 | 扶持期有首单就开始积累 |
| 评价 | 引导首批买家留好评 |
| CTR | 主图好 → CTR高 → 权重提升 |
| 转化率 | 详情页/SKU/价格好 → 转化高 → 权重提升 |
| 停留时长 | 详情页内容好 → 停留长 → 权重提升 |

> 权重是"滚雪球"——扶持期数据好→权重提升→排名上升→更多曝光→更多数据→更高权重。
> **新品要抓住扶持期把初始权重做起来。**

### 深入：免费点击率是什么

> keyword-assistant 返回的 `free_click_rate` = 免费点击率 = 不花钱（自然搜索）的点击率。

- `click_rate`（总点击率）= 付费+免费的合计
- `free_click_rate`（免费点击率）= 只有自然搜索的

**为什么看免费点击率**：
- 免费点击率高 = 这个词在自然搜索里点击率高 = 不花钱也能来流量
- 选免费点击率高的词放标题 = 标题能拿到更多自然搜索曝光

> **这是"不花钱拿曝光"最直接的杠杆——选免费点击率高的词做标题。**

## 来源三：推荐流量

### 是什么

> 平台根据商品属性/标签，推荐给可能感兴趣的用户（猜你喜欢/推荐流）。

流程：
```
商品属性完整 + 标签准确 + 主图合规
    ↓
平台把商品放进推荐池
    ↓
用户浏览推荐流时可能看到你的商品
    ↓
曝光（不稳定，可能突然来一波）
```

### 怎么拿到更多推荐流量

| 动作 | 怎么做 | 为什么有效 |
|---|---|---|
| **属性填全** | 后台所有属性字段都填（材质/尺寸/颜色/适用场景等） | 属性越全→匹配维度越多→推荐越精准 |
| **标签打准** | 选择准确的商品标签（不要乱打） | 标签准→推荐给对的人→CTR高→继续推荐 |
| **主图合规** | 主图符合平台规范（无牛皮癣/无违规文字） | 不合规会被排除出推荐池 |
| **价格带合理** | 价格在类目主流价格带内 | 太高太低都可能被排除推荐 |
| **SKU齐全** | 覆盖主流规格需求 | SKU多→匹配需求多→推荐机会多 |

### 深入：推荐流量为什么不稳定

推荐流量和搜索流量的根本区别：

| 维度 | 搜索流量 | 推荐流量 |
|---|---|---|
| 触发 | 用户主动搜索 | 系统主动推荐 |
| 你能控制 | 标题/排名 | 属性/标签（间接） |
| 稳定性 | 相对稳定（有人搜就有） | 不稳定（系统决定推不推） |
| 量级 | 取决于排名 | 可能突然来一波也可能没有 |

> 推荐流量是"锦上添花"——不要指望它作为主要曝光来源。
> **搜索匹配流量才是新品的稳定自然曝光来源。**

## 三个来源的优先级和配合

### 优先级

| 优先级 | 来源 | 为什么 | 量级 |
|---|---|---|---|
| 1 | 新品扶持流量 | 免费+确定有（7-14天） | 中 |
| 2 | 搜索匹配流量 | 免费+稳定（只要标题含核心词） | 取决于排名 |
| 3 | 推荐流量 | 免费+不稳定 | 不确定 |

### 配合策略

```
上架前：
  - 用 keyword-assistant 查热词+蓝海词+免费点击率高的词
  - 组合标题（核心词+长尾词+属性词）
  - 确认类目正确
  - 属性填全+标签打准
  - 主图做好（CTR达标）
  - 详情页/SKU准备好

上架后（扶持期7-14天）：
  - 抓住扶持流量，用最好的状态迎接
  - 关注CTR/收藏加购/首单数据
  - 数据好→权重提升→排名上升→更多搜索流量
  - 用 market-analysis 验证能搜到自己

扶持期后：
  - 搜索匹配流量接续（靠标题+权重）
  - 推荐流量锦上添花
  - 如果自然曝光不够日均500→开小预算推广补充
```

## 自然曝光最大化检查清单

上架前：
- [ ] 用 keyword-assistant 查了核心搜索词（搜索人气高的）
- [ ] 查了蓝海长尾词（供需比高的）
- [ ] 查了免费点击率高的词（free_click_rate高的）
- [ ] 标题组合了核心词+长尾词+属性词
- [ ] 类目和竞品一致（用 market-analysis 验证）
- [ ] 属性全部填全
- [ ] 标签打准
- [ ] 主图做好（CTR达标）
- [ ] 详情页/SKU/价格准备好

上架后（扶持期）：
- [ ] 关注日均曝光有没有（≥100就有）
- [ ] CTR达标（≥行业均值）
- [ ] 收藏加购达标（≥5%）
- [ ] 有首单（7-14天内）
- [ ] 用 market-analysis 搜核心词能搜到自己

扶持期后：
- [ ] 自然搜索流量有没有接续
- [ ] 日均曝光是否≥500
- [ ] 不够500→查标题/类目/属性/违规
- [ ] 都排查了还不行→开小预算关键词推广补曝光

## 用什么技能拿自然曝光数据

| 要拿什么 | 用什么技能 | 看什么字段 | 接线状态 |
|---|---|---|---|
| 核心搜索词 | keyword-assistant | search_popularity（搜索人气） | ✅ 可用 |
| 蓝海长尾词 | keyword-assistant | demand_supply_ratio（供需比） | ✅ 可用 |
| 免费点击率高的词 | keyword-assistant | free_click_rate（免费点击率） | ✅ 可用 |
| 高转化词 | keyword-assistant | pay_conv_rate（转化率） | ✅ 可用 |
| 飙升词 | keyword-assistant rank模式 | rise（飙升榜） | ✅ 可用 |
| 搜索结果排名验证 | market-analysis | 搜关键词看能不能搜到自己 | ✅ 可用 |
| 关键词趋势/季节性 | keyword-traffic | trend（13个月趋势） | ✅ 可用 |
| 类目CTR水平 | industry-data-mcp | qiwrok_category_stats | ⚠️ MCP未接线 |

> 拿自然曝光数据的技能全部可用（除了行业类目CTR需要外部MCP）。
> **keyword-assistant 是拿自然曝光数据的核心技能**——搜索人气/供需比/免费点击率/飙升词都能查。

## 自然曝光常见误读

| 误读 | 纠正 | 为什么 |
|---|---|---|
| "不推广就没有曝光" | 有三种自然曝光来源 | 新品扶持+搜索匹配+推荐 |
| "扶持流量是白给的" | 平台在观察数据表现 | 表现差扶持期后流量断 |
| "标题随便写就行" | 标题是搜索匹配第一入口 | 没核心词=搜不到 |
| "核心词搜索量大就放标题" | 还要看免费点击率和供需比 | 免费点击率高=不花钱也来流量 |
| "类目随便选" | 类目错=搜索匹配不上 | 搜核心词看不到你 |
| "属性不用填全" | 属性不全=推荐匹配不上 | 少了推荐流量来源 |
| "推荐流量是主要来源" | 搜索匹配才是稳定来源 | 推荐不稳定可能突然断 |
| "扶持期可以慢慢优化" | 上架即优化好 | 扶持期数据差=后续流量断 |
| "旺季上架最好" | 旺季前1-2个月最好 | 旺季竞争激烈新品被淹没 |
| "免费点击率=主图CTR" | 口径不同 | 免费点击率是关键词的自然搜索点击率 |
