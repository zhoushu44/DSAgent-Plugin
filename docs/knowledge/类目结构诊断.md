# 类目结构诊断

> 判断店铺类目组合是否合理、各类目应承担什么经营任务、资源配置是否匹配。
> 含类目角色判断（11类）、结构健康判断（集中/分散/断层/重叠/资源错配）。
> 从本店 category-structure-diagnosis 技能的 knowledge 规则整理。

---

## 核心认知：类目角色由实际经营贡献决定

> 类目角色不由名称决定，不由运营主观意愿决定，不由销售排名决定。
> 必须基于实际经营证据判断。

---

## 类目角色（11类）

| 角色 | 特征 | 判断重点 |
|---|---|---|
| **核心成交** | 持续对店铺成交形成重要贡献 | 贡献规模/持续性/稳定性/对整体影响。一次活动冲高不能单独证明 |
| **增长机会** | 已有需求信号+店铺有承接空间 | 增长信号/效率/供给/链接梯队/行业机会/扩张空间。"机会"=值得验证不等于确定 |
| **引流入口** | 主要价值在获得有效访客带动后续 | 不只看访客量，要判断流量是否形成互动/收藏加购/成交/连带。大量低质量流量≠引流价值 |
| **利润贡献** | 有可靠毛利/利润证据 | 销售高/客单高/ROI高都不能替代利润证据。没利润数据不授此角色 |
| **复购/连带** | 主要价值来自老客复购/跨品购买 | 没有复购或连带证据不授此角色 |
| **品牌/形象** | 承担品牌表达/产品完整性/场景展示 | 规模小但不能仅依销售排名判没价值。需有品牌配置证据 |
| **供给补充** | 补充商品组合/规格/价格带/场景 | 规模小不必然无效 |
| **试验孵化** | 验证阶段规模有限但值得积累 | 不得用成熟类目绝对规模标准淘汰 |
| **季节/活动** | 价值集中在特定季节/节日 | 结合经营阶段判断不用全年平均 |
| **收缩风险** | 长期贡献有限/效率弱/缺战略价值 | 进收缩评估但不等于直接退出 |
| **（无角色）** | 证据不足以判断任何角色 | 标记待确认不强行贴标签 |

## 结构健康判断（五维）

### 1. 集中风险

> 高集中不一定不健康——如果核心类目经营稳定/符合定位/供给稳定/风险可控，高集中可以是合理战略。

**判断为"集中风险"的条件**：集中程度已造成经营脆弱性——依赖少数头部商品/库存或供应风险/缺替代类目/核心波动影响全店。

### 2. 无效分散

> 类目多不等于结构丰富。

**判断为"无效分散"的条件**：多个类目同时经营贡献低/供给差异小/没明确角色/长期占资源/缺成长信号。

> 核心问题不是"类目太多"而是"资源被分散到缺明确价值的对象上"。

### 3. 梯队断层

> 健康结构不应只有"一个核心+一批弱类目"。

**判断为"梯队断层"的条件**：核心贡献高但缺能继续成长的第二梯队。当前不差但未来增长和抗风险弱。

### 4. 类目重叠

> 名称相似不能证明重复——要看商品/场景/人群/价格带/经营功能是否高度相似。

**判断为"重叠待核查"的条件**：多维度高度相似。需进一步判断是否造成商品重复归属/用户混乱/供给重复/资源重复。

### 5. 角色资源错配

| 错配类型 | 表现 |
|---|---|
| 核心角色资源不足 | 核心成交类目长期缺货/供给不足/无主推/内容薄弱 |
| 机会角色缺验证资源 | 增长机会类目在售链接少/库存不足/无测试资源 |
| 低价值类目资源占用 | 收缩风险类目长期贡献有限但仍获大量资源 |

> 资源错配比单纯规模大小更值得处理。

---

## 角色与风险必须分开判断

> 一个类目可以同时是"核心成交+高集中风险"或"增长机会+供给不足"。

- 角色描述：为什么这个类目值得存在
- 风险描述：当前这个类目存在什么经营问题
- 两者不得混成一个标签

---

## 行业机会可以影响角色但不能替代店内证据

> 行业增长快不代表店铺这个类目自动成为增长类目。

| 情况 | 判断 |
|---|---|
| 行业增长+本店经营好 | 增长机会类目 |
| 行业增长+本店经营弱 | 外部机会存在但店内承接不足（不直接加预算/供给） |
| 行业不增长+本店经营好 | 核心角色但增长空间有限 |

## 常见误读

| 误读 | 纠正 |
|---|---|
| "销售排名高=核心类目" | 要看持续性/稳定性，一次活动冲高不算 |
| "访客量高=引流类目" | 要看流量是否形成后续经营价值 |
| "客单高=利润类目" | 没利润数据不授利润角色 |
| "行业增长=该扩" | 店内承接不足时不直接扩 |
| "集中度高=不健康" | 核心稳定+风险可控时高集中是合理战略 |
| "类目多=结构丰富" | 无效分散比类目少更糟 |
| "名称相似=重复" | 要看商品/场景/人群/价格带多维 |
| "销售低=该删" | 品牌/补充/季节类目非销售角色 |
