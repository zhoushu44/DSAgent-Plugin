# 测款测图操作总纲

> 测款和测图是新品上架前后的两个关键验证环节。测款决定"值不值得做"，测图决定"图能不能接住流量"。
> 本文把两个阶段合成一个独立的实战操作文档，从"有产品想法"到"图跑稳可以放量"的完整路径。

---

## 为什么测款和测图要放在一起

测款和测图虽然是两个阶段，但在实战中是连续的：

```
有产品想法 → 测款（值不值得做）→ 进货/上架 → 测图（图接不接得住）→ 开推广放量
```

- 测款不过 → 不进货，省钱省时间
- 测款过了但测图不过 → 开推广也是白花钱（曝光来了点不进来）
- 两个都过 → 可以放心开推广放量

**所以这两个环节是推广放量的前置条件，放在一起看才完整。**

---

## 上篇：测款（值不值得做）

### 测款的本质

> **花小钱验证大决策。** 用几百块的样品/测试费，避免几万块进货压库存。

测款不是"看销量"，而是**同时验三件事**：需求（市场买不买单）+ 利润（赚不赚钱）+ 预算（花多少测）。三道门任何一道不过都不该量产。

### 门一：需求验证

| 信号 | 怎么看 | 甜区 | 数据来源 |
|---|---|---|---|
| 搜索量 | 月搜索量 | 1,000-10,000 | keyword-assistant（国内）/ Jungle Scout（跨境） |
| 趋势方向 | 同比/环比 | 上升或稳定不下降 | keyword-traffic / Google Trends |
| 季节性 | 全年搜索曲线 | 有规律可预期 | keyword-traffic 13个月趋势 |
| 竞争密度 | 同款卖家数 | 有竞品但不垄断 | market-analysis / 手工搜 |
| 痛点验证 | 竞品差评主题 | 有可解决的痛点 | product-reviews / customer-voice-analyzer |

**需求评分（0-100）**：搜索量20分+趋势20分+季节10分+竞争20分+痛点30分
- ≥70 = GO
- 50-69 = CAUTION
- <50 = NO-GO

> **不能只看"市场大"。要看新进入者能拿多少，不是品类老大拿了多少。**

### 门二：利润验证

| 成本项 | 怎么算 | 注意 |
|---|---|---|
| 落地成本 | 采购价+头程物流+关税+入库费 | 不是只看工厂报价 |
| 平台费用 | 佣金+FBA/仓储费+支付费 | 按实际费率算 |
| 竞品售价 | 取同款/近款 top10 均价 | 不取最高价（卖不动） |
| 毛利 | 售价-落地成本-平台费用 | 不含推广费 |
| 推广盈亏平衡 | 毛利/(1/ACOS盈亏点) | 推广花多少才不亏 |

**利润判决**：
- 毛利率≥30%且有推广空间 = GO
- 15-30% = CAUTION（需严控成本或提价）
- <15% = NO-GO（除非有战略理由）

> **"看起来便宜"不等于赚钱。工厂报价$4的货，加完费用可能是死路。**

### 门三：预算验证

| 项 | 怎么算 |
|---|---|
| 关键词CPC | 查主关键词实际点击单价 |
| 测试周期 | 7-14天 |
| 日预算 | CPC × 预期点击数/天 × 1.5 |
| 测试总预算 | 日预算 × 测试周期 |
| 盈亏平衡ACOS | 毛利/售价×100% |
| 目标ACOS | 盈亏平衡ACOS × 0.7 |

> **预算算的是"测试成本"不是"排位成本"。不能证明花X万排到第Y名——任何排位承诺都是未验证假设。**

### 首批进货量（三档情景）

不拍一个数，给保守/基准/激进三档：

| 情景 | 算法 | 适用 |
|---|---|---|
| 保守 | 日均预估销量 × 交期 × 0.7 | 资金紧/不确定性高 |
| 基准 | 日均预估销量 × 交期 × 1.0 | 正常 |
| 激进 | 日均预估销量 × 交期 × 1.5 | 有把握/补货周期长 |

**日均预估销量**：看竞品同BSR区间销量（不是top1），打0.3-0.5折（你是新手不是老大）。

**红旗**：计划进货量=几年销量 → 月销30进5000=14年库存，锁死现金和仓储。

### 测款决策矩阵

| 需求 | 利润 | 预算 | 判决 |
|---|---|---|---|
| GO | GO | 可承受 | **量产** |
| GO | CAUTION | 可承受 | **小批量试**（先进1/3） |
| GO | NO-GO | — | **不做**（或重谈成本） |
| CAUTION | GO | 可承受 | **小批量试** |
| CAUTION | CAUTION | — | **观望** |
| NO-GO | 任意 | — | **不做** |

### 测款期数据判断（已上架在测）

| 指标 | 甜区 | 信号 |
|---|---|---|
| 首周曝光 | 有且增长 | 系统在分配流量 |
| 点击率CTR | ≥行业均值 | 主图/标题承接得住 |
| 收藏加购率 | ≥5% | 有购买意向 |
| 首单时间 | 7-14天内 | 需求真实 |
| 首单转化率 | ≥行业均值 | 成交承接正常 |
| 退款率 | <行业均值 | 货能卖住 |

> **新品不强求ROI。** 样本期ROI低正常，看"链路通没通"（曝光→点击→意向→成交）。

## 下篇：测图（图接不接得住）

### 测图的本质

> 图美不美主观，**CTR客观**。最终以CTR为准，不以"我觉得好看"为准。

测图解决的是经营链路的**第二环：点击响应**。

```
流量获取(曝光) → 【点击响应(CTR)】 → 意向承接 → 成交 → 质量
                     ↑
                  图在这一环
```

**CTR是放大器**：CTR从2%提到4%，等于流量翻倍但不用多花钱。

### 什么时候该测图

| 场景 | 该不该测 | 为什么 |
|---|---|---|
| 新品上架7天有曝光但CTR低 | ✅立即测 | 曝光有了图没接住 |
| 老品CTR连续下降 | ✅测 | 图衰退/竞品换更好的图 |
| 有曝光但收藏加购率低 | 先测图再测承接 | CTR低时后续指标都受影响 |
| 没曝光 | 先解决曝光 | 没曝光测不了图 |
| CTR高于行业均值 | 不急测 | 但要监控防衰退 |

> **先确认"有足够曝光"（流量获取没问题），再测图。没曝光就测图是错的。**

### 测图核心指标

| 指标 | 怎么算 | 甜区 | 说明 |
|---|---|---|---|
| CTR | 点击÷曝光 | ≥行业均值 | 第一指标 |
| 曝光量 | 展现次数 | 日均≥500 | 样本不够CTR不可信 |
| CTR趋势 | 连续多日 | 稳定或上升 | 连续下降=衰退 |
| 同行对比 | 同关键词同位置竞品 | 不低于竞品 | 同条件下比 |

**CTR行业均值怎么来（深入版）**：

CTR 基准不是拍脑袋的数字，有五个真实数据来源，按优先级使用：

| 优先级 | 来源 | 怎么拿 | 可靠度 | 适用场景 |
|---|---|---|---|---|
| 1（最优） | **店铺自身历史CTR** | 自己推广后台看过去30-90天同品类商品CTR | 高（真实经营数据） | 有推广历史的成熟店 |
| 2 | **同类目竞品CTR** | `competitor-strategy-comparison` 技能取本品vs竞品CTR对比 | 高（同条件同周期可比） | 有竞品对标需求时 |
| 3 | **行业类目CTR** | `industry-data-mcp` 的 `qiwrok_category_stats` 返回类目ctr | 中（行业聚合非单品） | 看类目整体水平时 |
| 4 | **关键词CTR趋势** | `keyword-traffic` 的 `trend` 命令返回13个月CTR/CVR/竞争/均价 | 中（关键词级非商品级） | 判断CTR季节性和趋势时 |
| 5（兜底） | **相对判断** | 没有以上数据时，和自己历史比、和同店其他品比 | 低（只有方向性） | 新店/无历史数据时 |

> **不用"我觉得3%就行"——这是无来源经验值。**
> 不同类目、不同关键词、不同位置的CTR差异极大，通用阈值没有意义。
> 必须用上述五个来源中的一个或多个建立基准。

**五级基准的实操取法**：

**第一级：店铺自身历史CTR（最优）**
- 来源：推广后台（生意参谋/万相台）过去30-90天同品类商品的ctr字段
- 怎么用：取同品类商品的历史CTR中位数作为基准
- 注意：只取"同品类"的——服装和电子的CTR不能混着算
- 字段映射：`sycm.alimama_item_promotion` 表的 `ctr` 字段

**第二级：同类目竞品CTR**
- 来源：`competitor-strategy-comparison` 技能，一级场景对比里返回本品和竞品的CTR
- 怎么用：取竞品top3-5的CTR均值作为对标基准
- 注意：要选"同关键词同位置"的竞品比，跨位置比没意义
- 字段：`GET /api/goods/grow/comparison/scene` 返回的 ctr

**第三级：行业类目CTR**
- 来源：`industry-data-mcp` 的 `qiwrok_category_stats`（需订购行业库MCP）
- 怎么用：返回类目维度的ctr，作为行业大盘水平参考
- 注意：这是行业聚合值，不等于你单品的CTR基准——它告诉你"行业平均多少"，不告诉你"你的品该到多少"
- 没有行业库时跳过此级

**第四级：关键词CTR趋势**
- 来源：`keyword-traffic` 的 `trend <关键词>` 命令，返回13个月日趋势含ctr
- 怎么用：看你核心关键词的历史CTR区间，作为"这个词的点击率基准"
- 注意：这是关键词级CTR（搜索结果页的点击率），不是商品主图CTR——两者口径不同
- 字段：`{keyword}ctr`（百分比格式）

**第五级：相对判断（兜底）**
- 条件：以上四级都没有
- 怎么做：和自己历史比（这个品比上个月涨了还是降了）、和同店其他品比（这个品比店里其他品高还是低）
- 只能判断方向（变好/变差），不能判断绝对水平（够不够好）

**五级基准的技能现状对照**（截至2026-10，已核实）：

| 级别 | 对应技能 | 接线状态 | 能拿什么CTR |
|---|---|---|---|
| 1 | `shop-promotion-diagnosis` | ✅ 已有可用 | `sycm.alimama_item_promotion` 表 `ctr` 字段（自己推广计划点击率） |
| 2 | `competitor-strategy-comparison` | ✅ 已有可用 | `GET /api/goods/grow/comparison/scene` 本品vs竞品 ctr |
| 3 | `industry-data-mcp` | ⚠️ 技能有但MCP未接线 | `qiwrok_category_stats` 类目ctr——需订购「参谋长」行业库后才下发地址/凭证 |
| 4 | `keyword-traffic` + `keyword-assistant` | ✅ 已有可用 | `trend` 返回13个月 `{keyword}ctr`；`keyword-assistant` 返回关联词 `click_rate`/`free_click_rate`/`click_rate_change` |
| 5 | 人工判断 | ✅ 无需技能 | 和自己历史比、和同店其他品比 |

**补充数据源**（不在五级主链里，但能增强判断）：

| 技能 | 能拿什么 | 补充作用 |
|---|---|---|
| `competitor-indicator` | 达摩盘 `clickRate`（广告点击率） | 第二级竞品CTR的达摩盘维度补充 |
| `product-layering-diagnosis` | 商品层 `ctr`（可选字段） | 第一级店铺历史CTR的商品维度补充 |

**结论**：五级里**四级都有技能可直接用**，只差第三级行业类目CTR——那个需订购外部行业库MCP后接线。但第三级本身是"中可靠度"补充来源，没有它不影响前两级（店铺历史+竞品，都是高可靠度）和第四级（关键词趋势）的使用。

**CTR基准使用铁律**：
1. 不得用无来源经验值（"3%就行""5%算高"）作为判断标准
2. 不同类目/关键词/位置的CTR差异极大，通用阈值没意义
3. 优先用店内真实数据，行业数据只做增强不替代
4. 关键词CTR ≠ 商品主图CTR——口径不同，不能混用
5. CTR会随季节/竞争/流量结构变化，基准要定期更新（建议30天刷新一次）
6. 取数前先确认技能接线状态——第三级行业类目未接线时跳过，不编数据

### 测图判断逻辑

#### 情况一：CTR低+曝光够 → 图的问题

| 信号 | 判读 | 动作 |
|---|---|---|
| 曝光日均≥500，CTR<行业均值×0.7 | 图承接不足 | 换图测试 |
| 曝光够，CTR连续3天降 | 图衰退 | 准备新图 |
| 曝光够，CTR突然断崖降 | 可能违规/被限流 | 先查状态再查图 |

#### 情况二：CTR低+曝光不够 → 不只是图

> 曝光不够时CTR样本不可信。先解决曝光（出价/预算/关键词覆盖），曝光上来后再测图。

#### 情况三：CTR够+后续指标低 → 不是图的问题

> CTR达标但收藏加购/转化低 → 问题在后续环节（意向承接/成交承接），不在图。
> **CTR够了还改图=在错误的环节使劲。**

### 怎么测图（三种方法）

#### 方法一：A/B测试（推荐）

| 要素 | 要求 |
|---|---|
| 测试对象 | 主图A vs 主图B（只改一个变量） |
| 流量分配 | 随机均分 |
| 样本量 | 每张图至少1000曝光 |
| 测试周期 | 3-7天（覆盖工作日+周末） |
| 判定指标 | CTR（主要）+点击量（辅助） |
| 统计显著性 | 差异要够大，2.1% vs 2.0%不判胜负 |

> **一次只测一个变量。** 同时换图+换标题+换价格，就不知道是哪个起的作用。

#### 方法二：轮换测试（无A/B工具）

图A跑3-7天记录日均CTR → 换图B同条件跑3-7天 → 比CTR高的留下。
期间不改出价/预算/标题，否则污染数据。

#### 方法三：竞品对照

找同关键词排名相近的3-5个竞品 → 观察主图风格/卖点/背景/角度 → 对比CTR差距 → 找差距原因（不是抄是找方向）。

### 测图指标组合判断

| CTR | 收藏加购率 | 判读 | 动作 |
|---|---|---|---|
| 高 | 高 | 好图+好承接 | 放量 |
| 高 | 低 | 好图但承接弱 | 测图完成去测承接 |
| 低 | — | 图有问题 | 先测图 |
| 中等 | 高 | 图凑合承接强 | 图可优化不急 |
| 中等 | 低 | 都有问题 | 先提CTR（放大器效应） |

### 什么图算好图（客观标准）

| 信号 | 好 | 差 |
|---|---|---|
| 卖点清晰度 | 1秒看懂卖什么 | 要研究才知道 |
| 与搜索意图匹配 | 搜"便携"就显便携 | 搜"便携"显大容量 |
| 竞品差异化 | 和竞品有明显区别 | 和竞品一模一样 |
| 背景干净度 | 主体突出 | 背景抢主体 |
| 文字/角标 | 关键信息露出 | 无信息或太多 |

### 全站推广下的测图特殊性

| 特殊点 | 说明 |
|---|---|
| 流量是系统分配的 | CTR低可能不是图差，是系统分错流量 |
| 阶段影响CTR | 启动/学习期CTR波动大，不作为图好坏依据 |
| 归因不可见 | 不能反推"某个流量来源导致CTR低" |
| 改图影响学习 | 频繁换图会打断系统学习 |

> **全站推广测图建议**：稳定投放阶段再测图；启动/学习期先让系统跑稳。改图后观察3-5天再判断，不因1天波动换回。

## 测款测图的完整时间线

| 阶段 | 时长 | 做什么 | 过了进下一步 |
|---|---|---|---|
| 1. 需求验证 | 1-2天 | 查搜索量/趋势/竞争/痛点 | 需求GO或CAUTION |
| 2. 利润验证 | 1天 | 算落地成本+平台费vs竞品价 | 利润GO或CAUTION |
| 3. 预算验证 | 半天 | 算CPC×测试周期×1.5 | 预算可承受 |
| 4. 进货上架 | 按交期 | 按三档情景进货 | 货到 |
| 5. 测款期 | 7-14天 | 看链路通没通（曝光→点击→意向→首单） | 有首单+链路通 |
| 6. 测图期 | 3-7天 | A/B或轮换测图，CTR达标 | CTR≥行业均值 |
| 7. 承接验证 | 3-5天 | CTR够后看收藏加购/转化 | 后续指标达标 |
| 8. 开推广 | — | 测款测图都过→开关键词/全站 | — |

> **任何一步不过都不要硬往下走。** 测款不过不进货；测图不过不开推广；承接不过先修承接。

---

## 测款测图的五个不要

| 不要 | 为什么 |
|---|---|
| 不要跳过测款直接进货 | 需求/利润/预算没验就进货=赌 |
| 不要没曝光就测图 | 没曝光测不了图，先解决曝光 |
| 不要同时换图+标题+价格 | 一次一个变量，否则不知道谁起作用 |
| 不要凭审美判断图好不好 | 以CTR为准，不以"我觉得好看"为准 |
| 不要新品ROI低就判死 | 样本期看链路通没通，不看ROI |

## 快速自查清单

进货前：
- [ ] 需求验证过了？（搜索量/趋势/竞争/痛点）
- [ ] 利润验证过了？（落地成本+平台费vs竞品价，毛利≥30%）
- [ ] 预算可承受？（CPC×7-14天×1.5）
- [ ] 首批量按三档情景算的？（不是拍脑袋）

开推广前：
- [ ] 测款期链路通了？（曝光→点击→意向→首单）
- [ ] CTR达标了？（≥行业均值，有足够样本）
- [ ] CTR够后续指标也达标？（收藏加购≥5%）
- [ ] 是哪个阶段？（全站启动期不测图，稳定期再测）

全部过=可以开推广放量。任何一条红灯=先解决再往下走。
