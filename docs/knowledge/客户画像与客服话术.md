# 客户画像与客服话术

> 客户画像解读（新访/未购回访/已购回访/职业/学历/品牌/消费层级）+ 客服全场景话术（售前/售中/售后/退款/投诉/催单/差评）。
> 从本店 sycm-customer 和 customer-service-reply 技能整理。

---

## 客户画像

### 三类客户概览

| 客户类型 | 含义 | 关注什么 |
|---|---|---|
| **新访客户** | 第一次来店 | 有没有被吸引住/会不会回来 |
| **未购回访** | 来过没买又回来了 | 为什么上次没买/这次会不会买 |
| **已购回访** | 买过又回来了 | 复购动力/满意度/追加销售 |

### 画像维度

| 维度 | 看什么 | 怎么用 |
|---|---|---|
| **职业** | 什么职业的人买 | 定向广告按职业投放 |
| **学历** | 什么学历 | 文案风格调整 |
| **品牌偏好** | 喜欢什么品牌 | 竞品对标/品牌合作 |
| **品类偏好** | 买什么品类 | 交叉销售/关联推荐 |
| **消费层级** | 高/中/低消费 | 分层定价/分层激励 |
| **性别/年龄/地域** | 基础人口统计 | 基础定向 |

### 深入：消费层级怎么用

| 消费层级 | 特征 | 怎么用 |
|---|---|---|
| 高消费 | 客单高/买高端品 | 推高毛利品/VIP计划/早鸟 |
| 中消费 | 客单中等/主流品 | 推套装/满减/交叉销售 |
| 低消费 | 客单低/入门品 | 推引流品/限时折扣/首购优惠 |

### 数据来源

用 sycm-customer 技能取数：
- 客户概览（新访/未购回访/已购回访人数和占比）
- 客户画像（职业/学历/品牌/品类/消费层级/性别/年龄/地域）
- 输出 JSON/CSV/HTML 报告

## 客服话术

### 全场景覆盖

| 场景 | 话术类型 | 目标 |
|---|---|---|
| **售前咨询** | 产品咨询/价格咨询/规格咨询/对比竞品 | 促成下单 |
| **售中跟进** | 物流催单/订单确认/付款提醒 | 减少流失 |
| **售后处理** | 退款/退货/换货/投诉/差评 | 挽回+防差评 |
| **评价引导** | 好评引导/追评引导/买家秀 | 提升评价质量 |
| **复购触达** | 到货关怀/使用回访/复购提醒 | 驱动复购 |

### 售前咨询话术框架

| 客户问 | 话术框架 | 注意 |
|---|---|---|
| "这个好用吗" | 痛点→解决方案→证据（评价/数据） | 不编数据 |
| "和XX比怎么样" | 差异化卖点对比，不贬低竞品 | 客观不踩 |
| "能便宜点吗" | 价值锚定→不降价的话给赠品/免邮 | 不轻易降价 |
| "有货吗" | 确认库存→催单 urgency | 有货催/无货给替代 |
| "发什么快递" | 确认物流→时效承诺 | 不承诺做不到的 |

### 催单话术

| 时机 | 话术 | 目标 |
|---|---|---|
| 下单未付款30分钟 | "您的订单已锁定库存，X小时内未付款将释放" | urgency催付 |
| 下单未付款2小时 | "您选的XX很受欢迎，库存有限" | 稀缺感 |
| 下单未付款6小时 | "有问题可以随时问我，帮您解决" | 关怀不催 |

### 退款/投诉话术

| 客户情绪 | 话术框架 | 注意 |
|---|---|---|
| 不满/愤怒 | 先道歉→认可感受→给方案→跟进 | 不辩解先共情 |
| 要求退款 | 确认原因→给方案（退款/换货/补偿）→执行 | 不拖 |
| 差评威胁 | 积极解决→请求改评（不诱导） | 不用利益换好评 |
| 投诉质量 | 记录问题→反馈改进→补偿 | 把投诉变改进信号 |

### 差评回应

| 差评类型 | 回应框架 | 目标 |
|---|---|---|
| 质量差 | 道歉→记录→给方案（退换/补偿）→改进承诺 | 挽回+让其他买家看到态度 |
| 物流慢 | 道歉→解释原因→催物流→补偿 | 不甩锅物流 |
| 不喜欢 | 尊重选择→推荐替代品→退换引导 | 不强推 |
| 与描述不符 | 道歉→核实→修正描述/补偿 | 防同类再发 |

### 复购触达话术

| 时机 | 话术 | 目标 |
|---|---|---|
| 到货3天 | "收到了吗？用着怎么样？" | 关怀+使用反馈 |
| 到货7天 | "分享一个使用小技巧..." | 增值不推销 |
| 到货30天 | "XX快用完了吧？补货有优惠" | 复购提醒（消耗品） |
| 到货90天 | "新品上市，老客户早鸟" | 老客专属 |

## 常见误读

| 误读 | 纠正 | 为什么 |
|---|---|---|
| "客服=回复问题" | 客服是转化和留存的关键环节 | 好客服提升复购降低退款 |
| "差评=删除" | 差评要积极回应 | 回应态度比删差评更有价值 |
| "催单=催付款" | 催单是关怀不是施压 | 先关怀再urgency |
| "话术=模板" | 话术是框架要个性化 | 照模板=机械感 |
| "画像=性别年龄" | 消费层级/品牌偏好更有用 | 基础人口统计不够 |
| "退款=损失" | 退款是改进信号 | 把退款变产品改进 |
