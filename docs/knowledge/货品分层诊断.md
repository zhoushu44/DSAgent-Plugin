# 货品分层诊断

> 判断店铺不同商品当前承担什么经营角色、哪些该保护/投入/培养/观察/退出。
> 含五层分层（核心/成长/潜力/观察/退出）+ 六维判断 + 层级与风险分开 + 动态迁移。
> 从本店 product-layering-diagnosis 技能的 knowledge 规则整理。

---

## 核心认知：分层本质是经营角色判断

> 货品分层不是按销售额从高到低排序，也不是给商品永久贴标签。
> 分层应回答两个问题：这个商品当前对店铺有什么经营价值？基于当前证据店铺下一阶段如何对待它？

---

## 六维判断（必须同时考虑）

| 维度 | 看什么 | 防止什么误判 |
|---|---|---|
| **经营贡献** | 成交规模/净支付/订单/流量/稳定性/对整体影响 | 只看销售额 |
| **经营质量** | 转化/净支付质量/退款侵蚀/推广回报/成交稳定性 | "卖得多=好货" |
| **成长潜力** | 流量增长/收藏加购/询单/首批成交/净支付增长 | "现在小=没价值" |
| **风险状态** | 退款/转化/库存/推广风险 | "核心款=没问题" |
| **样本成熟度** | 数据量够不够 | "3单高转化=爆款" |
| **店铺目标** | 保利润/冲成交/打新品/清库存/稳基本盘 | 脱离目标谈对错 |

> 不得只依据单一指标完成分层。

## 五层分层

### 核心款

- 已经形成较大且相对稳定的经营贡献
- 是当前店铺需要优先保护的商品
- **核心款不代表没有问题**——可同时存在退款/转化/库存/推广风险（核心款+风险状态）
- 经营原则：优先保护基本盘再处理风险和增长

### 成长款

- 已形成一定有效经营结果且仍表现较明确增长空间
- 已经产生有效成交+经营信号增强+获得资源后结果能同步改善+尚未达到核心款规模
- 经营原则：验证增长持续性，证据成立下逐步增加资源
- 不得因短期单日增长直接认定

### 潜力款

- 当前贡献有限但已出现值得验证的正向信号
- 当前成交小+已出现有效流量/收藏加购/询单/首批成交+部分指标积极+尚未稳定
- 经营原则：给予有限测试资源，验证能否从"有信号"转化为"有结果"
- **潜力款不是"表现差但不想放弃"的美化称呼——必须存在正向证据**

### 观察款

- 当前证据不足以证明增长价值也不足以证明该退出
- 常见：样本不足/上线短/数据波动大/有部分信号但缺连续性
- 经营原则：控制资源继续积累证据等待重新判断
- **必须设置重新判断条件，不能成为无人处理的垃圾桶**

### 低效退出款

- 已获合理经营机会但持续无法形成有效价值且资源继续投入机会成本高
- 长期贡献低+有流量但持续无法成交+持续消耗资源但回报弱+没成长信号
- 经营原则：减少无效资源占用，根据库存/战略/目标决定收缩/清理/退出
- **不得仅因短周期表现差直接判断为退出款**

---

## 层级与风险必须分开判断

> "商品是什么层级"和"商品是否健康"是两个不同问题。

| 组合 | 含义 |
|---|---|
| 核心款+退款风险 | 基本盘好但有退款侵蚀 |
| 核心款+转化风险 | 基本盘好但转化在降 |
| 成长款+推广效率风险 | 在增长但推广效率有问题 |
| 潜力款+样本不足 | 有信号但数据不够 |
| 观察款+流量不足 | 没判断但流量不够 |

> 不得因风险降低层级，也不得因核心款忽略风险。

---

## 动态迁移

> 货品分层是阶段性经营判断不是永久标签。

```
潜力款 → 成长款 → 核心款（正向）
核心款 → 经营质量恶化 → 重新评估资源价值（风险）
潜力款 → 多轮验证失败 → 观察款 → 低效退出款（退出）
```

> 层级变化必须由新的经营证据支持，不得因运营主观意愿直接升级或降级。

---

## 店铺目标影响资源策略

| 目标 | 重视什么 | 不变的是什么 |
|---|---|---|
| 保利润 | 净支付质量/退款风险/投入回报/资源效率 | 不忽略经营质量风险 |
| 冲成交 | 成交贡献/增长能力/可放大空间 | 不忽略明显风险 |
| 打新品 | 允许新品贡献低进入潜力/成长验证 | 必须有真实正向信号 |
| 清库存 | 正常不值得投入的可获阶段性资源 | — |
| 稳基本盘 | 优先保护核心款和稳定成长款 | 降低高不确定性对资源的竞争 |

> 经营目标影响资源策略和判断权重，不得用于篡改商品已存在的经营事实。

---

## 资源分配原则

> 遵循"价值×确定性"原则。

| 价值×确定性 | 资源策略 |
|---|---|
| 高价值高确定性（核心款） | 优先获得稳定资源 |
| 高潜力中等确定性（成长款） | 适合增量测试资源 |
| 低确定性（潜力款/观察款） | 优先获得验证资源不是大规模投入 |
| 低价值且充分验证无改善（退出款） | 减少资源占用 |

> 分层最终目的不是分类本身，而是减少平均主义式资源分配。

## 常见误读

| 误读 | 纠正 |
|---|---|
| "按销售额排名分层" | 要六维同时考虑不单一指标 |
| "核心款=健康" | 核心款可以有风险，层级和风险分开 |
| "潜力款=不想放弃" | 必须有正向证据不是美化称呼 |
| "观察款=垃圾桶" | 必须设重新判断条件 |
| "短周期差=退出" | 不得仅因短周期差判退出 |
| "新品=潜力款" | 不得因是新品自动归潜力 |
| "少量订单高转化=成长款" | 不得因少量订单高转化直接判成长/核心 |
| "销售高=没风险" | 不得因销售规模高忽略退款/转化/库存风险 |
| "运营想推=潜力" | 不得把主观意愿当成长潜力证据 |
