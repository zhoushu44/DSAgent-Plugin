## 怎么用这个打法库

### 使用流程

| 步骤 | 做什么 | 为什么 |
|---|---|---|
| 1. 摸清约束 | 确认产品/人群/阶段（冷启动/增长/成熟）/预算/人力/时间 | 不同阶段不同打法 |
| 2. 筛选打法 | 从 140 条中挑 3-5 条最匹配的，说明为何适合 | 不是全用，是选最合适的 |
| 3. 给落地方案 | 每条写明具体动作/所需资源/预期见效周期 | 能执行不只列清单 |
| 4. 排优先级 | 按"见效速度 × 资源投入"排序，先做1-2条 | 先做最快见效的 |
| 5. 标注风险 | 说明哪些打法在当前资源下不现实 | 避免给出无法执行的清单 |

### 按阶段选打法

| 阶段 | 特征 | 适合的打法 | 不适合 |
|---|---|---|---|
| **冷启动** | 没流量没客户没品牌 | 内容SEO/社媒/免费工具/合作/创始人销售 | 付费投放（没转化数据烧钱）/品牌PR |
| **增长** | 有产品有初始客户要放量 | 付费投放/邮件/活动促销/产品驱动增长/联盟分销 | 纯SEO（太慢）/大规模品牌建设 |
| **成熟** | 流量稳定要优化效率 | 客户留存/数据内容/国际化/合作伙伴/品牌PR | 大规模冷启动打法 |

### 按预算选打法

| 预算 | 能做 | 不能做 |
|---|---|---|
| **免费** | 内容/SEO/社区/社媒 | 付费广告/活动赞助 |
| **低预算** | 定向广告/赞助/小工具 | 大活动/PR |
| **中预算** | 活动/合作/PR | 收购/大型会议 |
| **高预算** | 收购/会议/品牌战役 | — |

### 按时间选打法

| 时间 | 快杠杆 | 慢杠杆 |
|---|---|---|
| **快（1-3天）** | 付费广告/邮件/社媒帖子 | — |
| **中（1-4周）** | 内容/SEO/社区建设 | — |
| **慢（1-6月）** | — | 品牌/思想领导力/平台效应 |

### 输出格式（推荐打法时）

每条推荐写明：
- **打法名称**：一句话描述
- **为何适合**：和用户情况的关系
- **怎么开始**：前2-3步实施步骤
- **预期效果**：成功长什么样
- **所需资源**：时间/预算/技能

## 合规红线

| 红线 | 说明 | 替代方案 |
|---|---|---|
| 诱导好评 | 不得用利益交换换取好评 | 做好产品自然引导评价 |
| 虚假宣传 | 不得编造销量/评价/功效 | 用真实数据+事实陈述 |
| 虚假紧迫感 | 不得编造"最后3件"等假紧迫 | 真实限时+真实库存 |
| 欺骗性社会认同 | 不得用假评价/假买家秀 | 用真实评价+真实案例 |
| 极限词 | "最/第一/绝对/100%有效"一律禁用 | 用具体数字+来源 |

## 常见误读

| 误读 | 纠正 | 为什么 |
|---|---|---|
| "140条全用" | 挑3-5条最匹配的 | 全用=没重点=什么都做不好 |
| "大V才有效" | 小达人也能起量 | 小达人精准+成本低 |
| "付费投放万能" | 没转化数据烧钱=亏 | 冷启动先做内容再付费 |
| "SEO太慢没用" | SEO是长线资产 | 冷启动慢但一旦排上去持续免费 |
| "促销=降价" | 促销可以是限时/捆绑/赠品 | 不一定要降价 |
| "品牌PR没用" | 成熟期品牌是壁垒 | 冷启动不做但成熟期必须做 |
