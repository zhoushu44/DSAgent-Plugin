# 营销心理学（终极完整版）

> 70+ 个心理学原理与思维模型完整列出。每个含：模型名/心理机制/电商应用。
> 按六大分类组织 + 14个挑战对照表 + 伦理底线 + 6大决策环节匹配。
> 基于本店 marketing-psychology 技能（70+ 模型完整列表）整理。

---

## 怎么用心理学模型

### 使用流程

| 步骤 | 做什么 | 为什么 |
|---|---|---|
| 1. 定位环节 | 确认当前要撬动哪一步（点击/加购/复购/拉新/留存/定价） | 不同环节用不同模型 |
| 2. 匹配模型 | 从 70+ 模型里挑 1-3 个最相关的 | 不泛泛谈心理学 |
| 3. 解释机制 | 讲清模型背后的心理机制 | 不只贴标签 |
| 4. 给出应用 | 落到具体文案/页面结构/活动机制 | 能执行不只列清单 |
| 5. 合规校验 | 确认不涉及虚假紧迫感/欺骗性社会认同 | 伦理底线 |

### 按决策环节选模型

| 决策环节 | 目标 | 最相关的模型 |
|---|---|---|
| **点击** | 让用户看到后点进来 | 社会认同/稀缺性/锚定/好奇心缺口 |
| **加购** | 让用户觉得值得买 | 损失厌恶/锚定定价/诱饵/互惠/承诺一致性 |
| **复购** | 让用户再来买 | 沉没成本/习惯回路/承诺一致性/禀赋效应 |
| **拉新** | 让用户推荐给别人 | 社会认同/互惠/稀缺性 |
| **留存** | 让用户不走 | 禀赋效应/转换成本/现状偏见 |
| **定价** | 让价格显得值 | 锚定/诱饵/魅力定价/心理账户 |

## 六大分类完整列表

### 一、基础思维模型（14个）

> 用对的思维框架解决对的问题。

| 模型 | 心理机制 | 电商应用 |
|---|---|---|
| **第一性原理** | 回到基本事实不抄竞品，用5Whys追问根因 | 不做内容营销因为竞品做，问"我要解决什么问题" |
| **JTBD（要完成的任务）** | 人不买产品，是"雇"产品完成任务 | 不卖"榨汁机"，卖"每天一杯新鲜果汁"——围绕任务不围绕规格 |
| **能力圈** | 只做自己擅长的，超圈要有学习或专家 | 不追每个渠道，专注有真正专长和竞争优势的 |
| **逆向思维** | 问"怎样保证失败"然后避免那些 | 列出所有会让活动失败的因素（混乱信息/错误受众/慢页面）然后系统预防 |
| **奥卡姆剃刀** | 最简单的解释通常对 | 转化降了先查明显原因（页面坏了/速度慢）再查复杂归因 |
| **帕累托原则（80/20）** | 80%结果来自20%努力 | 找到驱动80%结果的20%渠道/客户/内容，砍掉其余 |
| **局部vs全局最优** | 别困在错误的优化上 | 优化邮件标题（局部）不如先确认邮件是不是对的渠道（全局） |
| **约束理论** | 每个系统有一个瓶颈限制吞吐 | 转化好但流量低→优化转化没用，先解决流量瓶颈 |
| **机会成本** | 每个选择都有放弃的代价 | 低ROI渠道上的时间=不做高ROI活动，始终对比替代方案 |
| **边际递减** | 超过某点投入越多收益越少 | 第10篇博文不如第1篇影响大，知道什么时候该多样化 |
| **二阶思维** | 不只看直接效果还看效果的效果 | 闪促提收入（一阶）但训练客户等折扣（二阶）→慎用 |
| **地图≠疆域** | 模型和数据不是现实本身 | 客户画像有用但真实客户更复杂，保持和真实用户接触 |
| **概率思维** | 用概率不是确定 | 不全押一个活动，分散风险做多场景预案 |
| **杠铃策略** | 极端安全+小高风险组合 | 80%预算投验证过的渠道，20%投实验，避免中庸 |

### 二、理解买家与人类心理（19个）

> 理解人为什么买、怎么决策。

| 模型 | 心理机制 | 电商应用 |
|---|---|---|
| **基本归因错误** | 把别人行为归因于性格而非环境 | 客户不转化先查流程别怪客户——问题通常是情境不是个人 |
| **曝光效应** | 看过的东西更喜欢，熟悉生好感 | 持续品牌曝光跨渠道重复创造舒适和信任 |
| **可得性启发** | 容易想到的觉得更常见 | 用案例/评价让成功感觉更容易实现 |
| **确认偏差** | 人找支持已有信念的信息忽略矛盾 | 理解受众已相信什么顺着说不硬反 |
| **林迪效应** | 存在越久的越可能继续存在 | 基本营销原则（清晰价值/社会认同）比时髦打法耐用，别为潮流放弃基础 |
| **模仿欲望** | 人想要别人想要的东西，欲望是社会传染的 | 展示"受欢迎的人想要你的产品"→等待列表/独家/社会认同 |
| **沉没成本谬误** | 因过去的投入继续投入即使不再理性 | 知道什么时候该杀掉不赚钱的活动，过去花费不能为未来花费背书 |
| **禀赋效应** | 拥有后更珍惜 | 免费试用/样品让客户"拥有"后不舍得放弃 |
| **宜家效应** | 投入了努力的更珍惜 | 让客户定制/配置，投入增加感知价值和承诺 |
| **零价格效应** | 免费不只是低价是心理上不同 | 免费层/免费试用/免邮有不成比例的吸引力，¥1到¥0的跳远大于¥2到¥1 |
| **双曲贴现/当前偏见** | 强烈偏好即时奖励 | 强调即时好处（"今天就开始省时间"）而非未来（"6个月后看到ROI"） |
| **现状偏见** | 人偏好当前状态不想改变 | 降低迁移摩擦："一键导入数据"让切换感觉安全简单 |
| **默认效应** | 人倾向于接受预设选项 | 预选你想让客户选的计划，opt-out比opt-in有效（伦理使用） |
| **选择悖论** | 太多选项让人瘫痪 | 限制选项：三档定价比七档好，推荐一个"最适合大多数"的 |
| **目标梯度效应** | 接近目标时加速努力 | 进度条/"还差一步"/完成百分比驱动完成 |
| **峰终定律** | 按峰值和结尾判断体验不是平均 | 设计记忆峰值（惊喜升级/愉悦时刻）+强结尾（感谢页/跟进邮件） |
| **蔡格尼克效应** | 未完成的任务占据心智 | "你完成了80%"创造拉力完成，未完成资料/放弃购物车/悬念利用这 |
| **失误效应** | 能干的人有小缺点更讨喜，完美不如可亲 | 承认弱点（"我们不是最便宜的，但..."）增加信任和差异化 |
| **知识诅咒** | 知道了就难以想象不知道 | 你的产品对你显而易见对新客户困惑，用不熟悉的人测文案 |
| **心理账户** | 人按来源/用途不同对待钱 | "¥3/天"和"¥90/月"一样但感觉不同，"比你的咖啡还便宜"重新框架 |
| **后悔规避** | 人避免可能后悔的行动 | 退换保证/免费试用/"无承诺"降低后悔恐惧 |
| **从众效应/社会认同** | 人跟随他人行为，流行信号质量和安全 | 展示客户数/评价/Logo/评论/"趋势"指标，数字创造信心 |

### 三、影响行为与说服（12个）

> 怎么合乎伦理地影响决策。

| 模型 | 心理机制 | 电商应用 |
|---|---|---|
| **互惠原则** | 人有义务回报好处 | 免费内容/免费工具/大方免费层→产生回报义务，先给再要 |
| **承诺与一致性** | 承诺了就想保持一致 | 先小承诺（邮件注册/免费试用）→更可能大承诺（付费），每步建在上步上 |
| **权威偏见** | 人服从专家/权威 | 专家背书/认证/"被报道"标识/思想领导力内容 |
| **好感/相似性偏见** | 对喜欢的人/像自己的人说yes | 用可亲和的代言人/创始人故事/"为营销人而造"信号相似 |
| **同一性原则** | 共享身份驱动影响"我们的人" | 把品牌定位为客户群体的一部分，用圈内语言和共享价值 |
| **稀缺/紧迫启发** | 有限可得增加感知价值，稀缺信号渴望性 | 限时/低库存/独家→只在真实时使用 |
| **登门槛技术** | 先小请求再升级 | 免费试用→付费→年付→企业版，每步递进 |
| **留面子技术** | 先大请求再退到你想要的 | 先展示企业版定价再揭示平价入门版，对比让后者感觉划算 |
| **损失厌恶/前景理论** | 失去的痛是获得快乐的2倍 | "不行动会失去什么"比"能得到什么"更有效 |
| **锚定效应** | 第一个数字影响后续判断 | 先展示高价（原价/竞品/企业版）锚定期望 |
| **诱饵效应** | 加一个差的选项让另一个看起来好 | 三档定价里诱饵档让目标档看起来是明显选择 |
| **框架效应** | 怎么说改变怎么被感知 | "90%成功率"vs"10%失败率"一样但感觉不同，正面框架 |

### 四、定价心理学（6个）

> 价格怎么展示让用户觉得值。

| 模型 | 心理机制 | 电商应用 |
|---|---|---|
| **魅力定价/左位数效应** | 以9结尾感觉比整数便宜很多 | ¥99比¥100感觉便宜很多——价值导向产品用.99/.95 |
| **整数定价（流畅）效应** | 整数感觉高端且易处理 | ¥100=品质信号；¥99=价值信号——高端产品用整数 |
| **100法则** | <$100用百分比折扣显得大；>$100用绝对值显得大 | ¥80产品"20%off"比"省¥16"好；¥500产品"省¥100"比"20%off"好 |
| **价格相对性/好-更好-最好** | 人按选项相对判断价格 | 三档中间是你目标——贵的锚定，便宜的提供起点 |
| **心理账户（定价）** | 同一价格不同框架感知不同 | "¥1/天"比"¥30/月"感觉便宜——"比你的咖啡还便宜" |
| **对比效应** | 和什么比决定感知 | 先展示"之前"状态，对比"之后"让改进鲜明 |

### 五、设计与交付模型（11个）

> 页面/活动怎么设计。

| 模型 | 心理机制 | 电商应用 |
|---|---|---|
| **希克定律** | 选项越多决策越慢越多放弃 | 简化选择：一个CTA比三个好，少表单字段比多好 |
| **AIDA漏斗** | 注意→兴趣→欲望→行动 | 按阶段结构页面/活动，先抓注意再建欲望 |
| **7法则** | 约7次触点才转化 | 多触点跨渠道——重定向+邮件序列+持续曝光 |
| **助推理论/选择架构** | 小改变选项呈现方式影响决策 | 默认选择/战略排序/减少摩擦不限制选择 |
| **BJ Fogg行为模型** | 行为=动机×能力×提示 | 三者都到位才行动——高动机但难做=不行动；易做但没提示=不行动 |
| **EAST框架** | Easy/Attractive/Social/Timely | 减少摩擦+吸引+展示他人做+在正确时机问 |
| **COM-B模型** | Capability+Opportunity+Motivation | 能不能做+路径清不清+想不想做，三者都解决 |
| **激活能** | 开始需要的初始能量 | 降低起步摩擦：预填表单/模板/快速胜利让第一步极简 |
| **北极星指标** | 一个最能代表客户价值的指标 | 找到你的北极星（活跃用户/完成项目/客单收入）对齐所有努力 |
| **眼镜蛇效应** | 激励可能适得其反产生反效果 | 测试激励结构——推荐奖可能吸引低质量推荐刷系统 |
| **峰终+目标梯度** | 见上方 | 进度条+峰值+强结尾 |

### 六、增长与规模化（8个）

> 营销怎么复利和规模化。

| 模型 | 心理机制 | 电商应用 |
|---|---|---|
| **反馈循环** | 输出变输入创造循环 | 用户多→内容多→SEO好→用户更多——识别并加强正循环 |
| **复利** | 小的持续收益累积成大结果 | 持续内容/SEO/品牌建设复利——早开始收益指数增长 |
| **网络效应** | 越多人用越有价值 | 设计随用户增多变好的功能：共享空间/集成/市场 |
| **飞轮效应** | 持续努力创造动量最终自维持 | 内容→流量→线索→客户→案例→更多内容 |
| **转换成本** | 换竞品的代价（时间/钱/数据/努力） | 合理增加转换成本：集成/数据积累/工作流定制/团队采用 |
| **探索vs开发** | 平衡试新和优化已有 | 不放弃有效渠道追新，但留预算做实验 |
| **临界质量/拐点** | 达到后增长自我维持 | 聚焦资源在一个细分达到临界质量再扩——深度先于广度 |
| **幸存者偏差** | 只看成功忽略不可见的失败 | 研究失败的campaign不只成功的——你抄的爆款背后有99个失败你看不到 |

## 伦理底线

> 模型用于放大真实卖点，不能用于包装不存在的优势。

| 红线 | 说明 | 合规替代 |
|---|---|---|
| 虚假紧迫感 | 编造"最后3件"但实际有库存 | 真实库存+真实限时 |
| 欺骗性社会认同 | 买假评价/刷销量/假买家秀 | 真实评价+真实数据 |
| 误导性锚定 | 虚标原价让折扣看起来大 | 真实原价+真实折扣 |
| 利用偏差误导 | 利用损失厌恶制造恐慌 | 诚实陈述+真实价值 |
| 缺少数据支撑 | "最畅销"但没数据 | 先取得事实依据再使用 |

> 利用认知偏差误导消费者时拒绝并给出诚实说服的替代路径。

## 心理学常见误读

| 误读 | 纠正 | 为什么 |
|---|---|---|
| "心理学=操纵消费者" | 用于放大真实卖点不包装虚假 | 伦理底线 |
| "选一个模型套上去" | 先定位环节再选模型 | 不同环节不同模型 |
| "损失厌恶万能" | 用多了用户免疫 | 过度使用失效 |
| "社会认同=刷好评" | 必须用真实数据 | 刷的会被查 |
| "锚定=虚标原价" | 必须真实原价 | 虚标违规 |
| "JTBD=换个说法" | 是回到"用户要完成什么任务" | 不是话术是视角 |
| "所有模型同等重要" | 按环节匹配不是全用 | 不同挑战不同模型 |
| "心理学替代好产品" | 放大真实卖点不替代产品 | 产品不行心理学也救不了 |
