#### 标题4大核心要素

- **价值感**：明确告诉用户"能获得什么"
- **好奇心**：制造适当悬念和缺口
- **情绪共鸣**：触发用户的情感按钮
- **关键词布局**：精准匹配搜索流量，建议2-3个关键词

> 含数字/问号的标题点击率平均提升42%，标题需在3秒内抓住注意力。

#### 标题规则

1. 字数≤20字（含emoji不含空格），写完必须数一遍
2. 至少1个emoji（放在语义转折处或末尾，不堆砌）
3. 用竖线｜或中文逗号分隔信息层
4. 优先用数字开头（"3步""5个""10分钟"）
5. 含2-3个精准关键词匹配搜索
6. 禁止引号包裹整个标题

### 正文排版

#### 黄金三段式结构

```
【开头】快速切入主题，制造悬念或直击共鸣（前2行决定展开率）
  ↓
【正文】分段清晰，每段≤3-4行，干货+场景+真实体验
  ↓
【结尾】互动引导语 → "你们觉得呢？" / "需要清单的评论区dd~"
```

#### 3种开头钩子（前2-3行定生死）

**① 痛点切入**：
```
[痛点提问/你是不是也……]❗
[具体场景描述]
[转折+方法预告]💪
```

**② 反常识开头**：
```
[反常识结论]
[个人经历佐证]
[引出方法论]👇
```

**③ 故事切入**：
```
[时间/场景/人物背景]
[冲突或转折]
[引发好奇的悬念]
```

#### 3大核心写作公式

**① 痛点+解决方案**
- 开头用"你是不是也……"句式直击痛点
- 正文清晰列出步骤，加粗关键信息（成分/效果/使用频率）
- 示例：「熬夜脸黄气色差？急救护肤3步走：①……②……③……」

**② 场景化+价值前置**
- 把内容嵌入高频生活场景
- 标题最前亮出用户最关心的结果（省钱/懒人/小众）
- 示例：「周末闺蜜聚会，5分钟快速出门伪素颜妆教」

**③ 情绪价值+实用干货**
- 注入"治愈""解压""安全感"等情绪词
- 情绪之后必须用实在内容支撑，不能只喊口号
- 示例：「独居女孩的夜晚安全感，是这盏灯给的[附布置清单]」

#### 正文结构模板（总—分—总）

```
开头钩子（2-3行）
———————————————————
核心概念解释（3-5行）
———————————————————
方法/步骤（每步3-4行，用序号标记）
———————————————————
效果/数据佐证（3-5行）
———————————————————
避坑提醒（2-4条）
———————————————————
互动引导（2-3行）
```

#### 提升"网感"的关键技巧

| 技巧 | 方法 | 示例 |
|---|---|---|
| 表情符号 | 段落开头或关键信息处每段1-2个 | 🌟 📝 ✅ 🔥 |
| 口语化表达 | 避免书面语多用流行口语 | 咱就是说、真的绝了、姐妹们、沉浸式 |
| 互动钩子 | 提问或引导动作促进评论收藏 | 需要清单的评论区dd / 你们有没有同款烦恼？ |
| 段落控制 | 每段≤3-4行适时空行 | 增加留白移动端体验更好 |
| 对比句式 | 不是A❌ 而是B✅ | 不是盲目日更❌ 而是精准选题✅ |
| 数据锚点 | 用具体数字替代模糊描述 | "提升了" → "提升了35%" |

#### emoji使用规范

| 位置 | 用法 | 示例 |
|---|---|---|
| 段落开头 | 标记内容类型 | 🧠概念 📋步骤 🔥重点 💡技巧 |
| 强调处 | 情绪放大 | ❗警示 ✅正确 ❌错误 👉指向 |
| 结尾 | 互动引导 | 💾收藏 👇评论 🥰情感 |
| 序号替代 | 步骤编号 | 𝟭｜𝟮｜𝟯｜ 或 ❶❷❸ |

密度控制：每段1-2个emoji，禁止连续3个以上堆砌。

#### 文字排版细节

1. **短句为王**：每句≤20字，长句必须拆分
2. **换行即分段**：小红书没有段落缩进，靠换行制造呼吸感
3. **对比句式（推荐）**：`不是A❌ 而是B✅` 制造认知冲突
4. **数据锚点**：用具体数字替代模糊描述
5. **口语化表达**：用"咱就是说""真的绝了""姐妹们""划重点"等
6. **禁止长段落**：超过3-4行必须拆分
7. **互动引导（强制）**：正文结尾必须包含互动引导模块

### 摘要（30-54字）

摘要显示在消息列表和分享卡片中，直接影响打开率。

公式：不重复标题→补充关键信息/制造悬念

规则：
1. 字数30-54字
2. 不重复标题内容而是补充信息或制造悬念
3. 第一句话必须有吸引力呼应标题中的悬念
4. 避免"点击阅读全文"等无意义引导

示例：
```
标题："3个让AI写出人味文章的技巧"
摘要："第三条90%的人都不知道，建议收藏"
```

### 正文排版

#### 开头钩子（前3行决定留存率）

开头必须在前3行内完成：场景/痛点→引出话题→价值承诺

```
[场景/痛点] 描述读者正在面临的问题或场景
[引出话题] 自然的过渡，引出本文要讲的核心
[价值承诺] 明确告诉读者看完能得到什么
```

#### 正文规则

| 规则 | 要求 | 为什么 |
|---|---|---|
| 字数 | 1500-2500字（最佳完读率） | 太短不够深度太长完读率降 |
| 结构 | 小标题分段→每段深度展开→总结→CTA | 结构化易读 |
| 段落 | 每段≤4行 | 手机阅读舒适 |
| 配图 | 封面图（横版2.35:1或1:1）+正文3-6张每300-500字一张 | 长文配图减疲劳 |
| 引用块 | 重要观点用引用块强调 | 视觉层级 |
| 列表 | 要点用列表呈现 | 扫读友好 |

## 一稿多发完整流程

```
1. 接收原始内容（草稿/大纲/灵感片段）
        ↓
2. 读取各平台风格规范（platform-xhs/wechat/weibo.md）
        ↓
3. 生成小红书版
   - 标题≤20字+12种公式选一
   - 正文≤1000字+黄金三段式+3种钩子选一+3种写作公式选一
   - 3-5个#标签（热点+垂直+人群组合）
   - 3:4竖版首图+封面大字6-12字+配图建议3-6张
   - 去AI味处理
        ↓
4. 生成公众号版
   - 标题18-28字+5种公式选一
   - 摘要30-54字不重复标题
   - 正文1500-2500字+小标题分段+每段≤4行
   - 封面图横版+每300-500字配图
        ↓
5. 生成微博版
   - ≤300字+首句即观点
   - 1-3个#话题#
   - 引导转发
        ↓
6. 每个版本独立适配（不直接复制粘贴）
        ↓
7. 自检验证（每个平台各自的清单）
   小红书17项自检/公众号标题摘要正文/微博字数首句话题
        ↓
8. 保存文件
```

### 深入：为什么不直接复制粘贴

| 差异 | 小红书 | 微博 |
|---|---|---|
| 用户行为 | 搜索+浏览种草 | 刷信息流看热点 |
| 内容偏好 | 干货/教程/测评 | 观点/热点/短评 |
| 最佳长度 | 500-1000字 | ≤300字 |
| 标签作用 | #话题是搜索入口 | #话题是分类入口 |
| 图片要求 | 3:4竖版多图 | 1-9张可选 |
| CTA | 评论/收藏 | 转发/评论 |

> 同一篇1000字小红书直接发微博=太长没人看。
> 同一篇300字微博直接发小红书=太短不够深度。
> **每个平台必须独立适配——不是复制粘贴是重新组织。**

### 深入：去AI味（2026小红书核心）

> 2026小红书算法优先推荐"真人创作·真实体验"——AI痕迹明显的内容会被降权。

| AI味特征 | 怎么去 |
|---|---|
| 过于工整的排比句 | 用口语化表达 |
| 每段都emoji开头 | emoji放在语义转折处不每段 |
| 缺乏个人感受 | 加入"我觉得""我试了""说实话" |
| 信息密度过高无留白 | 适当加入场景描写和情绪 |
| 结构过于模板化 | 打破模板用真实故事线 |

> ⚠️ AI生成内容发布前必须口语化改写并加入真实体验细节，否则容易被识别为低质内容导致限流。

## 排版的常见误读

| 误读 | 纠正 | 为什么 |
|---|---|---|
| "一稿多发=复制粘贴" | 每个平台必须独立适配 | 用户习惯不同 |
| "小红书=堆emoji" | 禁止连续3个以上 | 堆砌=低质量 |
| "公众号越长越好" | 1500-2500字最佳完读率 | 太长完读率降 |
| "微博=随便写" | 首句即观点决定看不看 | 首句最重要 |
| "标题越长信息越多越好" | 小红书≤20字/公众号前15字含核心 | 平台限制+展示 |
| "内容好就行不用排版" | 排版影响完读率和互动 | 好内容+好排版=高互动 |
| "AI生成直接发" | 2026小红书去AI味降权 | 真人创作算法优先 |
| "极限词没事" | 最/第一/绝对/100%=违规 | 官方明确禁用 |
| "标签越多越好" | 小红书3-5个质量优于数量 | 无关标签降权 |
