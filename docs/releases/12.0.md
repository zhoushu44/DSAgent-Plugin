## 七、修复

### 7.1 健康检查假阳性（重点）

**现象**：连接器显示"有效"，一跑技能就 `token_expired`。

**三层根因**：

| 层 | 问题 |
|----|------|
| 工具层 | `dsagent_check_account_health` 只读本地 status 字段（心跳），从不真探测 |
| 探测层 | `probeRemoteSession` 只支持 taobao/xhs，pdd 一律 `return unknown` → 状态保持 |
| 降级层 | host HTTP 不可用时 `callHostTool` 返回 null → 被当成"无法判定" → 仍是 valid |

**修复**（4 处）：

| # | 文件 | 修复 |
|---|------|------|
| 1 | `src/tools-platform.ts` | 工具默认走 `checkHealthReal`（真实探测） |
| 2 | `src/gateway-proxy.ts` | 新增 `probePddMmsSession()`（探测点 `earth/api/mallInfo/commonMallInfo`） |
| 3 | `src/services/account-service.ts` | host 不可用时本地降级探测；远端明确失效立即透出 |
| 4 | `src/http-routes.ts` | `list_accounts` 加 `probeStale` 标记（超 30 分钟提示"待验证"） |

**效果**：

```text
修复前：已检查 1 个账号，全部有效。        ← 假阳性
修复后：[{"status":"expired","reason":"远端返回未登录/错误响应"}]
```
